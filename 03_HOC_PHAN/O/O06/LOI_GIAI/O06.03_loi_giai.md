# O06.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế release checklist có build reproduce, signature verify, rollback và token revoke.

CI release gate: create deterministic source archive from tag, build twice from clean agents, compare provenance and artifact SHA-256, sign artifact/attestation, verify signer identity and digest, perform smoke install, publish under scoped OIDC token, monitor errors. Prepare rollback package and dependency lock. On credential compromise revoke token and invalidate publication authority; signature verification alone cannot prove software safety.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
