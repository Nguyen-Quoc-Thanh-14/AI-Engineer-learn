# O06.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế chuỗi lệnh venv→install→test→build trên 3.15; nêu điểm cần kiểm uv/pip phiên bản hiện hành.

Commands for an environment with CPython 3.15.2 installed: `python3.15 -m venv .venv` → `. .venv/bin/activate` (Windows use `Scripts\activate`) → `python -m pip install -e '.[test]'` → `python -m pytest` → `python -m build`. If using `uv`, first verify selected interpreter with `uv python find 3.15` and tool's current lock/frozen flags, then run clean install. Do not mix pip and uv lock semantics without explicit policy. **Status:** workflow described, not tested under 3.15.2 here.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
