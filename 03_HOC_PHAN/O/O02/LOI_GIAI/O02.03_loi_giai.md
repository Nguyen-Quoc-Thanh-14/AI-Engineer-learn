# O02.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết changelog cho breaking API thay đổi và nêu lý do increment major.

Example breaking change: `calculate_total(items)` becomes `calculate_total(items, *, currency: str)` with required keyword-only argument. Update **major** for a stable public API according to SemVer if existing consumers break; e.g. 1.4.2 → 2.0.0. Changelog sections: Breaking Changes (new argument), Migration (`currency="VND"`), Added Tests, Compatibility/Minimum Python. SemVer is a convention, not automatically guaranteed by Python packages; pre-1.0 rules differ.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
