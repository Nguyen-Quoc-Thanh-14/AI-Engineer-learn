# O02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Tạo hai branch sửa cùng dòng, giải conflict và chạy pytest trước merge.

`git switch -c feature/a`; modify a shared line, commit. Switch to main; create `feature/b`, change the same line and commit. Merge `feature/a` into `feature/b` to trigger conflict; inspect `git status` and conflict markers; make a deliberate combined correction; `git add`, `git commit`, run `python -m pytest`, open PR with both behavior change and test output. Never auto-accept “ours/theirs” without reviewing semantics.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
