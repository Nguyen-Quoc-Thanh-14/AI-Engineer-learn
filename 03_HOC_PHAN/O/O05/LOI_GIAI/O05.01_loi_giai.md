# O05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Lập chính sách tự động update patch hàng tuần và review major/minor có migration plan.

Weekly patch update: automated branch opens lockfile diff + SBOM diff; clean install, unit/integration/security checks and human approval for sensitive packages. Minor/major upgrades require migration note, compatibility test and rollback plan; pin runtime and build tools. Security advisory may justify immediate out-of-band patch. Record owner and due date rather than leaving upgrade PRs unresolved.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
