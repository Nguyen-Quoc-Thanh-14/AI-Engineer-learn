# O05.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Lập checklist phát hành v0.1.0 tới TestPyPI từ Git tag ký và kiểm checksum.

Release v0.1.0: require reviewed Git tag + signed/verified commit; build sdist and wheel in clean CI, run `twine check`, create SHA-256 digest manifest, attest provenance, test wheel install in clean venv, upload to TestPyPI using scoped short-lived token, verify checksum against downloaded artifact, then request separate approval for PyPI. Revoke accidental token exposure and do not print credentials. Compatible wheel tags must be checked per target OS/Python.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
