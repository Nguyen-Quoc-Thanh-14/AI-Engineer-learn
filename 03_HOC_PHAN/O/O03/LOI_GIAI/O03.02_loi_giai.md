# O03.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế pipeline ruff format check → ruff lint → mypy/pyright → pytest.

Order CI quality gates: `ruff format --check .` → `ruff check .` → `mypy src` (or pyright) → `python -m pytest -q`. Run with pinned dev dependencies in clean env and fail the job when any gate exits nonzero. Tests should include at least one type error fixture to prove the checker is active; exclude that fixture from the main passing suite. Record tool versions and a clear policy for suppressions rather than blanket ignore flags.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
