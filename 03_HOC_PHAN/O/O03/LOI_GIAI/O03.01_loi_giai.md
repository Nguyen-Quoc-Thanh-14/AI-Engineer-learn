## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Chạy doctest cho square và viết README có install/test/limitations.

**Mã chạy riêng:** [O03.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/O03.01_bai_B_solution.py)

```python
import doctest

def square(x):
    """Square a numeric value.

    >>> square(3)
    9
    >>> square(-2)
    4
    """
    return x*x
assert doctest.testmod().failed==0
README="# Sample package\nInstall: `python -m pip install -e .`\nTest: `python -m doctest -v module.py`\nLimitations: no string inputs.\n"
assert 'Limitations' in README
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
