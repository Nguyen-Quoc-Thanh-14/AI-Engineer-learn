# O03.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết docs cho lỗi ValueError và compatibility khi thêm tham số tùy chọn.

Define `def parse_count(text: str, *, min_value: int = 0) -> int`: raises `ValueError` on malformed input or number below minimum. Public API doc must specify `min_value` is keyword-only, default and error semantics; include examples for normal/negative/invalid inputs. Backward-compatible addition of *optional* keyword-only param preserves old valid calls, but changing error type or side effects may still break consumers. Use doctest to check documented examples.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
