# O04.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết Dockerfile tối thiểu chạy Python dưới nonroot, pin base và thêm HEALTHCHECK phù hợp.

```dockerfile
FROM python:3.15.2-slim@sha256:<approved-and-verified-digest>
WORKDIR /app
RUN groupadd -r app && useradd -r -g app app
COPY dist/*.whl /tmp/
RUN python -m pip install --no-cache-dir /tmp/*.whl
USER app
HEALTHCHECK --interval=30s --timeout=3s CMD python -c "import urllib.request;urllib.request.urlopen('http://127.0.0.1:8000/health',timeout=2)" || exit 1
CMD ["python","-m","your_app"]
```
`<approved-and-verified-digest>` is a placeholder: **do not build/publish until replaced with the actual verified digest**, and adapt `/health` only if the app serves it. Run local nonroot and healthcheck tests; CPU/memory limits at orchestrator level.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
