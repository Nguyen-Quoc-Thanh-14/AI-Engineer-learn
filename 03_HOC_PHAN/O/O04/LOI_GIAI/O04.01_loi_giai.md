# O04.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế GitHub Actions workflow kiểm 3.14/3.15 + ruff + pytest, giải thích fail-fast.

GitHub Actions matrix: `python-version: ['3.14', '3.15']`, `os: [ubuntu-latest, windows-latest]`, `strategy.fail-fast: false`. Review and pin action SHA, run `python -m pip install -e '.[dev]'`, `ruff check .`, `ruff format --check .`, `pytest -q`. Missing 3.15 runner support is **blocked** not PASS; export JUnit XML per matrix cell. `fail-fast: false` is for collecting all results, not for ignoring failure.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
