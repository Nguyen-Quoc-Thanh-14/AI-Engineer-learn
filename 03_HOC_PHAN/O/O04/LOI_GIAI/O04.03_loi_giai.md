# O04.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế rollback API khi migration thêm field, giải thích expand-and-contract.

Expand-and-contract rollback: add nullable column first, deploy code reading old/new and writing both, backfill in bounded batches, validate, switch reads, later enforce constraint/drop old. Rollback must preserve old write path until all running versions have upgraded. Smoke-test both old and new API against expanded schema. Never roll back irreversible destructive DB migrations without a tested data recovery path.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
