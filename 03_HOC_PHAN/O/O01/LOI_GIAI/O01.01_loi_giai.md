# Lời giải mẫu O01.01 — Shell và filesystem commands

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Thử dùng `python -c` để hiển thị thư mục làm việc; phân biệt cwd và đường dẫn của file script.

## Code lời giải

```python
from pathlib import Path
assert Path.cwd().exists()
assert isinstance(str(Path.cwd()),str)
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Ví dụ không chạy shell trực tiếp mà in thư mục hiện tại qua Python; môi trường chạy của IDE hoặc cron có thể đặt working directory khác thư mục source code.

**Giới hạn:** Tên file có khoảng trắng đòi hỏi quoting khi sử dụng shell.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
