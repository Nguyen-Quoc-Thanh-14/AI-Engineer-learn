# O01.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Tạo cấu hình VS Code chọn `.venv`, chạy pytest và debug một function lỗi.

Create `.vscode/settings.json` with `{"python.defaultInterpreterPath":"${workspaceFolder}/.venv/bin/python","python.testing.pytestEnabled":true,"python.testing.unittestEnabled":false}` on Linux/macOS; select the actual `Scripts\python.exe` path on Windows. Add `.vscode/launch.json` for `type="debugpy"`, `request="launch"`, `program="${file}"` and `console="integratedTerminal"`. Add a breakpoint to a function with a known zero denominator, inspect local variables, verify venv and test the patched function. Do not commit private paths, tokens or machine credentials.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
