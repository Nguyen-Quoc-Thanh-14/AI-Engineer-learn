# O01.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết checklist chẩn đoán ModuleNotFoundError do sai PATH và venv.

Diagnostic order for `ModuleNotFoundError`: (1) print `sys.executable` and `sys.path`; (2) run `python -m pip --version`; (3) inspect `python -m pip show package`; (4) confirm correct venv and selected VS Code interpreter; (5) check import name vs package distribution name; (6) check `PYTHONPATH`/local name shadowing; (7) rebuild venv from lock if inconsistent. **Acceptance:** `python -c 'import package;print(package.__file__)'` runs in the intended environment without globally installing packages.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
