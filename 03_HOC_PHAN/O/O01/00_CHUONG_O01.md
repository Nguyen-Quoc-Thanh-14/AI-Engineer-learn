## O01.01 — Shell và filesystem commands

> **Trạng thái:** ĐÃ BIÊN SOẠN BẢN THẢO CHUYÊN BIỆT; VÍ DỤ VÀ LỜI GIẢI CHẠY ĐẠT PYTHON 3.13.5.
> **Giai đoạn:** GD1 · **Chương:** O01 — Terminal và môi trường phát triển · **Đích:** CPython 3.15.2.

### 1. Chuẩn đầu ra có thể kiểm chứng

1. Tự giải thích khái niệm **Shell và filesystem commands**, nêu một trường hợp nên và không nên áp dụng.
2. Dự đoán trạng thái/kết quả ví dụ trước khi chạy và giải thích từng bước.
3. Viết một lời giải độc lập, xử lý ít nhất ba trường hợp (bình thường, biên, sai đầu vào).
4. Chỉ ra giả định, giới hạn và đối chiếu kết quả bằng kiểm thử.

**Tiên quyết:** A.

### 2. Khái niệm — Bản chất

Shell là trình thông dịch câu lệnh hệ điều hành; working directory quyết định cách diễn giải relative path. Các lệnh như `pwd`, `cd`, `ls` (Unix) hoặc `dir` (Windows) tương tự nhau về mục đích nhưng cú pháp khác nhau. Mã Python nên dùng `pathlib` khi cần thao tác đường dẫn đa nền tảng.

### 3. Nguyên lý và cơ chế từng bước

Ví dụ không chạy shell trực tiếp mà in thư mục hiện tại qua Python; môi trường chạy của IDE hoặc cron có thể đặt working directory khác thư mục source code.

### 4. Ví dụ tối thiểu có thể chạy

```python
from pathlib import Path
cwd=Path.cwd()
assert cwd.is_dir()
print('cwd:',cwd.name)
```

**Kết quả kiểm thử cục bộ:** pass trên Python 3.13.5.

```text
cwd:
```

**Thực hành:** chạy file `07_MA_VI_DU/O01.01_vi_du.py` từ thư mục gốc giáo trình rồi sửa một tham số để dự đoán sự khác biệt.

### 5. Trường hợp biên, lỗi thường gặp và hướng debug

- **Ngộ nhận:** Không giả định `Path.cwd()` luôn là thư mục chứa tệp `.py`.
- **Trường hợp biên:** Tên file có khoảng trắng đòi hỏi quoting khi sử dụng shell.
- **Debug có phương pháp:** xác định hợp đồng → tái hiện lỗi bằng đầu vào tối thiểu → đọc traceback/kiểm tra trạng thái → sửa → thêm regression test.

### 6. So sánh lựa chọn kỹ thuật và đánh đổi

Terminal là công cụ để lặp lại các bước thay vì click thủ công, nhưng phải hiểu lệnh trước khi chạy.

### 7. Bài tập có yêu cầu kiểm chứng

Thử dùng `python -c` để hiển thị thư mục làm việc; phân biệt cwd và đường dẫn của file script.
