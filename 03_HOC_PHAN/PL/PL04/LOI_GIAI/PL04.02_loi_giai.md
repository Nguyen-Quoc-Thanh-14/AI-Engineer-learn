# PL04.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế tài nguyên cho training 2 GPUs và nêu all-reduce bottleneck.

2-GPU distributed data-parallel plan: split batch B into B/2 microbatches per worker, synchronize gradients with all-reduce, set per-device peak memory and network bandwidth budget. Compare step time/throughput against one GPU with same effective batch; estimate communication bottleneck via collective size and link throughput. Require deterministic sampler seed, checkpoint optimizer/scheduler/RNG states and deadlock/timeout policy. **Blocked:** no 2-GPU runtime in this environment.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
