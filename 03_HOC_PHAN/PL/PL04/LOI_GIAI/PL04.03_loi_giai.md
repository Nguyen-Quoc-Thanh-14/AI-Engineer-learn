## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** So outputs model.eval và model.train với dropout, kiểm inference determinism.

**Mã chạy riêng:** [PL04.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PL04.03_bai_B_solution.py)

```python
import torch
from torch import nn
torch.manual_seed(42)
m=nn.Sequential(nn.Linear(4,8),nn.Dropout(0.5),nn.Linear(8,1))
x=torch.ones(1,4)
m.eval()
with torch.inference_mode(): a=m(x);b=m(x)
assert torch.equal(a,b)
m.train();assert m[1].training is True
# Train mode changes dropout behavior, but individual outputs may coincidentally match.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
