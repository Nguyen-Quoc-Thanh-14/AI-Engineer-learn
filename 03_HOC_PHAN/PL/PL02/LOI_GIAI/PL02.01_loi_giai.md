## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Huấn luyện một MLP nhỏ dự đoán XOR và so với linear model.

**Mã chạy riêng:** [PL02.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PL02.01_bai_B_solution.py)

```python
import torch
from torch import nn
torch.manual_seed(7)
x=torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
y=torch.tensor([[0.],[1.],[1.],[0.]])
linear=nn.Linear(2,1);mlp=nn.Sequential(nn.Linear(2,16),nn.Tanh(),nn.Linear(16,1))
opt=torch.optim.Adam(mlp.parameters(),lr=.08)
for _ in range(180):
    opt.zero_grad();loss=((mlp(x)-y)**2).mean();loss.backward();opt.step()
with torch.no_grad():
    preds=(mlp(x)>0.5).float()
    assert torch.equal(preds,y)
# A linear classifier cannot represent XOR with a single linear decision boundary.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
