# PL02.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Dựng cùng MLP đơn giản với PyTorch và Keras 3, so training/evaluation APIs.

**Two-framework functional equivalence:** choose input dimension=4, hidden=8, output=1; PyTorch `nn.Sequential(nn.Linear(4,8),nn.ReLU(),nn.Linear(8,1))`, Keras `Sequential([Input(shape=(4,)), Dense(8,activation="relu"),Dense(1)])`. Train on deterministic toy regression with identical train/validation split, report loss curves and parameters; **do not** expect identical weights/loss after random initialization. Set `KERAS_BACKEND` before import and name Keras version explicitly. Blocked here for TensorFlow backend (not installed); PyTorch CPU path is available.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
