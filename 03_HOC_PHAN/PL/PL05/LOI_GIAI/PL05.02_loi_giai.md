# PL05.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Trên environment có Keras 3, tạo model đơn giản với backend đã cấu hình và đo fit/predict.

Keras 3 multi-backend: set `KERAS_BACKEND="torch"` (or supported backend) before first import, then construct a tiny model with `keras.layers.Dense`, compile/fit/predict on fixed 100-example data. Compare with a native PyTorch model using same loss/optimizer *semantics*; API mapping and numeric output need not be identical. Save dependency versions and check `keras.backend.backend()`; TensorFlow backend cannot be tested here because TensorFlow is absent. Include a separate environment with TensorFlow if required.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
