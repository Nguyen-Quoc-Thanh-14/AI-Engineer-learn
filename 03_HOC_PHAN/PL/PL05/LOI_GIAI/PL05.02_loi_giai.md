# PL05.02 — Lời giải B: Keras 3 với PyTorch backend

**Đề B:** “Trên environment có Keras 3, tạo model đơn giản với backend đã cấu hình và đo fit/predict.”

## Lời giải thực thi

1. Cài Keras cùng toàn bộ dependency; \`python -m pip check\` phải thoát 0. Không sử dụng \`pip install --no-deps keras\`.
2. Đặt \`KERAS_BACKEND=torch\` **trước** khi \`import keras\`; kiểm tra \`keras.backend.backend() == "torch"\`.
3. Tạo dữ liệu \`x=[-2,-1,0,1,2]\`, nhãn \`y=2x+1\`; \`Dense(1)\` trọng số/bias ban đầu bằng 0; optimizer SGD learning rate 0.05.
4. Đo MSE ban đầu, train 60 epochs với \`shuffle=False\`, đo MSE cuối; dùng \`assert loss_final < 0.05 * loss_initial\`.
5. Kiểm tra \`predict(3)\` sai khác 7 dưới 0.3; save \`.keras\`, load và so kết quả dự đoán.
6. Dùng \`keras.ops.square\` trên Torch tensor \`requires_grad=True\`, gọi backward và đối chiếu \`[-4,0,6]\`; dùng h5py thực sự để ghi/đọc dataset.
