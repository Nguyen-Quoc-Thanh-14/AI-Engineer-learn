# PL05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Chạy autoregressive attention với upper-triangular mask và xem weights.

**Mã chạy riêng:** [PL05.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PL05.01_bai_B_solution.py)

```python
import torch
logits=torch.arange(16,dtype=torch.float32).reshape(4,4)
mask=torch.triu(torch.ones(4,4,dtype=torch.bool),diagonal=1)
att=torch.softmax(logits.masked_fill(mask,float('-inf')),dim=-1)
assert torch.allclose(att.sum(dim=-1),torch.ones(4))
assert torch.count_nonzero(att[0,1:])==0
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
