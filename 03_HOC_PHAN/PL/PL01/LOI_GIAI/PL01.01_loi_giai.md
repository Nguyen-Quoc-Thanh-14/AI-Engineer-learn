## 1. Khái niệm và hợp đồng

Autograd ghi phép tính tensor để lan truyền đạo hàm từ scalar loss về các leaf tensors có requires_grad=True; backward() cộng dồn vào .grad trừ khi được reset.

## 2. Lập luận trước khi viết mã

Với hàm f(x)=sum(3x²+2x), gradient giải tích là 6x+2. Kiểm tra các giá trị âm, 0 và dương, rồi gọi backward hai lần có chủ ý để thấy gradient cộng dồn. Định nghĩa loss scalar tránh phải truyền gradient đầu vào cho backward.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PL01.01_bai_tap_da_giai_v25.py`](../MA_MAU/PL01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/PL01.01_bai_tap_da_giai_v25.py
```

```python
import torch

def gradient(values):
    x = torch.tensor(values, dtype=torch.float64, requires_grad=True)
    loss = (3 * x.square() + 2 * x).sum()
    loss.backward()
    return x.grad.detach().tolist()

def check():
    result = gradient([-1.0, 0.0, 2.0])
    assert torch.allclose(torch.tensor(result), torch.tensor([-4.0, 2.0, 14.0]))
    assert gradient([]) == []
    x = torch.tensor([1.0], requires_grad=True)
    (x * x).sum().backward()
    assert x.grad.item() == 2.0
    (x * x).sum().backward()
    assert x.grad.item() == 4.0  # tích lũy

if __name__ == '__main__':
    check()
    print('OK PL01.01', gradient([-1., 0., 2.]))
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không gọi .numpy() trực tiếp trên tensor có requires_grad=True; muốn đưa sang NumPy hãy detach rồi chuyển sang CPU khi cần.

**Bài mở rộng chưa có đáp án:** So sánh autograd với sai phân hữu hạn và nêu sai số khi step quá nhỏ do floating-point cancellation.
