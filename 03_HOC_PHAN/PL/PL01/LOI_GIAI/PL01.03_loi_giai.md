# PL01.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết script kiểm backend TensorFlow/Keras/PyTorch và báo phiên bản, device.

Backend discovery script:
```python
import importlib.metadata as md
for lib in ('keras','tensorflow','torch'):
    try: print(lib,md.version(lib))
    except md.PackageNotFoundError: print(lib,'missing')
```
For Keras 3, set `KERAS_BACKEND` in the process environment **before importing keras**, and verify backend selection via `keras.backend.backend()`. For PyTorch print `torch.cuda.is_available()` and device name only when available; CPU is a valid fallback. Log driver/CUDA/runtime compatibility; do not imply a GPU is usable merely because it exists physically.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
