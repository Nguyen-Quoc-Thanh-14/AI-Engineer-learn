## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tính gradient f(x)=sin(x)*x và so finite differences.

**Mã chạy riêng:** [PL01.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PL01.02_bai_B_solution.py)

```python
import math

def analytic(x): return math.sin(x)+x*math.cos(x)
def numeric(x,eps=1e-6):return ((x+eps)*math.sin(x+eps)-(x-eps)*math.sin(x-eps))/(2*eps)
for x in (-3.,-0.1,0.,2.):assert abs(analytic(x)-numeric(x))<1e-8
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
