# PL03.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế đánh giá generative model gồm factuality, diversity, privacy, cost.

**Generative evaluation rubric:** factuality (percent claims supported by evidence), diversity (distinct output coverage across seeds), privacy (PII leakage probe on consented synthetic fixtures), safety (policy-specific violation rate), and cost (tokens/s or GPU-seconds per correct output). Create fixed 100-case holdout with manual labels and uncertainties; report Wilson intervals for binary pass rates, pre-register refusal handling and data provenance. Reject a model that improves diversity but leaks PII. A score from a single prompt is not representative.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
