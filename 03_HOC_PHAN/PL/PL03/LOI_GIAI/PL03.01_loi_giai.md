# PL03.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thử feature extractor pretrained có source weights hợp lệ, kiểm fine-tuning set layers.

Transfer-learning experiment: select model architecture and **licensed, hash-verified pretrained weights** from the official registry, freeze feature extractor initially, train new classifier head, then optionally unfreeze last block at lower LR. Split dataset by subject/source before augmentation. Track validation metric, inference latency and failures; never download untrusted pickle weights. Without approved pretrained weights and real images, this answer is a reproducible protocol, not a completed performance test.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
