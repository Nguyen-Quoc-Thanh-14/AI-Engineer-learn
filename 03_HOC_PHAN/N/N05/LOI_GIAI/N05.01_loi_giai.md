# N05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Lập threat model request → gateway → app → database với validation tại từng boundary.

**Trust boundaries:** untrusted client → gateway → service handler → database. Gateway verifies transport, request size/rate and authentication; service validates type/schema, authorizes *resource ownership* and uses parameterized SQL; database uses least-privilege credentials and constraints. Attack tests: wrong tenant ID returns 403/404, malformed JSON returns 400, duplicate idempotency key does not double-write, and large payload is rejected. Caching layers must not expose another tenant's object.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
