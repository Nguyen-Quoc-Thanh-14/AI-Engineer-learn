# N05.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thực hiện tabletop drill cho SQL injection vào API và viết action items có chủ sở hữu.

**SQL injection drill:** seed harmless test records; send a deliberately malformed query string into a *staging* endpoint; confirm ORM/parameterized SQL treats it as data rather than syntax. Capture sanitized request ID, alert path, DB access logs and rollback of test fixtures. Action items: Owner App—parameterize queries; Owner DB—least privilege; Owner Security—add SAST/DAST and incident playbook; Owner QA—add negative regression tests. Close only after signed review and monitored clean deploy.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
