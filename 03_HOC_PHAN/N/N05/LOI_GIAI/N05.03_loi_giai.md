# N05.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết checklist cập nhật Python và trust store sau advisory TLS và thử endpoint TLS trong test lab.

**Incident response based on Python 3.15.2 TLS security release:** inventory Python runtime and trust stores, read the upstream advisory for compromised intermediate certificates, update runtime and trust bundles through approved channels, validate legitimate TLS endpoint connectivity and confirm compromised chain is rejected in an isolated test lab. Record certificate chain/source and runtime version. **Do not** bypass TLS verification or weaken CA validation as a workaround; separate trusted public endpoints from controlled negative-test fixtures.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
