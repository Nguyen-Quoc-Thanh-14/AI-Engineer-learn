# N02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Tạo SBOM mẫu ở mức dependency/direct/transitive và thiết kế quy trình cập nhật khi có advisory.

SBOM record: `{name, version, direct_or_transitive, purl, source, digest, license, dependency_path}`. Generate SBOM via trusted build tool, retain provenance and compare against dependency lockfile. When advisory arrives: verify affected version/range, severity *and* exploitability in your deployment, choose safe patch, test in isolated CI, publish update, notify owner, and update SBOM. **Acceptance:** for a vulnerable transitive dependency, trace the top-level dependency path and prove the new build no longer contains the affected version.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
