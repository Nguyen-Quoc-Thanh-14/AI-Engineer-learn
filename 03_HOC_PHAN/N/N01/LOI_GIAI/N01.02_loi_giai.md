# Lời giải mẫu N01.02 — Injection, path traversal và command execution

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tạo allowlist mã hàng gồm ba chữ cái ASCII và 5 chữ số; tạo ca chứa newline.

## Code lời giải

```python
import re
def valid(s):return isinstance(s,str) and re.fullmatch(r'[A-Z]{3}[0-9]{5}',s) is not None
assert valid('ABC12345')
assert not valid('ABC12345\n')
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Kiểm tra một mã định danh kinh doanh bằng regex `fullmatch`, từ chối giá trị không đúng định dạng. Validation nên được thực hiện gần nơi dữ liệu đi vào boundary; hợp đồng cần ghi rõ Unicode hay ASCII.

**Giới hạn:** Quá dài cũng có thể gây tiêu thụ tài nguyên; bổ sung giới hạn độ dài.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
