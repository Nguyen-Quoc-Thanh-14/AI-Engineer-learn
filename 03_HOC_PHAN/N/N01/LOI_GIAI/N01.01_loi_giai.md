# N01.01 — Lời giải đúng đề: validation điểm số 0..10, từ chối NaN

> **Hiệu đính:** bản v2.5 đã giải nhầm bài kiểm tra tuổi 0–130. Bản này thay bằng lời giải theo đúng đề bài ở mục 7 của N01.01. **Trạng thái nghiệm thu CPython 3.15.2:** chạy lại workflow \`semantic-contracts-3152.yml\` và kiểm tra artifact; không tự coi mã mới là đã đạt trước khi có kết quả.

## 1. Đề bài gốc và hợp đồng

**Đề bài:** “Thiết kế schema cho điểm số 0..10 và test NaN không được lọt”.

Hợp đồng: chỉ chấp nhận giá trị \`int\` hoặc \`float\` **built-in** của Python, hữu hạn, thuộc đoạn đóng [0,10]; từ chối \`bool\` (trong Python \`bool\` là subclass của \`int\`), chuỗi, \`None\`, số âm, số > 10, \`NaN\` và vô cực. API trả về \`float\` hợp lệ; \`Decimal\`, NumPy scalar và coercion chuỗi nằm ngoài phạm vi bài.

## 2. Phương pháp

- Dùng \`type(value) in (int, float)\` thay vì \`isinstance(value, int)\` để \`True\` không bị xem là điểm 1.
- Kiểm tra \`0 <= value <= 10\` để xác định phạm vi. Riêng \`NaN\`, so sánh thứ tự luôn False nên phải từ chối rõ; \`math.isfinite\` cũng xác định vô cực.
- Với \`int\` rất lớn, **kiểm tra phạm vi trước khi chuyển sang float**, tránh lỗi tràn khi chuyển đổi.
- Không ghi điểm chưa xác minh vào báo cáo là PASS.

## 3. Mã và kiểm thử

Mã hoàn chỉnh: [\`N01.01_bai_tap_da_giai_v25.py\`](../MA_MAU/N01.01_bai_tap_da_giai_v25.py) (giữ tên file để không phá liên kết cũ).

```python
def parse_score(value: object) -> float:
    import math
    if type(value) not in (int, float):
        raise TypeError("Điểm phải là int hoặc float")
    if not 0 <= value <= 10:
        raise ValueError("Điểm ngoài [0,10] hoặc NaN")
    if type(value) is float and not math.isfinite(value):
        raise ValueError("Điểm không hữu hạn")
    return float(value)
```

Tối thiểu ba nhóm thử: hợp lệ \`0, 10, 7.5\`; ngoài miền \`-1, 11\`; không hợp lệ \`float('nan'), float('inf'), bool, str, None\`. Mã có thêm ca \`10**500\`. Bộ kiểm tra tách khỏi lời giải: \`tests/highrisk_contracts_3152.py\`.

## 4. Cách giải sai và hạn chế

\`0 <= x <= 10\` **một mình** có thể từ chối \`NaN\` bằng kết quả False nhưng không mô tả lý do; cần xử lý kiểu và finite rõ ràng, không chấp nhận \`bool\`, và không dựa vào coercion ngầm.

Bộ kiểm thử tập trung vào hợp đồng này; nó không thay thế validation ở API HTTP (size limit, JSON schema), giới hạn nghiệp vụ chấm điểm, kiểm thử bảo mật hệ thống hay phản biện sư phạm độc lập.

**Nguồn:** [Python math.isfinite](https://docs.python.org/3.15/library/math.html#math.isfinite).
