## 1. Khái niệm và hợp đồng

Trust boundary là ranh giới nơi dữ liệu từ nguồn không đáng tin được chuyển thành giá trị dùng trong hệ thống; kiểm tra cú pháp, miền và độ dài trước khi sử dụng.

## 2. Lập luận trước khi viết mã

API parse_age nhận chuỗi ASCII digits 0..130, bỏ khoảng trắng đầu/cuối, từ chối mọi ký tự còn lại bằng fullmatch. Việc hợp đồng chỉ nhận chuỗi tránh tự động chấp nhận số thực hoặc bool ngoài dự kiến.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/N01.01_bai_tap_da_giai_v25.py`](../MA_MAU/N01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/N01.01_bai_tap_da_giai_v25.py
```

```python
import re

def parse_age(value: str) -> int:
    if not isinstance(value, str):
        raise TypeError('age phải là chuỗi')
    value = value.strip()
    if not re.fullmatch(r'[0-9]{1,3}', value, flags=re.ASCII):
        raise ValueError('chỉ nhận số nguyên ASCII có 1–3 chữ số')
    age = int(value)
    if age > 130:
        raise ValueError('age ngoài miền [0,130]')
    return age

def check():
    assert parse_age(' 25 ') == 25
    assert parse_age('0') == 0 and parse_age('130') == 130
    for value in ('131', '12; DROP TABLE users', '-1', ''):
        try: parse_age(value)
        except ValueError: pass
        else: raise AssertionError('phải từ chối '+value)
    try: parse_age(True)
    except TypeError: pass
    else: raise AssertionError('bool không phải str')

if __name__ == '__main__':
    check()
    print('OK N01.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không dùng int() trên mọi dữ liệu rồi cho rằng đã đủ validation: chuỗi quá dài, định dạng bất ngờ hoặc giá trị ngoài miền vẫn là vấn đề.

**Bài mở rộng chưa có đáp án:** Thêm giới hạn kích thước request và normalize dữ liệu nhập từ HTTP; phân biệt validation và escaping đầu ra theo từng ngữ cảnh.
