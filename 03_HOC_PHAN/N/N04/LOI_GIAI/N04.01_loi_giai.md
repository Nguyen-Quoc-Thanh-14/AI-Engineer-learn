# N04.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Lập data-flow diagram cho API upload tệp, nêu 5 threats và mitigation.

**Upload DFD:** user → authenticated upload API → temporary quarantine → content validation/AV → object storage → authorized download handler. Assets: private files, user identity, metadata and storage keys. Five threats: path traversal, decompression bomb, content spoofing, cross-tenant IDOR, malicious script/active file. Controls: randomized storage names, size/time limits, allow-listed content parsing, tenant ownership check on each read, quarantine and sandboxed scanning. **Tests:** traversal paths, oversized bytes, wrong content magic, cross-tenant access, malformed archive. TLS and auth are necessary but not sufficient.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
