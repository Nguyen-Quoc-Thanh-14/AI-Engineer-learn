# Lời giải bài tập vận dụng — N04.02 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Viết 6 test IDOR: owner/nonowner/admin cho đọc và sửa resource.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
class Denied(PermissionError):pass
def access(user_id,role,owner_id,operation):
    if operation not in {'read','write'}:raise ValueError
    if role!='admin' and user_id!=owner_id:raise Denied
    return True
cases=[(1,'user',1,'read',True),(1,'user',1,'write',True),
       (2,'user',1,'read',False),(2,'user',1,'write',False),
       (2,'admin',1,'read',True),(2,'admin',1,'write',True)]
for uid,role,owner,op,expected in cases:
    try:got=access(uid,role,owner,op)
    except Denied:got=False
    assert got is expected
print('PASS N04.02')
```
