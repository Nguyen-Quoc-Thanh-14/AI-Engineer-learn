# N03.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Vẽ ma trận dependency mất kết nối và ứng xử cho payment, analytics, user profile.

| Failed dependency | Service behavior | Reason |
|---|---|---|
| Payment authorization | Fail closed; no order confirmation | Avoid unpaid orders |
| Analytics export | Queue bounded, report delayed | Core order flow may continue |
| User profile lookup | Return 503 if critical to permissions | Do not silently bypass authorization |

Use timeouts, circuit breakers and bounded retries with jitter. Include recovery testing; a retry is safe only when the operation is idempotent or the request has a deduplication key.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
