# Lời giải mẫu G02.01 — bytes, str và encoding

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết hàm nhận bytes UTF-8 và trả về str, xử lý dữ liệu không hợp lệ bằng ngoại lệ rõ.

## Code lời giải

```python
def text_utf8(data: bytes)->str:
    return data.decode('utf-8',errors='strict')
assert text_utf8('á'.encode())=='á'
try:text_utf8(bytes([255]))
except UnicodeDecodeError:pass
else:raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** UTF-8 decode có thể thất bại nếu chuỗi byte bị hỏng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
