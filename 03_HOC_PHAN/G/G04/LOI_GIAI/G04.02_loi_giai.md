# Lời giải bài tập vận dụng — G04.02 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Viết hàm atomic_write_text dùng tempfile.NamedTemporaryFile cùng thư mục và dọn tệp khi lỗi.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
import os,tempfile
from pathlib import Path
from tempfile import TemporaryDirectory
def atomic_write_text(path: Path, text: str):
    tmp=None
    try:
        with tempfile.NamedTemporaryFile(mode='w', encoding='utf-8', dir=path.parent,delete=False) as f:
            tmp=Path(f.name);f.write(text);f.flush();os.fsync(f.fileno())
        os.replace(tmp,path)
    finally:
        if tmp is not None and tmp.exists(): tmp.unlink()
with TemporaryDirectory() as t:
    p=Path(t)/'record.txt'
    atomic_write_text(p,'á');assert p.read_text(encoding='utf-8')=='á'
    atomic_write_text(p,'b');assert p.read_text()=='b'
    assert len(list(Path(t).iterdir()))==1
print('PASS G04.02')
```
