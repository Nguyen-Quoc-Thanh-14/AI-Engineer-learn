# Lời giải vận dụng — G03.01

**Đề bài B:** Đọc CSV có dấu phẩy trong chuỗi và kiểm tra số cột trước khi chuyển kiểu.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
import csv, io

def parse_rows(text):
    reader=csv.reader(io.StringIO(text))
    headers=next(reader)
    if headers != ['name','age']: raise ValueError('invalid header')
    result=[]
    for row in reader:
        if len(row)!=2: raise ValueError('invalid column count')
        result.append((row[0],int(row[1])))
    return result
assert parse_rows('name,age\n"Nguyễn, A",19\n')==[('Nguyễn, A',19)]
assert parse_rows('name,age\n')==[]
try: parse_rows('name,age\nA,22,EXTRA\n')
except ValueError: pass
else: raise AssertionError('invalid CSV accepted')
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
