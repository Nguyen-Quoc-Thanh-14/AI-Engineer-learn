# G05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Đọc file UTF-8 chứa dấu tiếng Việt trên Windows/Linux và kiểm tra byte roundtrip.

**Mã chạy riêng:** [G05.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/G05.01_bai_B_solution.py)

```python
from pathlib import Path
from tempfile import TemporaryDirectory
text='Tiếng Việt: Đà Nẵng 🌱'
with TemporaryDirectory() as tmp:
    p=Path(tmp)/'content.txt'; p.write_text(text,encoding='utf-8')
    assert p.read_bytes()==text.encode('utf-8')
    assert p.read_text(encoding='utf-8')==text
# Always specify encoding explicitly for portable file interchange.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.

**Trạng thái:** Chờ kết quả kiểm thử trong `31_HOAN_THIEN_LOI_GIAI_V28/ket_qua_kiem_thu_loi_giai.json`; không suy đoán Python 3.15.2.
