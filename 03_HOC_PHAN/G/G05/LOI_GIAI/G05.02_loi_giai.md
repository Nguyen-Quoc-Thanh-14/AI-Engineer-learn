# G05.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Giải thích vì sao `len("🇻🇳")` không bằng số lá cờ hiển thị.

**Mã chạy riêng:** [G05.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/G05.02_bai_B_solution.py)

```python
import unicodedata
flag='🇻🇳'
assert len(flag)==2 # two regional-indicator Unicode code points; one visual flag grapheme
precomposed='café'; decomposed='cafe\u0301'
assert precomposed!=decomposed
assert unicodedata.normalize('NFC',precomposed)==unicodedata.normalize('NFC',decomposed)
# Python str and len() do not automatically segment grapheme clusters.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
