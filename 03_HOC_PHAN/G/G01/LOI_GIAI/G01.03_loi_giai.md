# Lời giải vận dụng — G01.03

**Đề bài B:** Tạo hàm chỉ đọc file đuôi `.txt` trong thư mục tạm, tránh đi ra ngoài root.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
from pathlib import Path
from tempfile import TemporaryDirectory

def read_txt(root: Path, relative: str) -> str:
    root = root.resolve()
    file = (root / relative).resolve()
    if not file.is_relative_to(root) or file.suffix.lower() != '.txt':
        raise ValueError('invalid path or extension')
    return file.read_text(encoding='utf-8')
with TemporaryDirectory() as d:
    root=Path(d); (root/'hello.txt').write_text('xin chào',encoding='utf-8')
    assert read_txt(root,'hello.txt')=='xin chào'
    for bad in ('../secret.txt','hello.exe'):
        try: read_txt(root,bad)
        except ValueError: pass
        else: raise AssertionError('bad path permitted')
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
