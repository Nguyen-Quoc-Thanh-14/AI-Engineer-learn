# Lời giải độc lập có kiểm thử — G01.01 (v2.5)

> **Trạng thái:** ĐÃ GIẢI BÀI TẬP ỨNG DỤNG TƯƠNG ỨNG VÀ CHẠY THÀNH CÔNG TRÊN PYTHON 3.13.5. Không thay thế kiểm thử thư viện/CPython 3.15.2 hoặc phản biện chuyên gia.

## 1. Khái niệm và hợp đồng

Mở tệp qua context manager đảm bảo đóng tài nguyên ngay cả khi có ngoại lệ; encoding là phần hợp đồng của file văn bản, không nên phụ thuộc hệ điều hành.

## 2. Lập luận trước khi viết mã

Sử dụng Path và open(encoding="utf-8") để ghi và đọc. Tách hàm ghi/đọc làm hai bước cho phép kiểm thử riêng; pathlib.Path thực hiện ánh xạ đường dẫn mà không tự tạo các thư mục cha.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/G01.01_bai_tap_da_giai_v25.py`](../MA_MAU/G01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/G01.01_bai_tap_da_giai_v25.py
```

```python
from pathlib import Path
from tempfile import TemporaryDirectory

def write_text_file(path: Path, lines: list[str]) -> None:
    if not all(isinstance(x, str) for x in lines):
        raise TypeError('mỗi dòng phải là str')
    with Path(path).open('w', encoding='utf-8', newline='') as f:
        f.write(''.join(lines))

def read_text_file(path: Path) -> str:
    with Path(path).open('r', encoding='utf-8') as f:
        return f.read()

def check():
    with TemporaryDirectory() as tmp:
        dest = Path(tmp) / 'notes.txt'
        write_text_file(dest, ['Xin chào\n', 'Python!'])
        assert read_text_file(dest) == 'Xin chào\nPython!'
        write_text_file(dest, [])
        assert read_text_file(dest) == ''
        try: write_text_file(dest, [42])
        except TypeError: pass
        else: raise AssertionError('sai kiểu')

if __name__ == '__main__':
    check()
    print('OK G01.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không dùng `open(..., "w")` trên đường dẫn chưa kiểm tra trong hệ thống quan trọng: chế độ w sẽ cắt dữ liệu cũ. Khi ghi dữ liệu cần tính atomicity, hãy cân nhắc ghi tệp tạm và os.replace.

**Bài mở rộng chưa có đáp án:** Viết bản atomic write bằng NamedTemporaryFile cùng thư mục đích; kiểm thử việc thay nội dung khi một bước ghi có lỗi.
