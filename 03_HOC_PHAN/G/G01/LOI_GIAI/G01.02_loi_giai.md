# Lời giải mẫu G01.02 — with và context manager nhập môn

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết hàm chỉ nhận tên tệp không có đường dẫn và kiểm thử `../secret` bị từ chối.

## Code lời giải

```python
from pathlib import Path
def safe_name(s):
    p=Path(s)
    if p.name!=s or s in ('','.','..') : raise ValueError('invalid')
    return s
assert safe_name('abc.txt')=='abc.txt'
try:safe_name('../secret')
except ValueError:pass
else:raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Path.resolve() có thể phát sinh lỗi với môi trường hoặc đường dẫn không tồn tại.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
