# Lời giải vận dụng — I03.01

**Đề bài B:** Xây FIFO task processor dùng deque và kiểm thử queue rỗng.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
from collections import deque
class FIFO:
    def __init__(self): self._q=deque()
    def enqueue(self, task): self._q.append(task)
    def process(self):
        if not self._q: raise IndexError('empty queue')
        task=self._q.popleft()
        return task()
q=FIFO(); q.enqueue(lambda: 'one'); q.enqueue(lambda:'two')
assert q.process()=='one'
assert q.process()=='two'
try: q.process()
except IndexError: pass
else: raise AssertionError('empty queue not rejected')
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
