## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Benchmark truy cập index ngẫu nhiên và popleft trên dữ liệu nhỏ/lớn; giải thích sai số.

**Mã chạy riêng:** [I03.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/I03.03_bai_B_solution.py)

```python
from collections import deque
import random,time,statistics
rng=random.Random(9)
for n in (100,10000):
    data=list(range(n));q=deque(data)
    ix=[rng.randrange(n) for _ in range(100)]
    assert [data[i] for i in ix]==[q[i] for i in ix]
    assert list(deque(data))==data
    # Semantics: deque.popleft is O(1); list.pop(0) is O(n) shifting elements.
    assert q.popleft()==0 and data.pop(0)==0
# Benchmarks require warmup/repetitions; asymptotic performance is not a fixed timing ratio.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
