# Lời giải vận dụng — I04.03

**Đề bài B:** Xây scheduler ưu tiên với tie-break counter để tránh so sánh task object.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
import heapq, itertools
class Task:
    def __init__(self,name): self.name=name
class Scheduler:
    def __init__(self): self.heap=[]; self.counter=itertools.count()
    def add(self, priority, task): heapq.heappush(self.heap,(priority,next(self.counter),task))
    def pop(self): return heapq.heappop(self.heap)[2]
s=Scheduler(); s.add(2,Task('later'));s.add(1,Task('first'));s.add(1,Task('second'))
assert [s.pop().name for _ in range(3)]==['first','second','later']
assert not s.heap
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
