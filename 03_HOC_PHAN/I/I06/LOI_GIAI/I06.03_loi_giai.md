# Lời giải vận dụng — I06.03

**Đề bài B:** Viết tabulation Fibonacci O(1) auxiliary space và so sánh với memoization.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
from functools import lru_cache

def fib_tab(n):
    if n<0: raise ValueError('n must be nonnegative')
    a,b=0,1
    for _ in range(n): a,b=b,a+b
    return a
@lru_cache(None)
def fib_memo(n):
    if n<0: raise ValueError('n must be nonnegative')
    return n if n<2 else fib_memo(n-1)+fib_memo(n-2)
assert [fib_tab(i) for i in range(12)]==[fib_memo(i) for i in range(12)]
assert fib_tab(0)==0 and fib_tab(1)==1
try: fib_tab(-1)
except ValueError:pass
else:raise AssertionError()
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
