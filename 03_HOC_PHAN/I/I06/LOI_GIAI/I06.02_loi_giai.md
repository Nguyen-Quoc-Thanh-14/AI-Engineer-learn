# I06.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết backtracking tìm tập coins tối ưu và so sánh với greedy ở 6.

**Mã chạy riêng:** [I06.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/I06.02_bai_B_solution.py)

```python
def greedy(amount, coins=(1,3,4)):
    picked=[]
    for coin in sorted(coins,reverse=True):
        n,amount=divmod(amount,coin);picked.extend([coin]*n)
    return picked

def exact(amount, coins=(1,3,4)):
    if amount<0: raise ValueError('amount')
    best=[None]*(amount+1);best[0]=[]
    for target in range(1,amount+1):
        choices=[best[target-c]+[c] for c in coins if c<=target and best[target-c] is not None]
        best[target]=min(choices,key=len) if choices else None
    return best[amount]
assert len(greedy(6))==3 and len(exact(6))==2
assert exact(0)==[] and exact(7) is not None
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
