# Lời giải vận dụng — I05.03

**Đề bài B:** Thêm node unreachable và trả về None thay vì infinity nếu không có đường.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
import heapq, math

def shortest(graph,start,target):
    heap=[(0,start)];best={start:0}
    while heap:
        cost,node=heapq.heappop(heap)
        if cost!=best[node]: continue
        if node==target: return cost
        for nxt,w in graph.get(node,[]):
            if w<0: raise ValueError('negative edge')
            nc=cost+w
            if nc<best.get(nxt,math.inf):
                best[nxt]=nc;heapq.heappush(heap,(nc,nxt))
    return None
g={'A':[('B',2)],'B':[('C',3)],'C':[]}
assert shortest(g,'A','C')==5
assert shortest(g,'A','X') is None
assert shortest(g,'A','A')==0
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
