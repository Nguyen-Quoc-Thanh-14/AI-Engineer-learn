# Lời giải mẫu I01.02 — Time-space tradeoff

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Giải thích 2 trường hợp nên dùng list, 2 trường hợp nên dùng set khi kiểm tra membership.

## Code lời giải

```python
data=[1,2,3]
lookup=set(data)
assert 2 in lookup
assert 9 not in lookup
assert len(lookup)==len(data)
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Nếu cần nhiều lần tìm kiếm trong cùng tập giá trị, chuyển từ list sang set một lần thường có lợi. Nếu chỉ tìm một lần trên vài phần tử, chi phí tạo set có thể lớn hơn lợi ích. Luôn giữ nguyên ý nghĩa dữ liệu: set bỏ trùng và không giữ thứ tự theo giao diện sequence.

**Giới hạn:** Các giá trị unhashable như list không thể đưa trực tiếp vào set.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
