# Lời giải mẫu I01.03 — Amortized analysis nhập môn

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Chứng minh vì sao tổng chi phí sao chép theo chiến lược nhân đôi là O(n).

## Code lời giải

```python
def copied(n):
    c=1;total=0
    for i in range(n):
        if i==c:total+=i;c*=2
    return total
for n in range(1,100):assert copied(n)<2*n
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xét chiến lược nhân đôi dung lượng: các lần sao chép xảy ra ở kích thước 1,2,4,... Tổng số phần tử từng sao chép nhỏ hơn khoảng 2n cho n lần chèn; do đó tổng O(n), trung bình O(1). Đây là phân tích mô hình, không phải lời hứa về số lần realloc cụ thể của CPython.

**Giới hạn:** Chiến lược thực tế của list CPython khác mô hình nhân đôi đơn giản.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
