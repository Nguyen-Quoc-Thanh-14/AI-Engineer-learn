## 1. Khái niệm và hợp đồng

Tìm kiếm nhị phân có tiền điều kiện là dãy đã sắp xếp theo khóa. Mỗi vòng lặp thu hẹp khoảng nửa mở [lo, hi), duy trì bất biến rằng nếu giá trị xuất hiện thì vị trí đầu tiên có thể nằm trong khoảng đang xét.

## 2. Lập luận trước khi viết mã

Phiên bản lower_bound trả về chỉ số đầu tiên có phần tử >= target; kiểm tra bằng == để trả -1 khi không tìm thấy. Cần phân biệt vị trí đầu tiên với bất kỳ vị trí nào nếu danh sách có phần tử trùng.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/I02.01_bai_tap_da_giai_v25.py`](../MA_MAU/I02.01_bai_tap_da_giai_v25.py). Có thể chạy:

python ../MA_MAU/I02.01_bai_tap_da_giai_v25.py

```python
def first_index(sorted_values: list[int], target: int) -> int:
    lo, hi = 0, len(sorted_values)
    while lo < hi:
        mid = (lo + hi) // 2
        if sorted_values[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    if lo < len(sorted_values) and sorted_values[lo] == target:
        return lo
    return -1

def check():
    assert first_index([1, 2, 2, 3], 2) == 1
    assert first_index([], 1) == -1
    assert first_index([1, 3, 5], 4) == -1
    assert first_index([-2, 0, 0], -2) == 0
    for nums in ([], [1], [1,1,1], [-3,-1,0,7], list(range(30))):
        for v in range(-4, 32):
            want = nums.index(v) if v in nums else -1
            assert first_index(nums, v) == want

if __name__ == '__main__':
    check()
    print('OK I02.01')
```

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không áp dụng binary search cho dãy chưa sắp xếp; chương trình có thể chạy mà trả kết quả sai. Điều kiện sorted là tiền điều kiện, không thể suy ra từ kiểu list.

**Bài mở rộng chưa có đáp án:** Viết chứng minh bất biến với bộ ba initialization–maintenance–termination; sau đó tự tạo 100 dãy sorted và so với list.index khi tìm thấy.
