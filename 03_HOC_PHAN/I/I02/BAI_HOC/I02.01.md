## 2. Khái niệm — Bản chất

Binary search đúng nếu dữ liệu có thứ tự sắp xếp phù hợp. Với mỗi lượt, tìm phần tử giữa và thu hẹp nửa khoảng có thể chứa mục tiêu; chạy O(log n) so với O(n) của linear search ở trường hợp xấu.

## 3. Nguyên lý và cơ chế từng bước

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

## 4. Ví dụ tối thiểu có thể chạy

```python
def tim(ds,x):
    lo,hi=0,len(ds)
    while lo<hi:
        mid=(lo+hi)//2
        if ds[mid]<x:lo=mid+1
        else:hi=mid
    return lo if lo<len(ds) and ds[lo]==x else -1
assert tim([1,3,5,7],5)==2
assert tim([1,3,5,7],4)==-1
```

## 5. Trường hợp biên, lỗi thường gặp và hướng debug

- **Ngộ nhận:** Binary search trên list chưa sorted có thể trả kết quả sai mà không phát sinh ngoại lệ.
- **Trường hợp biên:** Dữ liệu có trùng giá trị cần làm rõ muốn trả vị trí nào.
- **Debug có phương pháp:** xác định hợp đồng → tái hiện lỗi bằng đầu vào tối thiểu → đọc traceback/kiểm tra trạng thái → sửa → thêm regression test.
