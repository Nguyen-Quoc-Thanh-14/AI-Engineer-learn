# Lời giải bài tập vận dụng — I07.02 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Thêm union by size và test component count sau các phép gộp.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
class DSU:
    def __init__(self,n):self.parent=list(range(n));self.size=[1]*n;self.count=n
    def root(self,x):
        while self.parent[x]!=x:
            self.parent[x]=self.parent[self.parent[x]];x=self.parent[x]
        return x
    def union(self,a,b):
        a,b=self.root(a),self.root(b)
        if a==b:return False
        if self.size[a]<self.size[b]:a,b=b,a
        self.parent[b]=a;self.size[a]+=self.size[b];self.count-=1
        return True
d=DSU(4);assert d.count==4
assert d.union(0,1) and d.union(1,2) and d.count==2
assert not d.union(0,2) and d.count==2
print('PASS I07.02')
```
