## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo reliability diagram và nhóm samples theo confidence bins.

**Mã chạy riêng:** [PM02.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PM02.03_bai_B_solution.py)

```python
import numpy as np
from sklearn.calibration import calibration_curve
prob=np.array([.1,.2,.3,.7,.8,.9]);y=np.array([0,0,1,0,1,1])
truth,confidence=calibration_curve(y,prob,n_bins=3,strategy='uniform')
assert len(truth)==len(confidence) and np.all((0<=confidence)&(confidence<=1))
# Reliability diagram requires plotting truth against confidence and adequate bin support.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
