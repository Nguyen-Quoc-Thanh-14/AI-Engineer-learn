# Lời giải bài tập vận dụng — PM04.01 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Dùng ColumnTransformer impute missing rồi one-hot encode categorical feature.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
import numpy as np
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder
X=np.array([['red',1.0],['blue',np.nan],['red',3.0]],dtype=object)
pre=ColumnTransformer([
 ('category',OneHotEncoder(handle_unknown='ignore'),[0]),
 ('number',SimpleImputer(strategy='median'),[1])])
Z=pre.fit_transform(X)
assert Z.shape==(3,3)
assert np.isfinite(Z.astype(float)).all()
assert pre.transform(np.array([['other',np.nan]],dtype=object)).shape==(1,3)
print('PASS PM04.01')
```
