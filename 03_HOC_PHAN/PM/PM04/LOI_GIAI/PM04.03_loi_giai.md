# PM04.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế monitoring dashboard latency p95, missing feature và accuracy delayed labels.

Model-serving dashboard contract: `model_version`, `request_id`, p50/p95 inference latency, 5xx rate, missing-feature rate, input feature drift (PSI or other with stated bins), delayed-label performance and data consent status. Separate real-time unlabeled drift signals from true accuracy measured **after** labels arrive; avoid calling drift a measured accuracy drop. Alert if p95 exceeds documented SLO for 3 windows; on failure promote prior signed artifact and record incident. Backfill labels with explicit join keys and timestamp cutoff.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
