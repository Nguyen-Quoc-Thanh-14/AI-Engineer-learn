## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo manifest thí nghiệm với SHA-256 dataset và Python/package versions.

**Mã chạy riêng:** [PM04.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PM04.02_bai_B_solution.py)

```python
from hashlib import sha256
import platform,json
import importlib.metadata as metadata
sample=b'feature,label\n1,0\n2,1\n'
manifest={'data_sha256':sha256(sample).hexdigest(),'python':platform.python_version(),
          'numpy':metadata.version('numpy'),'sklearn':metadata.version('scikit-learn'),'seed':42}
assert len(manifest['data_sha256'])==64 and manifest['seed']==42
print(json.dumps(manifest,sort_keys=True))
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.

**Trạng thái:** Chờ kết quả kiểm thử trong `31_HOAN_THIEN_LOI_GIAI_V28/ket_qua_kiem_thu_loi_giai.json`; không suy đoán Python 3.15.2.
