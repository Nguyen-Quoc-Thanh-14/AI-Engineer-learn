## 1. Khái niệm và hợp đồng

Chia dữ liệu phải dựa vào đơn vị độc lập phù hợp: nếu các bản ghi của cùng một người rơi vào train và test, mô hình có thể học thông tin về người đó thay vì tổng quát hóa.

## 2. Lập luận trước khi viết mã

Dùng user ID làm đơn vị phân chia; sắp xếp groups và shuffle bằng Random(seed) để tái lập. Chia ba tập train/validation/test theo nhóm, không theo record; kiểm tra giao nhau của tập user IDs sau khi chia. Với dữ liệu thời gian, chiến lược split sẽ khác.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PM01.02_bai_tap_da_giai_v25.py`](../MA_MAU/PM01.02_bai_tap_da_giai_v25.py). Có thể chạy:

```python
from random import Random

def split_users(records: list[tuple[str, float]], seed: int = 42):
    if not isinstance(records, list):
        raise TypeError('records phải là list')
    users = sorted({user for user, _ in records})
    if len(users) < 3:
        raise ValueError('cần ít nhất 3 user độc lập')
    Random(seed).shuffle(users)
    train_n = max(1, len(users) * 6 // 10)
    validation_n = max(1, (len(users) - train_n) // 2)
    train_users = set(users[:train_n])
    validation_users = set(users[train_n:train_n+validation_n])
    test_users = set(users[train_n+validation_n:])
    return tuple(
        [row for row in records if row[0] in group]
        for group in (train_users, validation_users, test_users)
    )

def check():
    records = [(f'u{i}', float(i+j)) for i in range(10) for j in range(2)]
    a,b,c = split_users(records)
    users = [{x[0] for x in group} for group in (a,b,c)]
    assert all(users) and not (users[0] & users[1] | users[0] & users[2] | users[1] & users[2])
    assert len(a) + len(b) + len(c) == len(records)
    assert split_users(records) == (a,b,c)
    try: split_users([('u1',1.0)])
    except ValueError: pass
    else: raise AssertionError('ít group')

if __name__ == '__main__':
    check()
    print('OK PM01.02')
```

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không chia ngẫu nhiên từng record trước rồi chỉ kiểm tra tỷ lệ 80/20; điều đó không chứng minh độc lập theo nhóm. Không fit preprocessing trên toàn bộ dữ liệu trước khi chia.

**Bài mở rộng chưa có đáp án:** Dùng scikit-learn GroupShuffleSplit/GroupKFold khi có thư viện; thảo luận vì sao time series cần TimeSeriesSplit hoặc split theo thời gian.
