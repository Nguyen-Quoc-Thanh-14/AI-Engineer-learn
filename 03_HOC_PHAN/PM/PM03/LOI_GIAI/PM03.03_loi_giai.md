# Lời giải bài tập vận dụng — PM03.03 (v2.7)

**Đề bài B (từ bản gốc v2.6):** So một classifier thật với DummyClassifier baseline trên cùng split.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
X,y=make_classification(n_samples=120,n_features=5,n_redundant=0,random_state=9)
Xtr,Xte,ytr,yte=train_test_split(X,y,random_state=7,stratify=y)
scores=[m.fit(Xtr,ytr).score(Xte,yte) for m in (DummyClassifier(strategy='most_frequent'),LogisticRegression(max_iter=500))]
assert len(scores)==2
assert all(0<=s<=1 for s in scores)
assert scores[1]>=scores[0]  # chỉ xác minh trên dữ liệu mô phỏng đã cố định seed
print('PASS PM03.03')
```
