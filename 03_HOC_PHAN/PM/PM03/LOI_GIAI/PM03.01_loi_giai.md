## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** So explained_variance_ratio và reconstruction error với 1 vs 2 components.

**Mã chạy riêng:** [PM03.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PM03.01_bai_B_solution.py)

```python
import numpy as np
from sklearn.decomposition import PCA
x=np.array([[0.,1.],[1.,2.],[2.,2.],[3.,4.],[4.,4.]])
for k in (1,2):
    pca=PCA(n_components=k).fit(x)
    z=pca.transform(x);approx=pca.inverse_transform(z)
    error=np.mean((x-approx)**2)
    assert 0<=pca.explained_variance_ratio_.sum()<=1.000001
    if k==1:e1=error
    else:assert error<e1+1e-10
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
