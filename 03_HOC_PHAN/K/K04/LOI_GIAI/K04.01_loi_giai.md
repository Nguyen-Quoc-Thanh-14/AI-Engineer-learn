## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thực thi NumPy x*x trên 1 triệu float, kiểm allclose và peak memory với loop.

**Mã chạy riêng:** [K04.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/K04.01_bai_B_solution.py)

```python
import numpy as np,time,tracemalloc
x=np.arange(1_000_000,dtype=np.float64)
vector=x*x
loop=np.array([v*v for v in x])
assert np.allclose(vector,loop)
# Timing and memory profile must be measured separately with repeat samples.
assert vector.nbytes==8_000_000
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
