# K04.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Benchmark pure Python vs Numba after warmup vs NumPy, tách compilation cost.

**Benchmark design:** implement a pure Python loop and equivalent `numpy` operation over one million integers; use `numba.njit` only if installed. Warm up the JIT before steady-state measurement; report initial compile+run separately. Validate outputs elementwise, measure RSS/peak bytes and repeated per-call medians. Do not claim a speedup before controlling data types, overflow semantics and warmup costs.
**Status:** design is reproducible; independent performance results depend on CPU, package versions and compilation settings.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
