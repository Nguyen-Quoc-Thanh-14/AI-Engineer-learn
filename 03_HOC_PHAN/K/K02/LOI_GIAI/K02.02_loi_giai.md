# K02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Chụp snapshot trước/sau tạo list, quan sát top allocation lines và dọn tham chiếu.

**Mã chạy riêng:** [K02.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/K02.02_bai_B_solution.py)

```python
import tracemalloc,gc
tracemalloc.start()
before=tracemalloc.take_snapshot()
a=[str(x) for x in range(10000)]
after=tracemalloc.take_snapshot()
changes=after.compare_to(before,'lineno')
assert changes and sum(x.size_diff for x in changes)>0
del a;gc.collect();tracemalloc.stop()
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.

**Trạng thái:** Chờ kết quả kiểm thử trong `31_HOAN_THIEN_LOI_GIAI_V28/ket_qua_kiem_thu_loi_giai.json`; không suy đoán Python 3.15.2.
