# K02.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** So sánh memory per element giữa `array.array` và `list` theo 1000 phần tử.

**Mã chạy riêng:** [K02.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/K02.03_bai_B_solution.py)

```python
from array import array
import sys
values=list(range(1000));compact=array('i',values)
assert list(compact)==values
assert sys.getsizeof(compact)<sys.getsizeof(values)
# Shallow getsizeof excludes referenced PyLong objects in list; note this explicitly in report.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.

**Trạng thái:** Chờ kết quả kiểm thử trong `31_HOAN_THIEN_LOI_GIAI_V28/ket_qua_kiem_thu_loi_giai.json`; không suy đoán Python 3.15.2.
