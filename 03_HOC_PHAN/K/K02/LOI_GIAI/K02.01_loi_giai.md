# Lời giải vận dụng — K02.01

**Đề bài B:** Chứng minh cách dùng set giảm chi phí membership so với nested list scan với dữ liệu lớn.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
# Đo độc lập bằng timeit; không sử dụng ngưỡng tốc độ tuyệt đối vì phụ thuộc máy.
from timeit import repeat
n=2000
values=list(range(n)); queries=list(range(n,2*n))
def scan(): return sum(q in values for q in queries)
def hashed():
    index=set(values)
    return sum(q in index for q in queries)
assert scan()==hashed()==0
list_times=repeat(scan,number=1,repeat=3)
set_times=repeat(hashed,number=1,repeat=3)
assert min(list_times)>0 and min(set_times)>0
# Big-O: repeated list membership O(n*m), building set + lookup O(n+m) trung bình.
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
