# Lời giải mẫu K01.02 — timeit, cProfile và sampling profiler

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tự profile một hàm lọc và sort 10.000 số; giải thích hai hotspot.

## Code lời giải

```python
import cProfile
p=cProfile.Profile();p.enable()
sorted(range(1000),reverse=True)
p.disable()
assert p is not None
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Ví dụ dùng `cProfile.Profile()` có sẵn trên Python 3.13. Đọc `stats` theo cumulative time thay vì chỉ xem một call nhanh/đắt. Kết quả phụ thuộc workload; phải ghi phiên bản runtime.

**Giới hạn:** Sampling có thể bỏ qua các call rất ngắn; profiler mới trên 3.15 cần tài liệu phiên bản.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
