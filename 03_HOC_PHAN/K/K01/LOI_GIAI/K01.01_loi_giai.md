## 1. Khái niệm và hợp đồng

Benchmark chỉ cung cấp bằng chứng về một khối lượng công việc trong một môi trường đo cụ thể. Kết quả thời gian không phải định luật phổ quát; cần có baseline, kiểm tra tính đúng và nhiều lượt đo.

## 2. Lập luận trước khi viết mã

Dùng timeit.repeat với number và repeat cố định, báo cáo các phép đo riêng và giá trị tối thiểu, không đặt assertion cứng rằng cách A luôn nhanh hơn cách B. Nên ghi Python version, CPU, dữ liệu và môi trường.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/K01.01_bai_tap_da_giai_v25.py`](../MA_MAU/K01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/K01.01_bai_tap_da_giai_v25.py
```

```python
from timeit import repeat

def squares_loop(n):
    result = []
    for x in range(n):
        result.append(x * x)
    return result

def squares_comprehension(n):
    return [x * x for x in range(n)]

def measure(stmt):
    samples = repeat(stmt, number=100, repeat=3)
    assert len(samples) == 3 and min(samples) >= 0
    return min(samples), samples

def check():
    for n in (0, 1, 100):
        assert squares_loop(n) == squares_comprehension(n)
    baseline, samples = measure(lambda: squares_loop(100))
    assert baseline >= 0 and len(samples) == 3

if __name__ == '__main__':
    check()
    print('OK K01.01 (không kết luận thuật toán nào nhanh hơn nếu chưa đo)')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Tránh dùng time.time để đo những đoạn quá ngắn một lần; độ nhiễu hệ thống có thể lớn hơn thời gian chương trình.

**Bài mở rộng chưa có đáp án:** Đo list comprehension và vòng for cho dãy dài 10, 1000, 100000 phần tử; ghi lại đường xu hướng và thảo luận O(n).
