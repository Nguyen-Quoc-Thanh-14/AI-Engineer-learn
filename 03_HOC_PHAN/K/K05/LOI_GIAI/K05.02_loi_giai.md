# K05.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Trên Python 3.15 chạy Tachyon sampling 3 phiên và so phân bố hotspots.

**Python 3.15 only:** collect three Tachyon `profiling.sampling` runs of the same CPU workload, record sampling rate/CPU load and top hotspots, compare ranked function names and note discrepancies. Separate wall-clock profiling from Python call profiling; a sampled stack is a statistical estimate, not an exact instruction count.
**Status:** requires Python 3.15.2 profiler, not validated in current runtime.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
