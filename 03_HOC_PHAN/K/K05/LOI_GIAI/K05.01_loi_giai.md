# K05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Chạy profiling.tracing trên Python 3.15 và so call counts với cProfile ở cùng workload.

**Python 3.15 only:** run the built-in `profiling.tracing` interface using documented 3.15 CLI/API examples and compare observed hot call sites with `cProfile` on an unchanged workload. Record sampling/tracing overhead and distinct measurement semantics. Do not invent exact API calls based on older versions. Use a fixed dataset, five repetitions and publish code, interpreter flags and profiler output.
**Status:** not run because CPython 3.15.2 is absent.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
