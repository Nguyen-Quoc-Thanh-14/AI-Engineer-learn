# K05.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết benchmark report kèm median, IQR và phân tích outlier.

**Mã chạy riêng:** [K05.04_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/K05.04_bai_B_solution.py)

```python
import statistics
xs=[1.0,1.1,1.2,1.3,1.4,1.5,1.1,1.0,1.2,9.0]
quartiles=statistics.quantiles(xs,n=4,method='inclusive')
iqr=quartiles[2]-quartiles[0];median=statistics.median(xs)
assert iqr>0 and median<2
outliers=[x for x in xs if x>quartiles[2]+1.5*iqr]
assert outliers==[9.0]
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
