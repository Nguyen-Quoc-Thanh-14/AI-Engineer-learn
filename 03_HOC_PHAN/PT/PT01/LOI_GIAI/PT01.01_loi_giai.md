# Lời giải mẫu PT01.01 — Vector và ma trận

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Nhân ma trận không vuông (2x3) với vector dài 3, kiểm tra chiều đầu ra.

## Code lời giải

```python
import numpy as np
A=np.array([[1,0,2],[0,1,3]])
assert (A@np.array([2,3,4])).tolist()==[10,15]
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Với mảng 2x2 và vector dài 2, `A @ x` áp dụng biến đổi tuyến tính; kiểm tra thủ công phép nhân từng hàng.

**Giới hạn:** Đầu vào không đúng kích thước gây lỗi shape; vector 1D khác vector cột 2D.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
