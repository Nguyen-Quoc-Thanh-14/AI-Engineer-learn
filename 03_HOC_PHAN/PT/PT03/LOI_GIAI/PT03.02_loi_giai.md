## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Triển khai gradient descent f(x)=(x-2)^2 và vẽ loss curve.

**Mã chạy riêng:** [PT03.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PT03.02_bai_B_solution.py)

```python
def gradient_descent(x=0.,rate=.1,steps=60):
    history=[]
    for _ in range(steps):
        loss=(x-2)**2;history.append(loss)
        x-=rate*2*(x-2)
    return x,history
x,loss=gradient_descent()
assert abs(x-2)<1e-5 and loss[-1]<loss[0]
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
