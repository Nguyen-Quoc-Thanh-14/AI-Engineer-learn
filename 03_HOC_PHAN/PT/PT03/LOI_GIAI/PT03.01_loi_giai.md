## 1. Khái niệm và hợp đồng

Đạo hàm mô tả tốc độ biến thiên cục bộ; gradient là vector các đạo hàm riêng. Chain rule giải thích vì sao lớp cuối của neural network có thể truyền gradient về các tham số phía trước.

## 2. Lập luận trước khi viết mã

Dùng sai phân trung tâm [f(x+h)-f(x-h)]/(2h) để xấp xỉ đạo hàm của x²; so sánh với 2x. Dùng h vừa đủ và isclose, không so sánh float tuyệt đối == giữa hai cách tính.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PT03.01_bai_tap_da_giai_v25.py`](../MA_MAU/PT03.01_bai_tap_da_giai_v25.py). Có thể chạy:

```python
import math

def central_difference(f, x: float, step: float = 1e-5) -> float:
    if not (step > 0 and math.isfinite(step)):
        raise ValueError('step phải dương và hữu hạn')
    return (f(x+step)-f(x-step))/(2*step)

def check():
    for x in (-2.0, 0.0, 3.0):
        assert math.isclose(central_difference(lambda v: v*v, x), 2*x, abs_tol=1e-9)
    try: central_difference(lambda x: x*x, 1.0, 0)
    except ValueError: pass
    else: raise AssertionError('step 0')
    assert math.isclose(central_difference(lambda x: (x+2)**2, 1), 6.0, abs_tol=1e-9)

if __name__ == '__main__':
    check()
    print('OK PT03.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không giảm h đến 0 một cách mù quáng: sai số làm tròn tăng mạnh khi hiệu hai giá trị gần nhau bị triệt tiêu.

**Bài mở rộng chưa có đáp án:** Tự dẫn xuất gradient của f(x,y)=(x+y)²; dùng sai phân theo từng biến và so với đạo hàm tay.
