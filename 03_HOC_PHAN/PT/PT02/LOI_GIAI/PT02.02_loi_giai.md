# PT02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế thử nghiệm A/B và giải thích confidence interval effect size.

A/B experiment: randomize consented users into A/B, predefine primary metric (e.g. successful task rate), minimum sample, horizon and statistical test; avoid peeking/stopping for significance without correction. Report effect size `p_B-p_A`, 95% confidence interval, subgroup limitations and uncertainty. Example: A 50/100 successes vs B 60/100 has point effect +10 percentage points; a single outcome difference is **not proof** of causality without randomization/bias checks. No real test was run here.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
