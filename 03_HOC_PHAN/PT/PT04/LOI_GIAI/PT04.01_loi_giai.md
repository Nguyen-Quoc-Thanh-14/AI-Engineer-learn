## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết định nghĩa forall/exists với list comprehension và chứng minh trên tập rỗng.

**Mã chạy riêng:** [PT04.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PT04.01_bai_B_solution.py)

```python
# On empty domain: forall(P) is True; exists(P) is False.
xs=[]
assert all(x>0 for x in xs) is True
assert any(x>0 for x in xs) is False
xs=[1,2,3]
assert all(x>0 for x in xs)
assert any(x==2 for x in xs)
assert not any(x<0 for x in xs)
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
