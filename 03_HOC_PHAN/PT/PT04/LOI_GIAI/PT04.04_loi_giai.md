## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thử giải linear system gần suy biến, báo condition number và residual.

**Mã chạy riêng:** [PT04.04_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PT04.04_bai_B_solution.py)

```python
import numpy as np
A=np.array([[1.,1.],[1.,1.+1e-8]])
b=np.array([2.,2.+1e-8])
x=np.linalg.solve(A,b)
assert np.linalg.norm(A@x-b)<1e-8
assert np.linalg.cond(A)>1e7
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
