## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Chứng minh n(n+1)/2 bằng quy nạp và liên hệ invariant sum loop.

**Mã chạy riêng:** [PT04.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PT04.02_bai_B_solution.py)

```python
def triangle(n):
    if n<0:raise ValueError('n')
    total=0
    for i in range(1,n+1):
        assert total==(i-1)*i//2  # loop invariant
        total+=i
    assert total==n*(n+1)//2
    return total
for n in range(100):assert triangle(n)==sum(range(n+1))
# Induction: base n=0; adding n+1 transforms n(n+1)/2 into (n+1)(n+2)/2.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
