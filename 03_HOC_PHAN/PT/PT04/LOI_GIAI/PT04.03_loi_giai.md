## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Đếm số tập con của n phần tử và chứng minh chi phí 2^n.

**Mã chạy riêng:** [PT04.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PT04.03_bai_B_solution.py)

```python
from itertools import combinations
for n in range(9):
    universe=tuple(range(n))
    subsets=[combo for r in range(n+1) for combo in combinations(universe,r)]
    assert len(subsets)==2**n
# Complexity O(2^n * n) if materializing subsets; cardinality is exactly 2^n.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
