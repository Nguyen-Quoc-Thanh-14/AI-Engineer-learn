## 1. Khái niệm và hợp đồng

Chương trình là chuỗi thao tác có thứ tự; phép tính chạy được chưa có nghĩa đầu vào hợp lệ về mặt nghiệp vụ.

## 2. Lập luận trước khi viết mã

Đầu tiên xác lập hợp đồng: giá và số lượng là số nguyên không âm; loại trừ bool vì bool cũng là int trong Python. Sau đó tính thành tiền từ hai biến đã qua xác thực. Thử thêm trường hợp 0 và dữ liệu âm để phân biệt logic với lỗi cú pháp.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/A01.01_bai_tap_da_giai_v25.py`](../MA_MAU/A01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/A01.01_bai_tap_da_giai_v25.py
```

```python
def line_total(unit_price: int, quantity: int) -> int:
    """Trả tổng tiền cho số nguyên không âm, không có tác dụng phụ."""
    for value in (unit_price, quantity):
        if type(value) is not int:
            raise TypeError("unit_price và quantity phải là int")
        if value < 0:
            raise ValueError("không được âm")
    return unit_price * quantity


def check():
    assert line_total(12, 3) == 36
    assert line_total(9, 0) == 0
    try:
        line_total(-2, 5)
    except ValueError:
        pass
    else:
        raise AssertionError("không chặn đầu vào âm")
    try:
        line_total(True, 1)
    except TypeError:
        pass
    else:
        raise AssertionError("bool không thuộc hợp đồng")

if __name__ == '__main__':
    check()
    print('OK A01.01', line_total(12, 3))
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không nhầm thao tác print với giá trị return. Nếu ghi kết quả ra màn hình mà không return, hàm không trả về giá trị để kiểm thử hoặc tái sử dụng.

**Bài mở rộng chưa có đáp án:** Hãy đổi hợp đồng để cho phép đơn giá thập phân: giải thích vì sao xử lý tiền nên dùng Decimal thay vì float.
