# Lời giải mẫu D01.01 — First-class functions và callback

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tạo hàm `ap_dung(gia_tri, xu_ly)` trả về kết quả gọi `xu_ly(gia_tri)`. Kiểm thử callback nhân ba và callback chuyển số thành chuỗi.

## Code lời giải

```python
def ap_dung(gia_tri, xu_ly):
    if not callable(xu_ly):
        raise TypeError('xu_ly phải callable')
    return xu_ly(gia_tri)

assert ap_dung(4, lambda x: x * 3) == 12
assert ap_dung(4, str) == '4'
try:
    ap_dung(4, None)
except TypeError:
    pass
else:
    raise AssertionError('Thiếu kiểm tra callback')
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Hàm `xu_ly` nhận dữ liệu và một callback. Python liên kết tên `phep_bien_doi` tới cùng đối tượng hàm được truyền vào; khi chạy `phep_bien_doi(x)`, call expression mới thực thi callback. Việc chỉ viết `xu_ly([1, 2], nhan_doi)` **không** tự gọi `nhan_doi` trước khi truyền.

**Giới hạn:** Callback có thể ném ngoại lệ; giao diện cần xác định có chuyển tiếp lỗi hay xử lý cục bộ. Vòng lặp với đầu vào trống vẫn hợp lệ.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
