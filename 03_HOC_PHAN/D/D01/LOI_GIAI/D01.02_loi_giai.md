# Lời giải mẫu D01.02 — Higher-order function, map và filter

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết `tong_binh_phuong_so_le(ds)` bằng `filter` và `map`, sau đó so sánh với comprehension. Kiểm thử danh sách rỗng.

## Code lời giải

```python
def tong_binh_phuong_so_le(ds):
    return sum(map(lambda x: x * x, filter(lambda x: x % 2 == 1, ds)))

assert tong_binh_phuong_so_le([1, 2, 3]) == 10
assert tong_binh_phuong_so_le([]) == 0
assert sum(x * x for x in [1,2,3] if x % 2) == 10
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

`map()` không tạo list ngay. `list(...)` buộc iterator phát sinh kết quả. Khi `filter` nhận predicate, nó gọi predicate theo từng giá trị trong lúc duyệt.

**Giới hạn:** Một iterator đã tiêu thụ không thể tái duyệt tự động; muốn lặp lại cần tạo iterator mới hoặc vật hóa dữ liệu.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
