# Lời giải mẫu D05.03 — Tính dễ kiểm thử, tái sử dụng và tài liệu hóa

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tách chức năng đọc file khỏi logic lọc điểm; viết hàm thuần lọc điểm >= ngưỡng.

## Code lời giải

```python
def loc_diem(ds, *, nguong=5):
    return [x for x in ds if x >= nguong]
assert loc_diem([4,5,7]) == [5,7]
assert loc_diem([]) == []
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

`tao_thong_bao` nhận thời điểm từ tham số thay vì tự gọi đồng hồ. Nhờ vậy test xác định và không cần mock thời gian.

**Giới hạn:** Dependency injection nên tối giản; không tạo hàng chục lớp trừ khi thực sự có nhiều chiến lược kiểm thử.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
