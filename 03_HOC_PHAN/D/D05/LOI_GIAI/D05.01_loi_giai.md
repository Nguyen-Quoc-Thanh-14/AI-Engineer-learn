# Lời giải mẫu D05.01 — Chữ ký hàm và keyword-only

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tạo API `thanh_tien(gia, so_luong, *, phi=0)` và ca test phi âm theo hợp đồng tự chọn.

## Code lời giải

```python
def thanh_tien(gia, so_luong, *, phi=0):
    if min(gia,so_luong,phi)<0: raise ValueError('không âm')
    return gia*so_luong+phi
assert thanh_tien(10,3,phi=5)==35
assert thanh_tien(0,0)==0
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

`giam_gia(gia, *, ty_le)` yêu cầu ty_le được truyền theo tên. Dấu `*` không có nghĩa là phép nhân trong chữ ký.

**Giới hạn:** Thay đổi vị trí tham số trong public API có thể phá vỡ mã gọi cũ dù tên hàm vẫn như cũ.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
