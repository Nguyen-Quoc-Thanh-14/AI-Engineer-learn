# Lời giải mẫu D05.02 — Hợp đồng đầu vào/đầu ra và lỗi

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Đặc tả và triển khai hàm tính tỷ suất lợi nhuận; viết test input bình thường, mẫu 0 và số âm.

## Code lời giải

```python
def bien_loi_nhuan(thu,chi):
    if thu <= 0: raise ValueError('doanh thu phải dương')
    return (thu-chi)/thu
assert bien_loi_nhuan(100,60)==0.4
try: bien_loi_nhuan(0,0)
except ValueError: pass
else: raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Hàm chia yêu cầu mẫu khác 0. Không lặng lẽ trả 0 khi mẫu bằng 0, vì như vậy che giấu sai dữ liệu.

**Giới hạn:** Nếu dùng số thực so sánh bằng 0 rất sát 0, cần đánh giá độ ổn định số theo yêu cầu miền.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
