# Lời giải mẫu D04.02 — Union, generic và TypedDict

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Mô tả `TypedDict` cho dữ liệu người dùng gồm id và tên; viết validation runtime độc lập.

## Code lời giải

```python
from typing import TypedDict
class User(TypedDict):
    id: int
    name: str

def valid(v):
    return (isinstance(v, dict) and type(v.get('id')) is int and isinstance(v.get('name'), str))
assert valid({'id':1,'name':'An'})
assert not valid({'id':'1','name':'An'})
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

`first` trả về phần tử cùng kiểu với danh sách input nếu không rỗng; kiểu tổng quát nên làm rõ tiền điều kiện. `None` yêu cầu được xử lý độc lập.

**Giới hạn:** TypeVar cấp kiểu giúp bắt lỗi tĩnh nhưng không ngăn truy cập `items[0]` với list rỗng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
