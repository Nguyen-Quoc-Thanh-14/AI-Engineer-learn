# Lời giải mẫu D04.03 — Protocol, duck typing và static type checker

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết Protocol cho đối tượng có `save(text) -> None` và class InMemorySaver; test bằng assert.

## Code lời giải

```python
from typing import Protocol
class Saver(Protocol):
    def save(self, text: str) -> None: ...
class Memory:
    def __init__(self): self.data=[]
    def save(self, text): self.data.append(text)
def run(s: Saver): s.save('ok')
m=Memory();run(m)
assert m.data == ['ok']
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Chức năng phụ thuộc giao diện `.write(text)` hơn là một class cụ thể. Test doubles dễ cài đặt nhờ cùng giao diện.

**Giới hạn:** Một đối tượng thỏa Protocol tĩnh vẫn có thể báo lỗi logic, I/O hoặc sai hợp đồng khi thực thi.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
