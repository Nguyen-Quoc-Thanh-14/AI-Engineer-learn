# Lời giải mẫu D04.01 — Annotation và type hint

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết `dien_tich(hinh_vuong: float) -> float`, thêm validation số âm và nêu giới hạn của annotation.

## Code lời giải

```python
def dien_tich(canh: float) -> float:
    if canh < 0: raise ValueError('cạnh âm')
    return canh * canh
assert dien_tich(2.0)==4.0
try: dien_tich(-1)
except ValueError: pass
else: raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Hàm nhận `int` rồi cộng một. `-> int` không tự làm `isinstance` hay báo lỗi trước khi thực hiện phép cộng; hành vi phụ thuộc thân hàm.

**Giới hạn:** `bool` là subclass của `int`, nên yêu cầu chấp nhận số mà loại bool cần quy tắc validation riêng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
