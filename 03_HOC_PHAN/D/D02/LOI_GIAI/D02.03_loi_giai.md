# Lời giải mẫu D02.03 — Sử dụng decorator đúng mục đích

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết một test chứng minh wrapper không nuốt ValueError, rồi mô tả trường hợp dùng helper thường dễ bảo trì hơn decorator.

## Code lời giải

```python
from functools import wraps

def validate(fn):
    @wraps(fn)
    def inner(x):
        if x is None: raise ValueError('None')
        return fn(x)
    return inner

@validate
def cong_mot(x): return x+1
assert cong_mot(4)==5
try: cong_mot(None)
except ValueError: pass
else: raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Với chức năng chéo, so sánh wrapper với gọi một hàm helper tường minh. Chỉ chọn decorator nếu phần chức năng đó thực sự áp dụng lặp lại qua nhiều endpoint.

**Giới hạn:** Nếu decorator áp lên async function nhưng wrapper không `await`, nó có thể làm khác mô hình thực thi dự kiến.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
