# Lời giải mẫu D02.02 — functools.wraps và decorator có tham số

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết decorator factory `gioi_han(gioi_han_max)` để chặn kết quả lớn hơn giới hạn và bảo toàn tên hàm.

## Code lời giải

```python
from functools import wraps

def gioi_han(maximum):
    def decorator(fn):
        @wraps(fn)
        def inner(*args, **kwargs):
            value = fn(*args, **kwargs)
            if value > maximum: raise ValueError('vượt giới hạn')
            return value
        return inner
    return decorator

@gioi_han(5)
def tong(a,b): return a+b
assert tong(2,3) == 5
assert tong.__name__ == 'tong'
try: tong(3,4)
except ValueError: pass
else: raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Tại thời điểm định nghĩa hàm: Python tính `nhan_he_so(3)` trước, nhận decorator, rồi áp dụng decorator đó lên `cong`. `@wraps(fn)` giúp introspection thấy metadata gốc.

**Giới hạn:** `wraps` không thể bảo đảm toàn bộ chữ ký runtime vẫn giống hàm gốc; wrapper có thể thay đổi hành vi và typing.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
