## 1. Khái niệm và hợp đồng

Decorator nhận callable và trả lại callable khác. Kết quả trang trí là đối tượng được gán cho tên hàm, không đơn thuần một câu lệnh được chạy khi gọi hàm.

## 2. Lập luận trước khi viết mã

functools.wraps giúp bảo tồn tên và docstring để kiểm tra, logging và tài liệu API không bị méo. Trong bài tập, wrapper xác thực tham số trước khi gọi hàm gốc và giữ nguyên giá trị trả về.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/D02.01_bai_tap_da_giai_v25.py`](../MA_MAU/D02.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/D02.01_bai_tap_da_giai_v25.py
```

```python
from functools import wraps

def nonnegative(func):
    @wraps(func)
    def wrapper(value):
        if type(value) not in (int, float):
            raise TypeError('cần số')
        if value < 0:
            raise ValueError('không âm')
        return func(value)
    return wrapper

@nonnegative
def square(value):
    """Bình phương số không âm."""
    return value * value

def check():
    assert square(3) == 9
    assert square(0) == 0
    assert square.__name__ == 'square'
    try: square(-1)
    except ValueError: pass
    else: raise AssertionError('chưa validate')
    try: square('3')
    except TypeError: pass
    else: raise AssertionError('chưa validate kiểu')

if __name__ == '__main__':
    check()
    print('OK D02.01', square(3))
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không bỏ quên return wrapper hoặc return của hàm bọc; hai lỗi này khiến hàm trở thành None hoặc làm mất giá trị trả về.

**Bài mở rộng chưa có đáp án:** Hãy mở rộng decorator để kiểm tra nhiều tham số và giải thích vai trò của *args/**kwargs và inspect.signature.
