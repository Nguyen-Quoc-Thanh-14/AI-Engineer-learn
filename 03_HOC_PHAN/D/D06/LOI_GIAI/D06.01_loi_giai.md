# Lời giải bài tập vận dụng — D06.01 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Tạo generic `first[T](items:list[T])->T` và xử lý danh sách rỗng rõ ràng.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
from typing import TypeVar
T = TypeVar('T')  # tương đương cú pháp generic theo PEP 695, tương thích 3.13+
def first(items: list[T]) -> T:
    if not items: raise ValueError('danh sách không được rỗng')
    return items[0]
assert first([5, 9]) == 5
assert first(['x', 'y']) == 'x'
try: first([])
except ValueError: pass
else: raise AssertionError('phải từ chối rỗng')
print('PASS D06.01')
```

## Phản biện kỹ thuật và giới hạn

- Không suy ra tính đúng với mọi đầu vào từ các `assert` này; bổ sung property-based tests, kiểm thử đầu vào lỗi và tests hồi quy khi triển khai dự án.
- Cần đối chiếu version pin của thư viện trước khi dùng với Python 3.15.2.
- Tránh coi kiểm thử minh họa là xác nhận chất lượng/hiệu năng/bảo mật khi chạy thực tế.
