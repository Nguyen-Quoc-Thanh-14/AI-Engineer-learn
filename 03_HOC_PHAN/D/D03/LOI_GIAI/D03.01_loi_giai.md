# Lời giải mẫu D03.01 — LEGB và lexical scope

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết hàm lồng nhau lấy cấu hình từ enclosing scope, kiểm tra khi tồn tại tên trùng ở module.

## Code lời giải

```python
config='ngoai'
def tao():
    config='trong'
    def lay(): return config
    return lay
assert tao()()=='trong'
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Tên `x` trong `inner` được tìm trong local rồi enclosing (ở `outer`). Hàm gọi `inner` không thay đổi phạm vi lexical của `inner`.

**Giới hạn:** Một local binding (dù gán sau dòng đọc) có thể làm phát sinh UnboundLocalError.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
