# PE03.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế partitioning theo ngày/giờ có estimate số file và retention.

Partition by ingestion date `yyyy/mm/dd`, only add hour partition if per-hour volume justifies minimum file size. Example: 7 days × 24 hours × 10 files/hour = 1,680 objects; at 1 MB each this produces an inefficient small-file problem. Consolidate to approximately 128–512 MB target Parquet row groups/files depending on engine, compression and query patterns. Encrypt at rest/in transit, least-privilege prefixes, retention of raw sensitive data, lifecycle deletion tested. Report object-store request cost + egress, not storage bytes alone.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
