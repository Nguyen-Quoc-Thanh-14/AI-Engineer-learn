# PE03.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế load test 1 GB data, đo điểm nghẽn và ngưỡng chuyển sang distributed processing.

**Single-machine load test:** generate/replay ~1 GB columnar data with fixed seed and schema, measure peak RSS, wall-clock, CPU%, disk throughput, batch latency, spill-to-disk and retry recovery. Run 3 repeats and record OS/CPU/RAM, filesystem, Python/library versions. Define escalation threshold: peak RSS >70% available RAM, disk spill on common queries, or P95 pipeline latency exceeds SLA, then compare Polars/DuckDB before adding a distributed engine. Do not conclude “Spark required” from an unmeasured dataset size alone.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
