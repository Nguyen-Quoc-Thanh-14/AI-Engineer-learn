## 1. Khái niệm và hợp đồng

Reproducibility của pipeline yêu cầu nhận diện đầu vào, mã, tham số, phiên bản phụ thuộc và đầu ra. SHA-256 cung cấp fingerprint của bytes, không bảo đảm chất lượng logic của phép biến đổi.

## 2. Lập luận trước khi viết mã

Tính digest theo thứ tự file được sắp xếp; bao gồm đường dẫn tương đối và nội dung để tránh hai bộ file khác nhau cho kết quả giống chỉ vì nối bytes. Thử đọc cùng một thư mục hai lần, sau đó đổi nội dung và kiểm tra digest thay đổi.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PE03.01_bai_tap_da_giai_v25.py`](../MA_MAU/PE03.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/PE03.01_bai_tap_da_giai_v25.py
```

```python
import hashlib
from pathlib import Path
from tempfile import TemporaryDirectory

def snapshot_digest(folder: Path) -> str:
    folder = Path(folder)
    if not folder.is_dir():
        raise NotADirectoryError(folder)
    digest = hashlib.sha256()
    for path in sorted(p for p in folder.rglob('*') if p.is_file()):
        rel = path.relative_to(folder).as_posix().encode('utf-8')
        digest.update(len(rel).to_bytes(8, 'big'))
        digest.update(rel)
        content = path.read_bytes()
        digest.update(len(content).to_bytes(8, 'big'))
        digest.update(content)
    return digest.hexdigest()

def check():
    with TemporaryDirectory() as tmp:
        folder = Path(tmp)
        path = folder/'data.txt'
        path.write_bytes(b'abc')
        old = snapshot_digest(folder)
        assert snapshot_digest(folder) == old
        path.write_bytes(b'abd')
        assert snapshot_digest(folder) != old
        assert len(snapshot_digest(folder)) == 64
    try: snapshot_digest('/path/definitely/not/exists/99712')
    except NotADirectoryError: pass
    else: raise AssertionError('directory missing')

if __name__ == '__main__':
    check()
    print('OK PE03.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không hash theo thứ tự của os.listdir rồi cho rằng kết quả luôn ổn định trên hệ thống khác; và không xem SHA-256 là chứng nhận data lineage hoàn chỉnh.

**Bài mở rộng chưa có đáp án:** Bổ sung manifest chứa Python version, dependency lock, git commit và checksum của output, rồi so sánh hai lần chạy sạch.
