# PE02.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Đọc/ghi Parquet với pyarrow và so schema nullable/dtypes.

**Arrow/Parquet test case:** schema `sensor_id: string not null`, `timestamp: timestamp[us, UTC]`, `value: float64 nullable`; write a 10,000-row Arrow table, Parquet snappy and uncompressed versions, compare schemas and file sizes. Measure memory with Arrow buffers vs pandas objects, not `sys.getsizeof(table)` alone. A 3.15 implementation requires compatible `pyarrow` wheel and explicit null/float NaN semantics. **Blocked:** pyarrow not installed and CPython 3.15 unavailable.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
