# PE02.01 — Lời giải Bài B: Arrow/Parquet schema và nullable

**Đề:** Đọc/ghi Parquet với pyarrow và so schema nullable/dtypes.

[Mã thực thi](../MA_MAU/PE02.01_bai_B_parquet.py) dùng `pyarrow` tạo bảng 10.000 dòng: `sensor_id: string non-null`, `timestamp: timestamp[us,UTC] non-null`, `value: float64 nullable`. Tạo null có chủ đích, ghi hai bản Parquet (`snappy`, không nén), đọc lại và kiểm tra **bằng nhau cả schema (types, nullability) và data**, kiểm null count và ghi kích thước file để so sánh.

Chạy: `python 03_HOC_PHAN/PE/PE02/MA_MAU/PE02.01_bai_B_parquet.py` với `pyarrow==26.0.0` trên CPython 3.15.2. Kiểm thử từ ngoài nguồn trong `tests/test_issue9_parquet_contracts.py`.

Không suy ra nén luôn làm tệp nhỏ hơn cho mọi phân bố. Sự giống nhau của Arrow schema không chứng minh nội dung ứng dụng bảo đảm tuân thủ mọi hợp đồng dữ liệu. Chưa có phản biện độc lập.
