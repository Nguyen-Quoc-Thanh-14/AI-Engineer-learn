# Lời giải mẫu PE01.01 — Batch so với streaming pipelines

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết batch xử lý với idempotency key; chạy cùng batch hai lần và giải thích lựa chọn sink.

## Code lời giải

```python
seen=set()
def process(ids):
    return [x for x in ids if not (x in seen or seen.add(x))]
assert process([1,2,1])==[1,2]
assert process([1,2])==[]
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Ví dụ batch xử lý hàng sự kiện, chuẩn hóa và loại bản ghi trùng theo event_id; đây là mô phỏng offline, chưa bảo đảm exactly-once khi có database hoặc consumer restart.

**Giới hạn:** Late arrival và out-of-order event cần thiết kế window, watermark.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
