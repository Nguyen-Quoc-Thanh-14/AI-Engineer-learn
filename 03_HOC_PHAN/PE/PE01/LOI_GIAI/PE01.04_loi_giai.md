# Lời giải bài tập vận dụng — PE01.04 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Thiết kế incremental ingestion với lookback window và dedup primary key.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
from datetime import datetime,timedelta
def merge_incremental(stored,incoming,cutoff):
    result=dict(stored)
    for row in incoming:
        if row['updated_at']>=cutoff:
            id=row['id'];old=result.get(id)
            if old is None or row['updated_at']>=old['updated_at']:result[id]=row
    return result
start=datetime(2026,1,1);cutoff=start+timedelta(days=1)
old={1:{'id':1,'updated_at':start,'v':'old'}}
new=[{'id':1,'updated_at':cutoff,'v':'new'}, {'id':2,'updated_at':start,'v':'too old'}]
result=merge_incremental(old,new,cutoff)
assert result[1]['v']=='new'
assert 2 not in result
assert len(result)==1
print('PASS PE01.04')
```
