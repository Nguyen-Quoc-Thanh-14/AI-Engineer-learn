## 2. Khái niệm — Bản chất

Ảnh số thường là tensor H×W×C hoặc C×H×W. Pixel có giá trị tùy dtype và chuẩn hóa; RGB, BGR, grayscale có cách biểu diễn khác. Resize có thể làm mất thông tin; đổi color space không phải chỉ đổi tên trục.

## 3. Nguyên lý và cơ chế từng bước

Mô hình hóa ảnh RGB bằng NumPy không cần thư viện ảnh. Truy cập pixel bằng chỉ số hàng và cột, không đảo ngược chiều height/width. Kiểm tra shape và các kênh.

## 4. Ví dụ tối thiểu có thể chạy

```python
import numpy as np
image=np.zeros((2,3,3),dtype=np.uint8)
image[0,1]=[255,0,0]
assert image.shape==(2,3,3)
assert image[0,1,0]==255
print(tuple(image[0,1]))
```

**Kết quả kiểm thử cục bộ:** pass trên Python 3.13.5.

```text
(np.uint8(255), np.uint8(0), np.uint8(0))
```

**Thực hành:** chạy file `07_MA_VI_DU/PV01.01_vi_du.py` từ thư mục gốc giáo trình rồi sửa một tham số để dự đoán sự khác biệt.

## 5. Trường hợp biên, lỗi thường gặp và hướng debug

- **Ngộ nhận:** Không nhầm kích thước (height,width) với tọa độ (x,y); nhiều thư viện dùng thứ tự kênh khác.
- **Trường hợp biên:** Dtype uint8 có thể overflow khi cộng trực tiếp; ép kiểu phù hợp trước tính toán.
- **Debug có phương pháp:** xác định hợp đồng → tái hiện lỗi bằng đầu vào tối thiểu → đọc traceback/kiểm tra trạng thái → sửa → thêm regression test.

## 11. Hiệu đính đáp án B theo yêu cầu thực tế

**Đề bài gốc:** Tạo ảnh 4x4 đơn sắc, vẽ đường chéo bằng indexing rồi kiểm tra tổng pixel.
