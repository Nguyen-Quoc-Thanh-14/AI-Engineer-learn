## 1. Khái niệm và hợp đồng

Pixel RGB thường biểu diễn ba kênh màu; việc tính grayscale cần xác định ma trận màu, gamma, khoảng giá trị và cách làm tròn. Công thức weighted sum đơn giản chỉ là minh họa, không phải phép chuyển đổi màu quản lý màu chuẩn.

## 2. Lập luận trước khi viết mã

Dùng phép tính trọng số trên RGB 8-bit và round rồi clamp về 0..255, kiểm tra đúng ba kênh integer. Tách validate khỏi conversion để xử lý đúng dữ liệu âm/ngoài 255.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PV01.01_bai_tap_da_giai_v25.py`](../MA_MAU/PV01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/PV01.01_bai_tap_da_giai_v25.py
```

```python
def rgb_to_grayscale(pixel):
    if not isinstance(pixel, (tuple, list)) or len(pixel) != 3:
        raise ValueError('RGB cần 3 kênh')
    if any(type(v) is not int or not (0 <= v <= 255) for v in pixel):
        raise ValueError('mỗi kênh RGB phải là int từ 0 đến 255')
    r,g,b = pixel
    return round(0.299*r + 0.587*g + 0.114*b)

def check():
    assert rgb_to_grayscale((0,0,0)) == 0
    assert rgb_to_grayscale((255,255,255)) == 255
    assert rgb_to_grayscale((255,0,0)) == 76
    for bad in ((255, 0), (0,0,-1), (255,0,300), (True,0,0)):
        try: rgb_to_grayscale(bad)
        except ValueError: pass
        else: raise AssertionError('RGB sai')

if __name__ == '__main__':
    check()
    print('OK PV01.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không cộng đều R+G+B rồi mặc định kết quả tương đương độ sáng cảm nhận. Các chuẩn không gian màu có định nghĩa và biến đổi gamma khác nhau.

**Bài mở rộng chưa có đáp án:** Chuyển sang linear-light RGB trước khi tính luminance và so sánh với công thức demo; giải thích sự khác nhau.
