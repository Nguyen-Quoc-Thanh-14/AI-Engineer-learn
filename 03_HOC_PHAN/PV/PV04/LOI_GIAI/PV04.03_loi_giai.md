# PV04.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết bảng resource budget thiết bị và kế hoạch benchmark cold/warm inference.

**Limited-device resource budget:** 4-core CPU, 16 GB RAM, entry-level GPU as test target (must confirm actual specs). Allocate ≤4 GB RSS to model+decoder, queue depth ≤2, sustained thermals below throttling threshold, batch=1 for low latency. Benchmark cold start, warm inference p50/p95 on 200 local frames, input/output copy, decode and preprocessing separately; compare quantized vs FP32 accuracy on same holdout. If latency fails, lower image size or move feature extractor to a supported accelerator, documenting accuracy loss.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
