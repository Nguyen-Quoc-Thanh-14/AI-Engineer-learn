## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thiết kế metric đơn giản số ID switches trên 10 frames.

**Mã chạy riêng:** [PV04.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PV04.02_bai_B_solution.py)

```python
# Ground-truth per frame vs track IDs; ID switch when same GT object changes track ID.
gt_to_track=[{'personA':7},{'personA':7},{'personA':9},{'personA':9}, {}, {'personA':9}]
last={};switches=0
for frame in gt_to_track:
    for obj,track in frame.items():
        if obj in last and last[obj]!=track:switches+=1
        last[obj]=track
assert switches==1
# Real MOT metrics (IDF1, HOTA) require standardized annotation and matching.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
