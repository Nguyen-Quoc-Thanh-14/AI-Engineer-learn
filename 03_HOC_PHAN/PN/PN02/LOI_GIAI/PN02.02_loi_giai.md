# PN02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế A/B evaluation base vs LoRA trên cùng held-out prompts.

A/B plan: baseline frozen model vs parameter-efficient fine-tune (LoRA) with same architecture/tokenizer/prompt template, equal holdout set and evaluation budget. Train on separated approved data, log adapter rank/alpha, seed, learning rate, compute hours and number of trainable parameters; evaluate factuality, refusal, leakage probes, throughput and cost per correct answer. Version both base weights and adapter; prohibit test-set training. Without pretrained weights and evaluation data, this is a protocol, not a completed fine-tuning claim.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
