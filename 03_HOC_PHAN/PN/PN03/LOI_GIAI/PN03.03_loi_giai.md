# PN03.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế dashboard latency p95, cache hit, cost per correct answer.

LLM dashboard: request_id, model/version, prompt + completion tokens, cache hit%, p50/p95/p99 latency, upstream errors, estimated billable cost and **cost per evaluated correct answer** on labeled traffic. Formula `cost_correct = total_cost / max(n_correct,1)` with `n_correct=0` reported as undefined rather than a misleading finite number. Segment by prompt version and retrieval index. Track privacy-safe aggregate metadata; never log complete confidential prompts without explicit approval.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
