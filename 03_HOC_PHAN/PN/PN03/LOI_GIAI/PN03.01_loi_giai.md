## 1. Khái niệm và hợp đồng

Đánh giá NLP/LLM cần phân biệt exact-match accuracy, tính đúng ngữ nghĩa và groundedness. Một chuỗi giống đáp án tham chiếu không chứng minh mô hình dựa trên đúng nguồn hay không hallucinate.

## 2. Lập luận trước khi viết mã

Xây một đánh giá exact-match minh họa có chuẩn hóa khoảng trắng/chữ hoa. Tập đánh giá chứa cặp (reference,prediction), trả tỷ lệ khớp trên tổng số; test khi dự đoán sai, đầu vào trống và khi hai biểu thức tương đương ngữ nghĩa nhưng khác câu chữ.

```python
def normalize(s: str) -> str:
    if not isinstance(s, str):
        raise TypeError('phải là str')
    return ' '.join(s.casefold().split())

def exact_match_score(pairs: list[tuple[str,str]]) -> float:
    if not pairs:
        raise ValueError('không có mẫu đánh giá')
    return sum(normalize(a) == normalize(b) for a,b in pairs) / len(pairs)

def check():
    assert exact_match_score([('Paris', ' PARIS ')]) == 1.0
    assert exact_match_score([('Hà Nội', 'Hồ Chí Minh')]) == 0.0
    assert exact_match_score([('two', '2'), ('yes', 'yes')]) == 0.5
    try: exact_match_score([])
    except ValueError: pass
    else: raise AssertionError('dataset rỗng')

if __name__ == '__main__':
    check()
    print('OK PN03.01')
```

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không gọi tỷ lệ exact-match là “tỷ lệ không hallucinate”: thước đo này không phát hiện claim sai trong câu dài hay sự thiếu chứng cứ trích dẫn.

**Bài mở rộng chưa có đáp án:** Thiết kế 30 mục đánh giá gồm câu hỏi factoid, diễn giải, bịa số liệu, mâu thuẫn nguồn; chấm riêng factuality, citation support và refusal.
