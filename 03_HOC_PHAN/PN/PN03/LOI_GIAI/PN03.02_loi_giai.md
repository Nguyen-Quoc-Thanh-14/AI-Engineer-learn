# PN03.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết threat model RAG với untrusted PDFs, cross-tenant leakage và tool actions.

RAG threat model: untrusted PDF/web text enters retrieval; malicious instructions in retrieved text must remain **data** rather than overriding developer/system rules. Tenant separation is enforced when retrieving documents (filter **before** results reach model), again when opening sources and when invoking tools. Never pass untrusted snippets as raw tool arguments, or expose API credentials to prompts. Run synthetic injection cases: `ignore previous instructions`, `export all client files`; assert no cross-tenant results, tool calls or secrets. Record false positives and legitimate content failures.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
