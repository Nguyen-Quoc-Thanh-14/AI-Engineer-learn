# J04.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo hook từ chối subclass không có `name` class attribute và kiểm báo lỗi.

**Mã chạy riêng:** [J04.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J04.02_bai_B_solution.py)

```python
class RequireName:
    def __init_subclass__(cls,**kwargs):
        super().__init_subclass__(**kwargs)
        if not isinstance(cls.__dict__.get('name'),str) or not cls.name:
            raise TypeError('subclass must define nonempty class attribute name')
class OK(RequireName): name='report'
assert OK.name=='report'
try:
    class Broken(RequireName): pass
except TypeError: pass
else: raise AssertionError('invalid subclass accepted')
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.

**Trạng thái:** Chờ kết quả kiểm thử trong `31_HOAN_THIEN_LOI_GIAI_V28/ket_qua_kiem_thu_loi_giai.json`; không suy đoán Python 3.15.2.
