# J04.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Giải thích khác nhau của `object.__getattribute__` và `type.__getattribute__` bằng ví dụ property.

**Mã chạy riêng:** [J04.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J04.01_bai_B_solution.py)

```python
class Temp:
    @property
    def celsius(self):return self._c
    def __init__(self,c):self._c=c
x=Temp(20)
assert object.__getattribute__(x,'celsius')==20
assert type.__getattribute__(Temp,'celsius') is Temp.__dict__['celsius']
# Class attribute access returns the descriptor object; instance access calls its __get__.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
