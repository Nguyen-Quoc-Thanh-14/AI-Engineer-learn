## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Vẽ pipeline class statement → metaclass → __set_name__ → __init_subclass__.

**Mã chạy riêng:** [J04.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J04.03_bai_B_solution.py)

```python
trace=[]
class Descriptor:
    def __set_name__(self,owner,name):trace.append(('set_name',name))
class Base:
    def __init_subclass__(cls,**kwargs):
        trace.append(('init_subclass',cls.__name__))
        super().__init_subclass__(**kwargs)
class Metaclass(type):
    def __new__(mcls,name,bases,namespace):
        trace.append(('meta_new',name))
        return super().__new__(mcls,name,bases,namespace)
class Child(Base,metaclass=Metaclass):
    field=Descriptor()
assert trace==[('meta_new','Child'),('set_name','field'),('init_subclass','Child')]
assert Child.__mro__==(Child,Base,object)
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
