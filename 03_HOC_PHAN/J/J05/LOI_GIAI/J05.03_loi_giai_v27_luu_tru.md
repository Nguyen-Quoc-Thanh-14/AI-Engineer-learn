# Hướng dẫn và mẫu kiểm chứng — J05.03

**Trạng thái:** HƯỚNG DẪN / MẪU THAM KHẢO, **chưa phải lời giải độc lập hoàn chỉnh** cho bài vận dụng.

## Cách tiếp cận

1. Xác định tiền điều kiện và hậu điều kiện cho bài tập.
2. Giữ nguyên invariant và contract của phần lý thuyết.
3. Tạo test ca thường, ca biên và dữ liệu lỗi; không dùng kết quả một test duy nhất làm bằng chứng đầy đủ.
4. Đối chiếu với mã minh họa đã chạy (xem `../MA_MAU/J05.03_demo.py`).

## Mẫu tham khảo đã kiểm tra trong môi trường hiện tại

```python
class Service:
    def read(self): return 'ok'
commands={'read':Service().read}
assert commands['read']()=='ok'
assert 'delete_all' not in commands
```

**Nhiệm vụ còn mở:** Viết lời giải khác ví dụ mẫu cho yêu cầu: Viết dispatcher không dùng getattr trên input trực tiếp; test reject admin method.
