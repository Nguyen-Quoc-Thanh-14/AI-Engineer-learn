# J05.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết dispatcher không dùng getattr trên input trực tiếp; test reject admin method.

**Mã chạy riêng:** [J05.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J05.03_bai_B_solution.py)

```python
class Service:
    def read(self): return 'read'
    def admin_delete(self): return 'destroyed'
service=Service()
allowed={'read':service.read}
def dispatch(name):
    try: fn=allowed[name]
    except KeyError: raise PermissionError(name)
    return fn()
assert dispatch('read')=='read'
try: dispatch('admin_delete')
except PermissionError: pass
else: raise AssertionError('privileged method exposed')
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
