# Lời giải vận dụng — J03.01

**Đề bài B:** Viết class CounterIterator sinh 0..n-1 với StopIteration đúng.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
class CounterIterator:
    def __init__(self,n):
        if n<0: raise ValueError('negative')
        self.n=n;self.i=0
    def __iter__(self):return self
    def __next__(self):
        if self.i>=self.n: raise StopIteration
        result=self.i;self.i+=1;return result
assert list(CounterIterator(4))==[0,1,2,3]
assert list(CounterIterator(0))==[]
it=CounterIterator(1);assert next(it)==0
try:next(it)
except StopIteration:pass
else:raise AssertionError()
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
