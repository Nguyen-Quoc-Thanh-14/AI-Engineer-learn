## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** So sánh sử dụng bộ nhớ list và generator cho số lượng phần tử lớn mà không giữ cả hai.

**Mã chạy riêng:** [J03.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J03.03_bai_B_solution.py)

```python
import tracemalloc
n=10000
tracemalloc.start()
gen=(i*i for i in range(n));a=tracemalloc.get_traced_memory()[0]
all_values=[i*i for i in range(n)];b=tracemalloc.get_traced_memory()[0]
assert sum(gen)==sum(all_values) and b>a
tracemalloc.stop()
# Memory includes interpreter overhead; repeat measurements before quantitative claims.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
