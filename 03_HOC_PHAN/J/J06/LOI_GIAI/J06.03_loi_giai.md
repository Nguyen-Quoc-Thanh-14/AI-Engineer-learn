# J06.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Tạo migration checklist cho một API có cảnh báo deprecation và thử nhiều phiên bản.

**Migration checklist:** (1) record target/previous interpreters; (2) inspect [Python 3.15 What's New](https://docs.python.org/3.15/whatsnew/3.15.html) and deprecations; (3) run `python -Wd -m pytest`; (4) replace deprecated API with documented alternative; (5) test 3.14/3.15 in CI; (6) record exact affected packages and release notes. An observed deprecation warning is a migration signal, not proof the API is already removed. Store compatibility tests as regression fixtures.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
