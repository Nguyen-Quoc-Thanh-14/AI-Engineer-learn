## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** So sánh bytecode function sử dụng list comprehension với for-loop, giải thích giới hạn.

**Mã chạy riêng:** [J06.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J06.01_bai_B_solution.py)

```python
import dis

def by_loop(xs):
    out=[]
    for x in xs: out.append(x*x)
    return out

def by_comp(xs): return [x*x for x in xs]
assert by_loop([1,2,-3])==by_comp([1,2,-3])
op1=[i.opname for i in dis.get_instructions(by_loop)]
op2=[i.opname for i in dis.get_instructions(by_comp)]
assert op1 and op2
# Do not lock a test to specific opcode names; opcode spelling changes across releases.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
