# Lời giải mẫu J01.03 — Garbage collection và cyclic references

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Dựng vòng tham chiếu giữa hai dict; xóa hai binding; giải thích vì sao vòng không còn reachable.

## Code lời giải

```python
import gc
a={};b={}
a['next']=b;b['prev']=a
del a,b
assert gc.collect()>=0
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Hai list tự tham chiếu minh họa vòng; dùng `gc.collect()` trong thử nghiệm để quan sát nhưng không coi số object thu gom là hợp đồng ổn định. Tránh phụ thuộc `__del__` hoặc số collection chính xác.

**Giới hạn:** Object dùng weakref hoặc finalizer có quy tắc dọn dẹp riêng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
