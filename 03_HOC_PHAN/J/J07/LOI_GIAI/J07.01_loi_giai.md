## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Đọc bản Whats New 3.15 và viết ba test cho lazy import, frozendict và sentinel trên Python 3.15.

Three **Python 3.15-only** smoke tests required, to run with 3.15.2:
```python
lazy import json
assert 'json' in globals()  # first use of binding may resolve import
from builtins import frozendict, sentinel
f=frozendict({'x':1})
assert f['x']==1
try:f['x']=2
except TypeError:pass
else:raise AssertionError('mutated')
missing=sentinel('MISSING')
assert missing is missing
```
The module import model and exact `sentinel()` constructor/API must be checked against final official docs before publication. **Status:** candidate smoke test, not executed; not evidence of 3.15 compatibility.
