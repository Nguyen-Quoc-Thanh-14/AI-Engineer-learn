# J07.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Đọc bản Whats New 3.15 và viết ba test cho lazy import, frozendict và sentinel trên Python 3.15.

Three **Python 3.15-only** smoke tests required, to run with 3.15.2:
```python
lazy import json
assert 'json' in globals()  # first use of binding may resolve import
from builtins import frozendict, sentinel
f=frozendict({'x':1})
assert f['x']==1
try:f['x']=2
except TypeError:pass
else:raise AssertionError('mutated')
missing=sentinel('MISSING')
assert missing is missing
```
The module import model and exact `sentinel()` constructor/API must be checked against final official docs before publication. **Status:** candidate smoke test, not executed; not evidence of 3.15 compatibility.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.


## Hiệu đính Issue #9 — kiểm thử runtime có thể chạy trên CPython 3.15.2

Ba yêu cầu ở Bài B nay có bộ kiểm thử Python chạy **riêng trong tiến trình mới**, không lẫn trạng thái import của môi trường kiểm định: [`test_issue9_python315_features.py`](../../../../tests/test_issue9_python315_features.py).

- **Lazy import (PEP 810):** tiến trình mới khẳng định `fractions` chưa có trong `sys.modules` trước khi truy cập `fractions.Fraction`, sau đó đã được tải.
- **frozendict (PEP 814):** giá trị tra cứu được và ghi đè phải phát sinh `TypeError`.
- **sentinel (PEP 661):** tạo sentinel bằng tên, kiểm tra danh tính và khác `None`.

Lệnh chạy: `python -m unittest discover -s tests -p 'test_issue9_python315_features.py' -v`. **Không dùng kết quả này để đánh giá hiệu năng import toàn diện hoặc chứng nhận các thư viện ngoài.** Việc mypy/pyright hỗ trợ kiểu không thuộc phạm vi ba phép kiểm runtime này. Chỉ ghi PASS khi có CI trên đúng SHA; phản biện chuyên gia độc lập vẫn chưa thực hiện.

Nguồn: https://docs.python.org/3.15/whatsnew/3.15.html
