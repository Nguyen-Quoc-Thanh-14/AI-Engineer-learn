# J07.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết danh mục 5 đặc tính CPython-specific và phương án portable cho ứng dụng.

Five CPython-specific examples and portable alternatives:
1. Reference count lifetime → use `with`, explicit `close()` and `weakref.finalize` only where appropriate.
2. GIL performance assumptions → benchmark the selected interpreter and concurrency mode.
3. `sys.getsizeof` memory accounting → use tracemalloc/heap profiler with implementation caveats.
4. `dis` opcode names and adaptive cache → test observed behavior rather than exact opcode strings.
5. C-extension ABI → isolate native boundary; prefer Python protocols and compatible wheels.
**Acceptance:** annotate each assumption with official documentation, and avoid presenting a CPython behavior as part of the language specification.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
