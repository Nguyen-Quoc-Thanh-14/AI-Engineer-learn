# J07.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo cycle object và theo dõi gc bằng weakref, tránh dự đoán chính xác thời điểm thu hồi.

**Mã chạy riêng:** [J07.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/J07.02_bai_B_solution.py)

```python
import weakref,gc
class Node:
    def __init__(self): self.other=None
left=Node();right=Node();left.other=right;right.other=left
r=weakref.ref(left)
del left,right
gc.collect()
assert r() is None
# Explicit collect demonstrates cycle collection here; timing without it is not specified.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
