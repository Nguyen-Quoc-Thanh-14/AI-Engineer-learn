# J07.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế ma trận wheel tags cho CPython 3.15 GIL-enabled/free-threaded.

| Build target | Example wheel ABI category | Risk |
|---|---|---|
| Regular CPython 3.15, version-specific C API | `cp315` | Rebuild across minor versions |
| CPython 3.15 regular stable ABI | `abi3` | Limited API compliance required |
| CPython 3.15 free-threaded regular ABI | `cp315t` | Audit shared mutable C state |
| CPython 3.15 free-threaded stable ABI | `abi3t` | Must use supported new export hooks and target ABI macros |

The actual wheel tag must be derived from compliant build tooling and platform, not hand-edited. Validate imports and stress tests on separate regular/free-threaded interpreters and match packaging docs. `abi3` and `abi3t` are not interchangeable.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
