## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo CLI `--input`, `--dry-run` và kiểm invalid option.

**Mã chạy riêng:** [PA01.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PA01.03_bai_B_solution.py)

```python
import argparse
from pathlib import Path

def build_parser():
    p=argparse.ArgumentParser();p.add_argument('--input',required=True,type=Path)
    p.add_argument('--dry-run',action='store_true');return p
p=build_parser();args=p.parse_args(['--input','report.csv','--dry-run'])
assert args.input==Path('report.csv') and args.dry_run
try:p.parse_args(['--unknown'])
except SystemExit as e:assert e.code==2
else:raise AssertionError('unknown option accepted')
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
