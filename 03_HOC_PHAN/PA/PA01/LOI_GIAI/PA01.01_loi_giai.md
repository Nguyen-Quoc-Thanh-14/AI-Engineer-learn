# Lời giải mẫu PA01.01 — Tự động xử lý thư mục

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết trình quét đếm file theo suffix, bổ sung dry-run trước khi đổi tên.

## Code lời giải

```python
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as tmp:
    p=Path(tmp);(p/'x.log').write_text('A')
    assert [f.suffix for f in p.iterdir()]==['.log']
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Dùng `TemporaryDirectory()` tạo dữ liệu giả. `Path.iterdir()` không bảo đảm thứ tự nên `sorted()` nếu thứ tự cần ổn định. Ví dụ đếm loại tệp mà không đụng vào thư mục thật.

**Giới hạn:** Symlink, quyền truy cập và tên trùng có thể làm thao tác rename thất bại.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
