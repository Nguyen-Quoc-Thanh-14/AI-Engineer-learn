# PA02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế scraper chỉ lấy dữ liệu được phép, có robots/ToS review và rate limits.

**Authorized-scraping plan:** read website terms and `/robots.txt` for the relevant agent, secure explicit permission where required and obey rate limits/Retry-After. HTML parser should select stable semantic attributes, not fragile positional selectors, and only collect non-sensitive permitted data. Set `User-Agent` identifying your crawler, concurrency=1, delay≥2 s for the illustrative environment, timeout≤5 s, max_pages=3. Stop on HTTP 401/403, do not evade CAPTCHA, authentication or anti-bot controls. Save raw response hash and extraction version for reproducibility; sanitize outputs. **Acceptance:** mock a permitted HTML page with a missing field and assert parser returns an explicit schema error; no live crawling is necessary.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
