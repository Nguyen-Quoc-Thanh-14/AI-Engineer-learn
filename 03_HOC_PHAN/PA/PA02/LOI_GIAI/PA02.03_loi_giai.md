## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo scheduler giả lập clock có retry và job ID.

**Mã chạy riêng:** [PA02.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PA02.03_bai_B_solution.py)

```python
import random
# Clock injected: no sleeping or relying on wall clock for scheduler test.
class Job:
    def __init__(self,job_id): self.job_id=job_id;self.attempts=0
    def run(self,send):
        for delay in (0,1,2):
            self.attempts+=1
            try:return send(self.job_id)
            except ConnectionError:
                if delay==2:raise
        raise AssertionError('unreachable')
job=Job('job-003')
def fake_send(job_id):
    if job.attempts<3:raise ConnectionError('transient')
    return 'delivered:'+job_id
assert job.run(fake_send)=='delivered:job-003' and job.attempts==3
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
