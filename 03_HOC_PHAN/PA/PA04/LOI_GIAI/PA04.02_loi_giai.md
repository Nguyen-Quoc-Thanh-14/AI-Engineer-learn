## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thiết kế job heartbeat và thông báo khi ba lần chạy liên tiếp thất bại.

**Mã chạy riêng:** [PA04.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PA04.02_bai_B_solution.py)

```python
# Alert after three consecutive failed runs, reset on success.
class Heartbeat:
    def __init__(self):self.failures=0;self.alerts=[]
    def record(self,success):
        self.failures=0 if success else self.failures+1
        if self.failures==3:self.alerts.append('ALERT')
h=Heartbeat()
for ok in (False,False,True,False,False,False,False):h.record(ok)
assert h.alerts==['ALERT'] and h.failures==4
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
