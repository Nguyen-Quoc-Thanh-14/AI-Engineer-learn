## 1. Khái niệm và hợp đồng

Dry-run tạo kế hoạch thay đổi trước khi ghi dữ liệu; idempotency là thuộc tính của toàn bộ thao tác: chạy lần thứ hai với cùng dữ liệu không tạo thêm thay đổi ngoài ý muốn.

## 2. Lập luận trước khi viết mã

Xây danh sách đổi đuôi .TXT thành .txt mà không thực hiện ngay, và từ chối nếu đích đã tồn tại. Khi apply=True, dùng cùng kế hoạch đã xác minh. Việc kiểm tra tồn tại trước khi rename giảm lỗi phổ biến, nhưng không loại bỏ hoàn toàn race giữa lúc kiểm tra và thực hiện.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PA04.01_bai_tap_da_giai_v25.py`](../MA_MAU/PA04.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/PA04.01_bai_tap_da_giai_v25.py
```

```python
from pathlib import Path
from tempfile import TemporaryDirectory

def rename_txt(folder: Path, *, apply: bool = False) -> list[tuple[Path, Path]]:
    folder = Path(folder)
    if not folder.is_dir():
        raise NotADirectoryError(folder)
    changes = []
    for source in sorted(folder.iterdir()):
        if not source.is_file() or source.suffix != '.TXT':
            continue
        dest = source.with_suffix('.txt')
        if dest.exists():
            raise FileExistsError(dest)
        changes.append((source, dest))
    if apply:
        for source, dest in changes:
            source.rename(dest)
    return changes

def check():
    with TemporaryDirectory() as temp:
        folder = Path(temp)
        (folder / 'a.TXT').write_text('hello', encoding='utf-8')
        plan = rename_txt(folder)
        assert len(plan) == 1 and (folder/'a.TXT').exists()
        assert len(rename_txt(folder, apply=True)) == 1
        assert rename_txt(folder, apply=True) == []  # idempotent với input này
        assert (folder/'a.txt').read_text(encoding='utf-8') == 'hello'
        (folder/'b.TXT').write_text('source')
        (folder/'b.txt').write_text('target')
        try: rename_txt(folder, apply=True)
        except FileExistsError: pass
        else: raise AssertionError('phải phát hiện collision')

if __name__ == '__main__':
    check()
    print('OK PA04.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không nhầm việc chạy script hai lần không phát exception với idempotency: phải so sánh trạng thái file đầu/cuối. Đừng tự động ghi đè file trùng tên.

**Bài mở rộng chưa có đáp án:** Giải quyết bài toán cạnh tranh trong môi trường nhiều tiến trình bằng thao tác nguyên tử phù hợp với hệ điều hành và báo cáo rollback.
