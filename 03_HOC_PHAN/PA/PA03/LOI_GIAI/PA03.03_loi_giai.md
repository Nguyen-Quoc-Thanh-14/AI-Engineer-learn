# PA03.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Tạo pyproject.toml với `[project.scripts]` cho CLI của bạn.

For a CSV cleaning CLI, use `[project.scripts] clean-orders="orders.cli:main"` in `pyproject.toml`, `requires-python=">=3.14"` adjusted to tested versions. Tests must cover `clean-orders --input file.csv --dry-run`, invalid flags and a nonexistent path. Build wheel/sdist, install wheel in clean virtual environment, execute CLI, inspect output and logs. Keep dry-run default for destructive operations, refuse to overwrite without explicit flag, and version the CLI contract. Publishing is a separate controlled action.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
