# PS02.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Tạo schema sensor readings có timestamp timezone và units, xuất Parquet và test.

Sensor schema: `device_id` string, `timestamp` UTC timestamp with explicit timezone, `value` float64 nullable, `unit` allowed from documented set, `quality_flag` categorical. Arrow/Parquet implementation must reject mixed units and roundtrip timezone+nulls. Validate `timestamp` increasing per device, duplicates policy and file hash. Use synthetic data with DST boundary and missing readings; record Arrow version and compression codec. **Blocked:** pyarrow not installed.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
