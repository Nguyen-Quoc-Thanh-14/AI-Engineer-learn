## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết kernel Numba sum-of-squares và benchmark sau compile vs NumPy.

**Mã chạy riêng:** [PS04.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PS04.03_bai_B_solution.py)

```python
import numpy as np
try:
    from numba import njit
except ImportError: njit=None
x=np.arange(1000,dtype=np.float64)
ref=np.square(x).sum()
if njit is not None:
    @njit
    def squares(x):
        total=0.
        for v in x:total+=v*v
        return total
    assert np.isclose(squares(x),ref)
    # The first call also compiles the kernel: benchmark steady-state after warmup.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
