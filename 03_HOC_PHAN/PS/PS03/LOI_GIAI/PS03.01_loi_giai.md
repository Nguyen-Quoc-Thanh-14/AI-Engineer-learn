# PS03.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết thực nghiệm so hai solver có fixed tolerance và nhiều datasets.

Two-solver experiment: solve same linear system with `numpy.linalg.solve` and a second independently configured solver (e.g. SciPy LU) at fixed tolerance `rtol=1e-10` and `atol=1e-12`. Datasets: well-conditioned SPD, nearly singular and rank-deficient (must report expected failure). Repeat each 10 times with controlled CPU workload, compare residual ‖Ax-b‖ and condition number, not elapsed time alone. Pre-register what qualifies as failure; publish input matrices and runtime metadata.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
