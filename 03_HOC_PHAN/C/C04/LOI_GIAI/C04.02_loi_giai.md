# Lời giải C04.02 — enumerate, zip và sorted

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Ghép hai danh sách tên/điểm theo index thành dict; báo lỗi nếu độ dài khác nhau.

## Lời giải Python

```python
def lap_bang_diem(ten, diem):
    return dict(zip(ten, diem, strict=True))
assert lap_bang_diem(["A", "B"],[1,2]) == {"A":1,"B":2}
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Khi cần sắp xếp phức tạp, truyền `key` để tạo tiêu chí; Python sort ổn định, các phần tử có cùng key giữ thứ tự tương đối.

**Lỗi cần tránh:** `sorted` không sửa list ban đầu; `list.sort()` trả None, không phải list đã sắp.
