# Lời giải C04.03 — List, set và dict comprehension

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Tạo dict đếm chiều dài từng tên trong list, bỏ tên rỗng.

## Lời giải Python

```python
def do_dai_ten(ds):
    return {ten: len(ten) for ten in ds if ten}
assert do_dai_ten(["An", "", "Chi"]) == {"An": 2,"Chi": 3}
```

- Môi trường hiện có: Python 3.13.5.

## Giải thích

Quy trình: duyệt các phần tử, áp dụng bộ lọc if, tính biểu thức, thêm kết quả vào container. Khi dùng nhiều for, thứ tự tương ứng với vòng lặp lồng nhau.

**Lỗi cần tránh:** Với phần tử lớn hoặc pipeline dài, comprehension tạo list có thể tốn bộ nhớ; cân nhắc generator.
