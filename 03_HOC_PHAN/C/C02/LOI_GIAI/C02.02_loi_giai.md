## Bài toán

Viết hàm trả tên môn học có trong hai danh sách học kỳ, sắp theo bảng chữ cái.

## Lời giải Python

```python
def mon_chung(ky1, ky2):
    return sorted(set(ky1) & set(ky2))
assert mon_chung(["Toán","Văn"],["Văn","Anh"]) == ["Văn"]
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.

## Giải thích

Set dựa trên hashing; thứ tự lặp không phải giao kèo thứ tự. Đối với kết quả cần thứ tự, dùng sorted với các phần tử có thể so sánh được.

**Lỗi cần tránh:** Đừng giả định `list(set(items))` giữ nguyên thứ tự hay luôn cùng thứ tự trên môi trường khác nhau.
