# Lời giải C02.03 — Hashable và lỗi KeyError

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm kiểm tra một khóa có tồn tại và trả giá trị hoặc chuỗi "thiếu".

## Lời giải Python

```python
def lay_khoa(d, k):
    return d[k] if k in d else "thiếu"
assert lay_khoa({"x": None}, "x") is None
assert lay_khoa({}, "x") == "thiếu"
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Dict sử dụng hash để tìm bucket rồi so sánh equality khi cần; KeyError khác TypeError: KeyError do thiếu khóa, TypeError có thể do khóa không hashable.

**Lỗi cần tránh:** Không dùng list làm dict key; dùng tuple các phần tử hashable, hoặc chuyển kiểu có chủ đích.
