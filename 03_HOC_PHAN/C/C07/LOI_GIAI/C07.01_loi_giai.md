# Lời giải C07.01 — collections.abc, Mapping và hashability

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm nhận bất kỳ Mapping và trả list khóa đã sắp.

## Lời giải Python

```python
from collections.abc import Mapping
def khoa_da_sap(data: Mapping):
    return sorted(data.keys())
assert khoa_da_sap({"b":2,"a":1}) == ["a","b"]
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Có thể nhận một đối tượng Mapping trong hàm để giảm phụ thuộc vào dict cụ thể. Dùng `isinstance(x, Mapping)` khi yêu cầu runtime và cân nhắc type hint `Mapping[K,V]`.

**Lỗi cần tránh:** Không coi `Mapping` là kiểu `dict` cụ thể; code phụ thuộc `.update()` sẽ không chạy với mọi Mapping.
