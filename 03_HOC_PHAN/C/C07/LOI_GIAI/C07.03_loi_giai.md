# Lời giải C07.03 — sentinel và phân biệt None với trạng thái thiếu

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Tạo hàm lấy khóa: nếu vắng khóa trả sentinel; nếu có khóa với None thì trả None.

## Lời giải Python

```python
# CPython 3.15+
MISSING = sentinel("MISSING")
def tra_cuu(data, key):
    return data.get(key, MISSING)
assert tra_cuu({"x": None}, "x") is None
assert tra_cuu({}, "x") is MISSING
```

## Kiểm tra: not_run_python_315_required

- Môi trường hiện có: Python 3.13.5.
- Chưa kiểm chứng với Python 3.15.2.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Tạo sentinel có tên rõ; so sánh bằng `is` thay vì `==`. Dùng `dict.get(key, NOT_FOUND)` rồi kiểm tra identity để biết khóa có tồn tại.

**Lỗi cần tránh:** Không thay thế mọi `None` bằng sentinel; chỉ dùng khi bài toán cần trạng thái khác biệt.
