# Lời giải C07.02 — frozendict và cấu trúc mapping bất biến

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm nhận dict số nguyên và trả frozendict chứa giá trị được tăng một đơn vị.

## Lời giải Python

```python
# CPython 3.15+
def cong_mot_mapping(data):
    return frozendict({k: v+1 for k,v in data.items()})
assert cong_mot_mapping({"a":2})["a"] == 3
```

## Kiểm tra: not_run_python_315_required

- Môi trường hiện có: Python 3.13.5.
- Chưa kiểm chứng với Python 3.15.2.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Khởi tạo từ dữ liệu rồi chỉ đọc; thao tác `d[k]=v` gây TypeError. Dùng frozendict cho cấu hình nhỏ, khóa cache hay cấu trúc có ngữ nghĩa bất biến khi các phần tử thích hợp.

**Lỗi cần tránh:** Không dùng được trên Python 3.13; không được coi một frozendict chứa list là hashable.
