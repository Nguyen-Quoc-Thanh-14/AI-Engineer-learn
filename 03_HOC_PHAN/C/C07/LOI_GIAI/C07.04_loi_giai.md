# Lời giải C07.04 — Unpacking trong comprehensions (Python 3.15)

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết một list comprehension 3.15 hợp nhất ba list, và so sánh với phiên bản tương thích Python 3.13.

## Lời giải Python

```python
# CPython 3.15+
source = [[1,2],[3]]
new = [*part for part in source]
old = [v for part in source for v in part]
assert new == old == [1,2,3]
```

## Kiểm tra: not_run_python_315_required

- Môi trường hiện có: Python 3.13.5.
- Chưa kiểm chứng với Python 3.15.2.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Trong comprehension unpacking, từng iterable được mở rộng và đưa phần tử vào kết quả theo thứ tự duyệt. Dictionary unpacking xử lý khóa trùng theo quy tắc giá trị xuất hiện sau ghi đè trước.

**Lỗi cần tránh:** Không viết cú pháp mới vào tài liệu yêu cầu chạy trên 3.13 mà không ghi chú version; khi cần tương thích dùng `[x for group in groups for x in group]`.
