# Lời giải C01.02 — Truy cập, cập nhật và duyệt

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm thay phần tử cuối thành "done" trên một bản sao; không sửa input.

## Lời giải Python

```python
def cap_nhat_cuoi(items):
    out = items.copy()
    if out:
        out[-1] = "done"
    return out
src = ["a", "b"]
assert cap_nhat_cuoi(src) == ["a", "done"]
assert src == ["a", "b"]
assert cap_nhat_cuoi([]) == []
```

## Giải thích

Python chuyển index âm thành vị trí từ cuối, rồi kiểm tra hợp lệ. Slicing giới hạn ngoài biên một cách an toàn đối với nhiều sequence chuẩn.

**Lỗi cần tránh:** `append([1,2])` thêm một list; `extend([1,2])` thêm từng phần tử. Dễ gây lỗi dữ liệu lồng nhau.
