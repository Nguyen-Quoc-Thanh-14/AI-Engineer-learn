## 1. Khái niệm và hợp đồng

Mutable là khả năng thay đổi trạng thái của cùng một đối tượng; aliasing xảy ra khi nhiều tên trỏ tới cùng đối tượng. Thao tác tạo bản sao không tương đương thay đổi trực tiếp đối tượng cũ.

## 2. Lập luận trước khi viết mã

Cho hai tên cùng tham chiếu list ban đầu, append bằng alias sẽ làm cả hai cùng quan sát thay đổi. Tạo list mới trước khi append giúp bảo toàn dữ liệu đầu vào; tuy nhiên đây chỉ là shallow copy, phần tử lồng nhau vẫn có thể được chia sẻ.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/C03.01_bai_tap_da_giai_v25.py`](../MA_MAU/C03.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/C03.01_bai_tap_da_giai_v25.py
```

```python
def append_copy(items: list, value):
    if not isinstance(items, list):
        raise TypeError('items phải là list')
    return [*items, value]

def check():
    original = [1, 2]
    alias = original
    alias.append(3)
    assert original == [1, 2, 3] and alias is original
    result = append_copy(original, 4)
    assert result == [1, 2, 3, 4] and original == [1, 2, 3]
    assert append_copy([], 'x') == ['x']
    try: append_copy(None, 1)
    except TypeError: pass
    else: raise AssertionError('sai kiểu')
    nested = [{'x': 1}]
    copied = append_copy(nested, 2)
    assert copied[0] is nested[0]  # shallow copy

if __name__ == '__main__':
    check()
    print('OK C03.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Nhầm `b = a` thành sao chép; hoặc cho rằng copy một list tự động sao chép sâu tất cả phần tử con.

**Bài mở rộng chưa có đáp án:** Kiểm thử với list chứa dict, chứng minh shallow copy vẫn dùng chung dict bên trong; tìm khi nào cần copy.deepcopy.
