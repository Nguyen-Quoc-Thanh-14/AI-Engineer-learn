# Lời giải C03.02 — is, ==, aliasing

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm trả về bản sao list (top-level), chứng minh bằng `is not` và `==`.

## Lời giải Python

```python
def sao_chep(xs):
    return list(xs)
a = [1,2]
b = sao_chep(a)
assert b == a
assert b is not a
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Tạo hai list bằng hai literal tương đương: nội dung bằng nhau nhưng identity khác. Nếu gán `b=a`, hai tên trỏ chung đối tượng; thay đổi phần tử có thể ảnh hưởng cả hai.

**Lỗi cần tránh:** Không so sánh chuỗi/số bằng `is`: caching và interning không phải hợp đồng cho chương trình.
