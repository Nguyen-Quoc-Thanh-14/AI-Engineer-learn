# Lời giải C06.02 — collections, itertools, functools cơ bản

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm nhận hai iterable và trả list nối bằng `itertools.chain`.

## Lời giải Python

```python
from itertools import chain
def noi(a,b):
    return list(chain(a,b))
assert noi([1,2], (3,4)) == [1,2,3,4]
```

## Giải thích

Chọn đúng abstraction: dữ liệu nhỏ có thể dùng list đơn giản; xử lý nhiều chuỗi dữ liệu dùng iterator và chain; cache phải xét thay đổi trạng thái và bộ nhớ.

**Lỗi cần tránh:** Cache một hàm đọc dữ liệu thay đổi liên tục có thể trả kết quả lỗi thời; cache không phù hợp cho mọi hàm.
