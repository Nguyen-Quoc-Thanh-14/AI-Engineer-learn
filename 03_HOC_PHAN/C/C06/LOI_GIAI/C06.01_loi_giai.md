# Lời giải C06.01 — Lọc, nhóm, đếm và tổng hợp

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Nhóm tên theo chữ cái đầu, bỏ chuỗi rỗng.

## Lời giải Python

```python
from collections import defaultdict
def nhom_chu_dau(names):
    out = defaultdict(list)
    for name in names:
        if name:
            out[name[0]].append(name)
    return dict(out)
assert nhom_chu_dau(["An","Bình","Anh",""]) == {"A":["An","Anh"],"B":["Bình"]}
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Mẫu pipeline: lọc bản ghi không hợp lệ → tạo khóa → đếm/nhóm → trả cấu trúc dễ kiểm thử. Tránh biến đổi danh sách đang duyệt gây bỏ qua phần tử.

**Lỗi cần tránh:** Đừng dùng đếm dựa trên `list.count` trong vòng lặp lớn khi Counter có thể làm việc trong một lượt.
