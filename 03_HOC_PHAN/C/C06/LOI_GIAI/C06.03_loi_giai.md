# Lời giải C06.03 — Độ phức tạp thao tác list, dict và set

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm lọc các phần tử `values` thuộc `allowed` bằng cách chuyển allowed sang set để tra cứu nhanh.

## Lời giải Python

```python
def loc_duoc_phep(values, allowed):
    check = set(allowed)
    return [v for v in values if v in check]
assert loc_duoc_phep([1,2,3,1],[1,3]) == [1,3,1]
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Đầu tiên mô tả n, sau đó đếm số phép toán nổi trội; xét best/average/worst khi có khác biệt. Đừng tối ưu cú pháp trước khi chọn đúng cấu trúc dữ liệu.

**Lỗi cần tránh:** Dict/set không có bảo đảm O(1) cho mọi đầu vào; va chạm hash và tấn công có thể ảnh hưởng worst-case.
