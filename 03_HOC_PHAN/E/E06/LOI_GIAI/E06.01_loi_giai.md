# Lời giải bài tập vận dụng — E06.01 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Bổ sung `deposit` bảo toàn invariant và kiểm thử dữ liệu âm.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
class Account:
    def __init__(self, balance=0):
        if isinstance(balance,bool) or not isinstance(balance,int) or balance<0: raise ValueError
        self._balance=balance
    @property
    def balance(self): return self._balance
    def deposit(self, amount:int):
        if isinstance(amount,bool) or not isinstance(amount,int) or amount<=0: raise ValueError
        self._balance+=amount
        return self._balance
a=Account(10)
assert a.deposit(5)==15
try: a.deposit(-5)
except ValueError: pass
else: raise AssertionError
assert a.balance==15
print('PASS E06.01')
```

- Cần đối chiếu version pin của thư viện trước khi dùng với Python 3.15.2.
