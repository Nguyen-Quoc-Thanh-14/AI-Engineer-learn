# Lời giải mẫu E02.02 — Composition so với inheritance

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tạo class Report sử dụng đối tượng Formatter qua constructor, viết test fake formatter.

## Code lời giải

```python
class FakeFormatter:
    def format(self,x):return f'[{x}]'
class Report:
    def __init__(self,f):self.f=f
    def render(self,data):return self.f.format(data)
assert Report(FakeFormatter()).render('A')=='[A]'
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Trong hệ thống nhỏ, một hàm nhận dependency có thể đủ, không cần class.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
