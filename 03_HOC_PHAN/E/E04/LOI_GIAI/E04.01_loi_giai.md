# Lời giải vận dụng — E04.01

**Đề bài B:** Đổi thứ tự parent class và dự đoán chuỗi gọi dựa trên `__mro__`.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
class Root:
    def who(self): return ['Root']
class Left(Root):
    def who(self): return ['Left'] + super().who()
class Right(Root):
    def who(self): return ['Right'] + super().who()
class LeftFirst(Left, Right): pass
class RightFirst(Right, Left): pass
assert LeftFirst().who() == ['Left','Right','Root']
assert RightFirst().who() == ['Right','Left','Root']
assert LeftFirst.__mro__[:3] == (LeftFirst,Left,Right)
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
