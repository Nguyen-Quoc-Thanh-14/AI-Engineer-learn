# Lời giải vận dụng — E03.02

**Đề bài B:** Thêm `__set_name__` để dùng chung descriptor cho hai thuộc tính khác nhau.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
class NonNegative:
    def __set_name__(self, owner, name):
        self.storage_name = f"_{name}"
    def __get__(self, obj, owner=None):
        return self if obj is None else vars(obj)[self.storage_name]
    def __set__(self, obj, value):
        if isinstance(value, bool) or not isinstance(value, (int,float)) or value < 0:
            raise ValueError("must be a nonnegative number")
        vars(obj)[self.storage_name] = value
class Account:
    balance = NonNegative()
    credit_limit = NonNegative()
    def __init__(self, balance, credit_limit):
        self.balance = balance
        self.credit_limit = credit_limit
x = Account(10, 25)
assert (x.balance, x.credit_limit) == (10,25)
x.credit_limit = 0
assert x.balance == 10 and x.credit_limit == 0
try: x.balance = -0.01
except ValueError: pass
else: raise AssertionError('negative value must be rejected')
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
