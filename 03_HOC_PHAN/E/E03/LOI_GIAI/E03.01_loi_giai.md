## 1. Khái niệm và hợp đồng

Property biểu diễn hợp đồng cho một thuộc tính ở cấp đối tượng; getter được gọi khi đọc, setter được gọi khi gán. Một thuộc tính tính toán chỉ đọc có thể không cần backing field.

## 2. Lập luận trước khi viết mã

Nhất quán với bài gốc, temperature được lưu ở độ C sau khi xác thực. `kelvin` chỉ đọc và tính bằng cộng 273.15; các đầu vào NaN/Infinity bị loại vì không có ý nghĩa vật lý trong hợp đồng này. Đối chiếu chính xác bằng isclose để tránh sai số nhị phân.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/E03.01_bai_tap_da_giai_v25.py`](../MA_MAU/E03.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/E03.01_bai_tap_da_giai_v25.py
```

```python
import math

class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if type(value) not in (int, float):
            raise TypeError('nhiệt độ phải là số')
        if not math.isfinite(value) or value < -273.15:
            raise ValueError('nhiệt độ ngoài miền hợp lệ')
        self._celsius = float(value)

    @property
    def kelvin(self):
        return self._celsius + 273.15

def check():
    t = Temperature(0)
    assert math.isclose(t.kelvin, 273.15, abs_tol=1e-10)
    t.celsius = -273.15
    assert math.isclose(t.kelvin, 0, abs_tol=1e-10)
    try: t.celsius = float('nan')
    except ValueError: pass
    else: raise AssertionError('NaN phải bị từ chối')
    try: t.kelvin = 1
    except AttributeError: pass
    else: raise AssertionError('kelvin phải là read-only')

if __name__ == '__main__':
    check()
    print('OK E03.01', Temperature(0).kelvin)
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không đặt `self.celsius = value` bên trong setter `celsius`; điều đó gọi lại setter dẫn đến đệ quy vô hạn. Không dùng assert để xác thực dữ liệu không tin cậy.

**Bài mở rộng chưa có đáp án:** Thêm thuộc tính fahrenheit đọc/ghi; chứng minh phép chuyển đổi thuận nghịch trong sai số cho phép.
