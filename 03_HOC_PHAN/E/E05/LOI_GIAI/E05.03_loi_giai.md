# Lời giải bài tập vận dụng — E05.03 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Viết phiên bản class `Basket` và so sánh trade-off khi thêm yêu cầu giảm giá.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
from dataclasses import dataclass
@dataclass
class Basket:
    prices: list[int]
    def total(self, discount_percent:int=0) -> int:
        if not 0 <= discount_percent <= 100: raise ValueError('discount 0..100')
        return sum(self.prices)*(100-discount_percent)//100
def basket_total(prices, discount_percent=0): return Basket(list(prices)).total(discount_percent)
assert Basket([100,200]).total()==300
assert Basket([100,200]).total(10)==270
assert basket_total([],25)==0
print('PASS E05.03')
```
