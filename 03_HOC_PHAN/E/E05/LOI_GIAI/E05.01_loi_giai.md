# Lời giải vận dụng — E05.01

**Đề bài B:** Thêm phương thức `close()` trả về Task mới thay vì sửa task frozen.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
from dataclasses import dataclass, replace
from enum import Enum
class Status(Enum): OPEN='open'; CLOSED='closed'
@dataclass(frozen=True)
class Task:
    name: str
    status: Status = Status.OPEN
    def close(self): return replace(self, status=Status.CLOSED)
t = Task('review'); closed=t.close()
assert t.status is Status.OPEN
assert closed.status is Status.CLOSED and closed is not t
assert t.close()==closed
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
