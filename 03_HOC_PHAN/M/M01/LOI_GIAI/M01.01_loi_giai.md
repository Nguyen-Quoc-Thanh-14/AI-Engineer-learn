# Lời giải mẫu M01.01 — TCP/IP, DNS và socket nhập môn

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Thiết kế giao thức length-prefixed với 4-byte header; giải thích recv có thể trả ít hơn yêu cầu.

## Code lời giải

```python
import struct
payload=b'hello'
wire=struct.pack('!I',len(payload))+payload
assert struct.unpack('!I',wire[:4])[0]==5
assert wire[4:]==payload
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Bài lab offline dùng `socket.socketpair()` trên hệ hỗ trợ để truyền bytes; thực tế TCP cần framing để xác định ranh giới thông điệp. Ví dụ chỉ minh họa bytes qua socket, không cần mạng ngoài.

**Giới hạn:** Kết nối có thể timeout, đứt giữa chừng, trả dữ liệu rỗng khi peer đóng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
