# Hướng dẫn và mẫu kiểm chứng — M06.03

**Trạng thái:** HƯỚNG DẪN / MẪU THAM KHẢO, **chưa phải lời giải độc lập hoàn chỉnh** cho bài vận dụng.

## Cách tiếp cận

1. Xác định tiền điều kiện và hậu điều kiện cho bài tập.
2. Giữ nguyên invariant và contract của phần lý thuyết.
3. Tạo test ca thường, ca biên và dữ liệu lỗi; không dùng kết quả một test duy nhất làm bằng chứng đầy đủ.
4. Đối chiếu với mã minh họa đã chạy (xem `../MA_MAU/M06.03_demo.py`).

## Mẫu tham khảo đã kiểm tra trong môi trường hiện tại

```python
import sqlite3
with sqlite3.connect(':memory:') as db:
    db.execute('CREATE TABLE flags(id INTEGER PRIMARY KEY)')
    db.execute('INSERT INTO flags VALUES (1)')
    assert db.execute('SELECT COUNT(*) FROM flags').fetchone()[0]==1
```

**Nhiệm vụ còn mở:** Viết lời giải khác ví dụ mẫu cho yêu cầu: Viết integration test API tạo tài nguyên rồi đọc lại, rollback DB fixture sau test.
