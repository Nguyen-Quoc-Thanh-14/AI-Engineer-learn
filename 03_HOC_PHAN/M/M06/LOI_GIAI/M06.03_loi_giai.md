# M06.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết integration test API tạo tài nguyên rồi đọc lại, rollback DB fixture sau test.

**Integration flow:** create isolated test database → POST `/items` with valid payload → expect 201 + generated ID → GET `/items/{id}` → expect 200 and same representation → POST invalid payload → expect 422/400 by contract → rollback fixture after test. Stub external payment/email services; do not mock the database when claiming database integration. Track request ID across application logs and assertions. Include at least one 403 unauthorized ownership test.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
