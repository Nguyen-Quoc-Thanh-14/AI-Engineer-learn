# M06.03 — Lời giải B: API POST/GET và SQLite rollback thực

**Đề bài:** Viết integration test API tạo tài nguyên rồi đọc lại, rollback DB fixture sau test.

[Mã HTTP/SQLite nguồn-bound](../MA_MAU/M06.03_bai_B_http_sqlite.py) tạo một HTTP server loopback thật trên cổng tạm, dùng SQLite `:memory:` và mở transaction. Client POST `/items` nhận `201` cùng ID, GET `/items/{id}` trả `200` và dữ liệu tương ứng. Test còn kiểm `400` cho payload lỗi, `404` cho ID thiếu, `401` cho thiếu token và `403` cho khác chủ sở hữu. Transaction được rollback khi kết thúc fixture; kiểm số bản ghi bằng truy vấn SQL thật thay vì mock DB.

**Kiểm thử:** `python -m unittest discover -s tests -p 'test_issue9_m0603_http_sqlite.py' -v` từ gốc repository. Bốn test gồm ca chuẩn/rollback, dữ liệu lỗi, chặn truy cập chéo owner và thiếu xác thực.

**Giới hạn:** chỉ là lab chạy localhost với token **tổng hợp** hard-code và HTTPServer Python, không phải sản phẩm có authentication/CSRF/session/TLS thực, không chứng minh hoạt động trên FastAPI/PostgreSQL hay chịu tải production.
