# M07.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thiết kế kế hoạch đổi trường name → display_name trong 3 bản phát hành.

**Mã chạy riêng:** [M07.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/M07.01_bai_B_solution.py)

```python
# Expand-and-contract: release 1 read old + new; release 2 write both; release 3 stop old.
def rename_compat(record):
    if 'display_name' in record:return record['display_name']
    if 'name' in record:return record['name']
    raise ValueError('missing display name')
assert rename_compat({'name':'old'})=='old'
assert rename_compat({'display_name':'new','name':'old'})=='new'
try:rename_compat({})
except ValueError:pass
else:raise AssertionError('missing field accepted')
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
