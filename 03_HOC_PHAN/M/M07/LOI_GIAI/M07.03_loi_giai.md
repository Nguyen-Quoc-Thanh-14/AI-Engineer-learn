# Lời giải bài tập vận dụng — M07.03 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Thiết kế chuyển tiền 2 tài khoản: invariant tổng không đổi và rollback nếu giao dịch thất bại.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
import sqlite3
c=sqlite3.connect(':memory:');c.execute('CREATE TABLE acc(id INT PRIMARY KEY, balance INT CHECK(balance>=0))')
c.executemany('INSERT INTO acc VALUES(?,?)',[(1,100),(2,50)])
def transfer(src,dst,amount):
    if amount<=0:raise ValueError
    with c:
        n=c.execute('UPDATE acc SET balance=balance-? WHERE id=? AND balance>=?',(amount,src,amount)).rowcount
        if n!=1:raise ValueError('insufficient')
        n=c.execute('UPDATE acc SET balance=balance+? WHERE id=?',(amount,dst)).rowcount
        if n!=1:raise ValueError('missing receiver')
transfer(1,2,20)
assert c.execute('SELECT SUM(balance) FROM acc').fetchone()[0]==150
try:transfer(1,9,10)
except ValueError:pass
else:raise AssertionError
assert c.execute('SELECT balance FROM acc WHERE id=1').fetchone()[0]==80
c.close();print('PASS M07.03')
```

## Phản biện kỹ thuật và giới hạn

- Không suy ra tính đúng với mọi đầu vào từ các `assert` này; bổ sung property-based tests, kiểm thử đầu vào lỗi và tests hồi quy khi triển khai dự án.
- Cần đối chiếu version pin của thư viện trước khi dùng với Python 3.15.2.
- Tránh coi kiểm thử minh họa là xác nhận chất lượng/hiệu năng/bảo mật khi chạy thực tế.
