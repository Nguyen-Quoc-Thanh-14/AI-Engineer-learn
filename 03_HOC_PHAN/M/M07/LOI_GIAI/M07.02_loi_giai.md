# M07.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Vẽ flow authorization code + PKCE và đánh dấu trust boundaries.

**OAuth2 authorization-code + PKCE flow:** (1) client creates cryptographically random `code_verifier`, derives `code_challenge` (S256); (2) redirects browser to authorization server with state, redirect URI and challenge; (3) validates returned `state`; (4) exchanges code + verifier using TLS; (5) validates audience/issuer/expiry/scope according to token format and server policy; (6) API checks resource ownership separately. Trust boundaries: browser ↔ authorization server, client ↔ token endpoint, API ↔ identity provider. PKCE does not replace access controls or HTTPS.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
