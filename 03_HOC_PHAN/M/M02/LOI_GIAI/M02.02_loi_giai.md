# Lời giải bài tập vận dụng — M02.02 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Thiết kế retry policy cho GET với status 429/503, deadline và jitter có seed.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
import random
def retry_get(request, *, max_attempts=4, seed=7):
    rng=random.Random(seed); delays=[]
    for attempt in range(max_attempts):
        status,body=request(attempt)
        if status==200:return body,delays
        if status not in {429,503}:raise RuntimeError(f'unretryable {status}')
        if attempt==max_attempts-1:break
        delays.append(min(2**attempt,4)+rng.random()*.1)
    raise TimeoutError('exhausted retry budget')
assert retry_get(lambda n:(503,None) if n==0 else (200,'ok'))[0]=='ok'
assert retry_get(lambda n:(200,'x'))[1]==[]
try:retry_get(lambda n:(400,None))
except RuntimeError:pass
else:raise AssertionError
print('PASS M02.02')
```

- Cần đối chiếu version pin của thư viện trước khi dùng với Python 3.15.2.
