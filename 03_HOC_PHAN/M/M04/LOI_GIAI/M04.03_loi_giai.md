# Lời giải mẫu M04.03 — Transactions và isolation levels

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết transaction gồm hai INSERT rồi chủ động lỗi; kiểm tra rollback.

## Code lời giải

```python
import sqlite3
c=sqlite3.connect(':memory:')
c.execute('create table t(x integer)')
try:
    with c:
        c.execute('insert into t values (?)',(10,))
        raise RuntimeError()
except RuntimeError:pass
assert c.execute('select count(*) from t').fetchone()[0]==0
c.close()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Đặc tả autocommit thay đổi theo API và chế độ; cần khóa chính và constraint đúng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
