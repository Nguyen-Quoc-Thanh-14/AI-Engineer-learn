## 1. Khái niệm và hợp đồng

Parameterized query tách văn bản SQL khỏi dữ liệu đầu vào; sqlite3 gắn giá trị qua placeholder ? nên dữ liệu chứa dấu nháy không thể trở thành cú pháp SQL.

## 2. Lập luận trước khi viết mã

Tạo bảng trong SQLite in-memory và chèn bản ghi bằng câu lệnh tham số. Truy vấn tên dữ liệu cố ý giống payload injection phải tìm đúng bằng equality, không được tự nối chuỗi SQL từ đầu vào.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/M04.01_bai_tap_da_giai_v25.py`](../MA_MAU/M04.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/M04.01_bai_tap_da_giai_v25.py
```

```python
import sqlite3

def create_db():
    db = sqlite3.connect(':memory:')
    db.execute('CREATE TABLE people (id INTEGER PRIMARY KEY, name TEXT NOT NULL UNIQUE)')
    return db

def add_person(db, name):
    if not isinstance(name, str) or not name:
        raise ValueError('tên phải là chuỗi không rỗng')
    db.execute('INSERT INTO people(name) VALUES (?)', (name,))
    db.commit()

def find_person(db, name):
    return db.execute('SELECT name FROM people WHERE name = ?', (name,)).fetchall()

def check():
    with create_db() as db:
        add_person(db, 'Alice')
        add_person(db, "' OR 1=1 --")
        assert find_person(db, 'Alice') == [('Alice',)]
        assert find_person(db, "' OR 1=1 --") == [("' OR 1=1 --",)]
        assert find_person(db, 'nobody') == []
        try: add_person(db, '')
        except ValueError: pass
        else: raise AssertionError('tên rỗng')

if __name__ == '__main__':
    check()
    print('OK M04.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Placeholder chỉ dùng được cho giá trị, không dùng cho tên bảng/cột. Nếu cần identifier do người dùng chọn, phải áp dụng allowlist và quote identifier đúng cách.

**Bài mở rộng chưa có đáp án:** Thêm UNIQUE constraint cho tên và bắt IntegrityError; giải thích transaction rollback khi ghi hàng loạt.
