# M05.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết checklist migrate thêm cột NOT NULL vào bảng hàng triệu bản ghi mà không downtime.

**Zero-downtime NOT NULL migration:** 1. add nullable new column without rewriting entire huge table when supported; 2. deploy backward-compatible writers populating both fields; 3. backfill existing records in bounded batches with checkpoints; 4. validate no nulls and dual read paths; 5. add database constraint using engine-specific online capability; 6. deploy readers that rely on the new field; 7. remove old field in a later release. Design rollback for every stage and rehearse lock behavior on staging. Do not claim all DDL is online across DB engines.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
