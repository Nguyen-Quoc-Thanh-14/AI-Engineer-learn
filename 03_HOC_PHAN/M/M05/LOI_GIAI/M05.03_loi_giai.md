# M05.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Lập test assert số query <=2 khi tải orders cho 100 users bằng ORM.

**Regression test design:** seed 100 users with 2 orders each; reset SQL query counter; fetch users with their orders and access all order collections. Assert query count ≤2 with explicit eager-loading (`selectinload`/joined strategy as appropriate); compare with intentionally lazy N+1 case (typically 101 queries). Record ORM version, DB backend and whether SQL logs include setup queries. Pure-Python in-memory lists cannot validate ORM N+1 behavior.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
