## Cách tiếp cận

1. Xác định tiền điều kiện và hậu điều kiện cho bài tập.
2. Giữ nguyên invariant và contract của phần lý thuyết.
3. Tạo test ca thường, ca biên và dữ liệu lỗi; không dùng kết quả một test duy nhất làm bằng chứng đầy đủ.
4. Đối chiếu với mã minh họa đã chạy (xem `../MA_MAU/M05.02_demo.py`).

## Mẫu tham khảo đã kiểm tra trong môi trường hiện tại

```python
import sqlite3
with sqlite3.connect(':memory:') as db:
    db.execute('CREATE TABLE users(id INTEGER PRIMARY KEY)')
    db.execute('ALTER TABLE users ADD COLUMN active INTEGER DEFAULT 1')
    db.execute('INSERT INTO users(id) VALUES (3)')
    assert db.execute('SELECT active FROM users').fetchone()[0]==1
```

**Nhiệm vụ còn mở:** Viết lời giải khác ví dụ mẫu cho yêu cầu: Viết checklist migrate thêm cột NOT NULL vào bảng hàng triệu bản ghi mà không downtime.
