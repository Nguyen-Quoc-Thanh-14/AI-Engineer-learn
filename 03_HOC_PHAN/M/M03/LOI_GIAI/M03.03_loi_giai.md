# Lời giải bài tập vận dụng — M03.03 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Tạo index cho cột truy vấn, dùng EXPLAIN QUERY PLAN và giải thích trade-off khi insert.

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
import sqlite3
c=sqlite3.connect(':memory:')
c.execute('CREATE TABLE events(id INTEGER PRIMARY KEY,category TEXT)')
c.executemany('INSERT INTO events(category) VALUES(?)',[('x',)]*20+[('y',)]*20)
c.execute('CREATE INDEX idx_events_cat ON events(category)')
plan=' '.join(str(x) for x in c.execute('EXPLAIN QUERY PLAN SELECT * FROM events WHERE category=?',('x',)))
assert 'idx_events_cat' in plan
assert c.execute('SELECT COUNT(*) FROM events WHERE category=?',('x',)).fetchone()[0]==20
assert c.execute('SELECT COUNT(*) FROM events').fetchone()[0]==40
c.close();print('PASS M03.03')
```
