# Lời giải bài tập vận dụng — M03.02 (v2.7)

**Đề bài B (từ bản gốc v2.6):** Viết LEFT JOIN hiển thị user không có orders và phân biệt COUNT(*), COUNT(order_id).

**Trạng thái kiểm định:** Mã dưới đây đã chạy dưới tiến trình Python 3.13.5 độc lập, không có lỗi ngoài dự kiến. Đây là kiểm thử minh họa trên dữ liệu xác định, không phải bằng chứng tương thích 3.15.2 hoặc mọi hệ điều hành/thư viện.

## Thiết kế và giả định

Lời giải triển khai trường hợp sử dụng xác định theo yêu cầu bài B. Các `assert` minh họa tối thiểu ca chuẩn, ca biên hoặc từ chối đầu vào sai khi thích hợp; bài sử dụng công cụ/thư viện ngoài vẫn phải được kiểm thử trên môi trường đích.

## Mã hoàn chỉnh

```python
import sqlite3
c=sqlite3.connect(':memory:')
c.executescript('CREATE TABLE users(id INT PRIMARY KEY); CREATE TABLE orders(id INT PRIMARY KEY,uid INT);'
'INSERT INTO users VALUES(1),(2); INSERT INTO orders VALUES(9,1),(10,1);')
rows=c.execute('SELECT u.id,COUNT(*),COUNT(o.id) FROM users u LEFT JOIN orders o ON o.uid=u.id GROUP BY u.id ORDER BY u.id').fetchall()
assert rows==[(1,2,2),(2,1,0)]
assert rows[1][1]!=rows[1][2]
assert len(rows)==2
c.close();print('PASS M03.02')
```
