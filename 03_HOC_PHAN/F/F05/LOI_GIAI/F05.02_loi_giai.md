# F05.02 — Đáp án B: thứ tự side effect của eager và lazy import

**Đề bài:** Tạo module có log khi import và so sánh thời điểm xuất log với eager import.

[Mã B tái lập bằng Python 3.15](../MA_MAU/F05.02_bai_B_import_order.py) tạo một module tạm có dòng MODULE_INITIALIZED khi import. Mỗi phép thử chạy trong **một subprocess mới**, để sys.modules không vô tình che tác dụng phụ. Phép đo chỉ ghi stdout theo thứ tự chính xác.

| Tình huống | Thứ tự stdout kỳ vọng |
|---|---|
| eager import và truy cập | MODULE_INITIALIZED → MAIN_BEFORE → VALUE 7 |
| lazy import và truy cập | MAIN_BEFORE → MODULE_INITIALIZED → VALUE 7 |
| lazy import nhưng không truy cập | MAIN_BEFORE → MAIN_AFTER (không có MODULE_INITIALIZED) |
| eager import module lỗi | Lỗi trước MAIN_BEFORE |
| lazy import module lỗi | MAIN_BEFORE rồi mới phát sinh lỗi |

**Cách chạy:** `python 03_HOC_PHAN/F/F05/MA_MAU/F05.02_bai_B_import_order.py`, tiếp theo `python -m unittest discover -s tests -p 'test_issue9_f0502_lazy_import.py' -v`. Mã yêu cầu CPython 3.15. Các kiểm thử được ràng buộc với file B thực, không dùng mock thay lazy import.

**Giới hạn:** Đây là kiểm tra thứ tự khởi tạo cho module cụ thể, không chứng minh khả năng tương thích lazy from, benchmark tốc độ hoặc tất cả side effects. Kết quả runtime phải đối chiếu workflow thực tế cùng SHA; không phải phản biện chuyên gia độc lập.
