## 1. Khái niệm và hợp đồng

Mỗi module là một namespace; import gắn đối tượng module hoặc một tên tham chiếu vào namespace hiện tại. sys.modules lưu cache các module đã nạp.

## 2. Lập luận trước khi viết mã

Phân biệt `import math` với `from math import sqrt`: cách đầu gắn tên math; cách sau gắn tên sqrt tại module gọi. importlib.import_module giúp import động theo chuỗi, nhưng chỉ nên nhận tên module đã allowlist nếu đầu vào có thể do người dùng kiểm soát.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/F01.01_bai_tap_da_giai_v25.py`](../MA_MAU/F01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/F01.01_bai_tap_da_giai_v25.py
```

```python
import importlib
import math
import sys

def square_root(x):
    if type(x) not in (int, float):
        raise TypeError('cần số')
    if x < 0:
        raise ValueError('căn thực không xác định cho số âm')
    module = importlib.import_module('math')
    return module.sqrt(x)

def check():
    assert square_root(9) == 3.0
    assert square_root(0) == 0.0
    assert importlib.import_module('math') is math
    assert sys.modules['math'] is math
    try: square_root(-1)
    except ValueError: pass
    else: raise AssertionError('miền âm')
    try: importlib.import_module('not_a_real_module_93486')
    except ModuleNotFoundError: pass
    else: raise AssertionError('module không tồn tại')

if __name__ == '__main__':
    check()
    print('OK F01.01', square_root(9))
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không cho rằng `from m import name` tạo một liên kết động luôn theo sát việc gán lại m.name. Nó chỉ lấy tham chiếu vào đối tượng tại thời điểm import.

**Bài mở rộng chưa có đáp án:** Tạo module `config.py` với một hằng số, nhập nó từ file main và chỉ ra khác biệt giữa import cache và reload.
