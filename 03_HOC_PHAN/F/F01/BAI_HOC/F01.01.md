## 2. Khái niệm — Bản chất

Mỗi module thường có namespace riêng, được nhập qua `import`. Code ở module-level có thể được thực thi trong lần import đầu tiên ở interpreter hiện tại và module được cache trong `sys.modules`.

## 3. Nguyên lý và cơ chế từng bước

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

## 4. Ví dụ tối thiểu có thể chạy

```python
import math
assert math.isqrt(16)==4
assert 'math' in __import__('sys').modules
print(math.pi > 3)
```

## 5. Trường hợp biên, lỗi thường gặp và hướng debug

- **Ngộ nhận:** Không đặt file của mình là `json.py`, `math.py`, `typing.py` vì có thể shadow standard library.
- **Trường hợp biên:** Module import lỗi ở top-level có thể khiến cả lệnh import thất bại.
- **Debug có phương pháp:** xác định hợp đồng → tái hiện lỗi bằng đầu vào tối thiểu → đọc traceback/kiểm tra trạng thái → sửa → thêm regression test.

## 11. Bài chuyên sâu bổ sung v2.5 — kiểm định bằng chương trình thực thi

> **Kết quả:** Đã chạy thành công lời giải độc lập trên Python 3.13.5 tại thời điểm xuất bản v2.5. **Chưa kiểm định trực tiếp trên CPython 3.15.2; chưa qua phản biện sư phạm độc lập.**

### Nguyên lý cần nắm

Mỗi module là một namespace; import gắn đối tượng module hoặc một tên tham chiếu vào namespace hiện tại. sys.modules lưu cache các module đã nạp.

### Cách suy luận và thiết kế lời giải

Phân biệt `import math` với `from math import sqrt`: cách đầu gắn tên math; cách sau gắn tên sqrt tại module gọi. importlib.import_module giúp import động theo chuỗi, nhưng chỉ nên nhận tên module đã allowlist nếu đầu vào có thể do người dùng kiểm soát.

### Phản ví dụ và ngộ nhận cần tránh

Không cho rằng `from m import name` tạo một liên kết động luôn theo sát việc gán lại m.name. Nó chỉ lấy tham chiếu vào đối tượng tại thời điểm import.

### Lộ trình tự kiểm tra

1. Đọc yêu cầu bài tập ở trên, tự viết lời giải **trước khi mở đáp án**.
2. Dự đoán đầu ra các trường hợp bình thường, biên và không hợp lệ; nói rõ từng precondition, hậu điều kiện.
3. Chạy mã độc lập [`F01.01_bai_tap_da_giai_v25.py`](../MA_MAU/F01.01_bai_tap_da_giai_v25.py) để đối chiếu.
4. Kiểm tra lời giải chi tiết: [`F01.01_loi_giai.md`](../LOI_GIAI/F01.01_loi_giai.md).
5. **Bài mở rộng:** Tạo module `config.py` với một hằng số, nhập nó từ file main và chỉ ra khác biệt giữa import cache và reload.
