## 2. Khái niệm — Bản chất

Khi import, Python tra cứu import path theo cấu hình và import system; `sys.path` là một đầu vào quan trọng nhưng không phải toàn bộ cơ chế. Tránh sửa sys.path tùy tiện trong mã ứng dụng.

## 3. Nguyên lý và cơ chế từng bước

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

## 4. Ví dụ tối thiểu có thể chạy

```python
import sys
assert isinstance(sys.path,list)
print('Độ dài import path:',len(sys.path)>0)
```

**Kết quả kiểm thử cục bộ:** pass trên Python 3.13.5.

```text
Độ dài import path: True
```

**Thực hành:** chạy file `07_MA_VI_DU/F01.03_vi_du.py` từ thư mục gốc giáo trình rồi sửa một tham số để dự đoán sự khác biệt.

## 5. Trường hợp biên, lỗi thường gặp và hướng debug

- **Ngộ nhận:** Module local trùng tên package được cài làm import trỏ sai nơi.
- **Trường hợp biên:** Chạy từ working directory khác nhau có thể phơi bày lỗi đóng gói dự án.
- **Debug có phương pháp:** xác định hợp đồng → tái hiện lỗi bằng đầu vào tối thiểu → đọc traceback/kiểm tra trạng thái → sửa → thêm regression test.
