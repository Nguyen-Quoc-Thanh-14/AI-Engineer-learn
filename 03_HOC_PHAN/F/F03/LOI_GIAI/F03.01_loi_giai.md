# F03.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Ghi chính xác chuỗi lệnh tạo venv trên Windows và Linux/macOS; giải thích `python -m pip --version`.

**Linux/macOS:** `python3.15 -m venv .venv`, `. .venv/bin/activate`, `python -m pip --version`.
**Windows PowerShell:** `py -3.15 -m venv .venv`, `.\.venv\Scripts\Activate.ps1`, `python -m pip --version` (requires 3.15 installed and launcher's version selection supported).
**Verify:** `python -c "import sys;print(sys.executable);print(sys.prefix!=sys.base_prefix)"` must print a `.venv` interpreter path and `True`. `python -m pip --version` must report a pip installation belonging to that venv, not the global Python. Do not change system execution policy without a justified organizational policy.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
