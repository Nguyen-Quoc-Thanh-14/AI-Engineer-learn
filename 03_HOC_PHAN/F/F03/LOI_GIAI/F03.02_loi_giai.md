# F03.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết mô hình checklist lockfile; phân biệt pin ứng dụng và thư viện phát hành.

**For applications:** fix the interpreter minor version, use a lockfile produced by a chosen tool, record exact transitive dependencies and hashes when supported, and run a clean install in CI. Verify lockfile is committed; fail a build when resolution would mutate it.
**For libraries:** publish tested version ranges in metadata, avoid overly restrictive top-level pins except for known incompatibilities; lock a separate development/test environment.
**Acceptance:** create a fresh virtual environment twice from the lock and compare `pip freeze` outputs; record OS/interpreter markers and note that platform-specific wheels can differ. A lock does not guarantee deterministic behavior if external data, hardware, timezone or network APIs differ.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
