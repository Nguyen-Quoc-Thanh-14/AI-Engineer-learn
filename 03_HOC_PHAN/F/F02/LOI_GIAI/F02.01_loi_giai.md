# F02.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Phác cấu trúc `src/app/__init__.py`, `tests/test_core.py`, `pyproject.toml`; giải thích cách chạy `python -m pytest`.

```text
sample-project/
├── pyproject.toml
├── src/sample_project/__init__.py
├── src/sample_project/core.py
└── tests/test_core.py
```
`pyproject.toml`: `[build-system]` requires setuptools; `[project]` defines `name="sample-project"`, `version="0.1.0"`, `requires-python=">=3.14"`.
`core.py`: `def square(x: int) -> int: return x*x`. `test_core.py`: `from sample_project.core import square; assert square(-2)==4`.
Create a virtual environment, install editable project (`python -m pip install -e . pytest`), then `python -m pytest -q`. A src-layout prevents importing the local tree accidentally when tests should exercise an installed package.
**Acceptance:** running tests from an independent working directory must succeed; `python -c 'import sample_project; print(sample_project.__file__)'` should resolve the installed editable package.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
