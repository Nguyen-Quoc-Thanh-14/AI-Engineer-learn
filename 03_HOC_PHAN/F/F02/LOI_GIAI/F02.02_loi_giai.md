# Lời giải vận dụng — F02.02

**Đề bài B:** Thêm validation tax_rate trong Config, kiểm thử giá trị âm.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
from dataclasses import dataclass
from math import isfinite
@dataclass(frozen=True)
class Config:
    tax_rate: float
    def __post_init__(self):
        if isinstance(self.tax_rate,bool) or not isinstance(self.tax_rate,(float,int)) or not isfinite(self.tax_rate) or not (0 <= self.tax_rate <= 1):
            raise ValueError('tax_rate must be between 0 and 1')
assert Config(0.1).tax_rate==0.1
assert Config(0).tax_rate==0
for bad in (-0.1, 1.01, float('nan')):
    try: Config(bad)
    except ValueError: pass
    else: raise AssertionError('invalid tax rate accepted')
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
