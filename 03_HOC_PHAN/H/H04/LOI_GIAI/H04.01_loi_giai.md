# H04.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Dùng pdb trong local để xem call stack khi b=0, ghi lại nguyên nhân thay vì sửa bằng except: pass.

Minimal reproduction:
```python
def ratio(a,b):
    return a/b
ratio(10,0)
```
Start `python -m pdb script.py`, set `b ratio`, continue and inspect `p b`, `where`, `up`, `down`. The observable root cause is that the denominator is zero, not that Python failed to handle an exception. Fix by defining the contract and rejecting zero before division (or returning domain-specific failure). Add regression tests for `b=2`, `b=-1`, `b=0`. Never use `except: pass` as a substitute for debugging.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
