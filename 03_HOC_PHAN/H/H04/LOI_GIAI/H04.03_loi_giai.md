# H04.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết test flaky do time.sleep ngắn, rồi thay bằng synchronization hoặc fake clock.

**Mã chạy riêng:** [H04.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/H04.03_bai_B_solution.py)

```python
from threading import Event,Thread
# Avoid relying on time.sleep; explicitly coordinate observable completion.
ready=Event();done=Event();results=[]
def worker():
    ready.wait(timeout=2);results.append('ok');done.set()
t=Thread(target=worker);t.start();ready.set()
assert done.wait(timeout=2)
t.join(timeout=2);assert not t.is_alive() and results==['ok']
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
