## 1. Khái niệm và hợp đồng

Arrange–Act–Assert tách chuẩn bị dữ liệu, thao tác và kiểm tra kỳ vọng; ca thử tốt mô tả hợp đồng, không chỉ gọi hàm rồi không kiểm tra gì.

## 2. Lập luận trước khi viết mã

Đặt kiểm thử trong unittest, mỗi ca có tên nêu tình huống; ca sai kiểu kiểm tra ngoại lệ chính xác. Khi thay đổi logic normalize_username, các test trở thành regression suite giúp phát hiện thay đổi hành vi.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/H02.01_bai_tap_da_giai_v25.py`](../MA_MAU/H02.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/H02.01_bai_tap_da_giai_v25.py
```

```python
import unittest

def normalize_username(name: str) -> str:
    if not isinstance(name, str):
        raise TypeError('name phải là str')
    result = name.strip().lower()
    if not result:
        raise ValueError('không được trống')
    return result

class UsernameTests(unittest.TestCase):
    def test_regular(self):
        # Arrange
        raw = '  Alice  '
        # Act
        result = normalize_username(raw)
        # Assert
        self.assertEqual(result, 'alice')

    def test_boundary(self):
        self.assertEqual(normalize_username(' A '), 'a')

    def test_invalid(self):
        with self.assertRaises(ValueError):
            normalize_username('   ')
        with self.assertRaises(TypeError):
            normalize_username(None)

def check():
    suite = unittest.defaultTestLoader.loadTestsFromTestCase(UsernameTests)
    result = unittest.TestResult()
    suite.run(result)
    assert result.wasSuccessful() and result.testsRun == 3

if __name__ == '__main__':
    check()
    print('OK H02.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Đừng dùng `try: ... except Exception: pass` khi cần kiểm thử ngoại lệ vì có thể che lỗi không liên quan; hãy dùng assertRaises với đúng loại lỗi.

**Bài mở rộng chưa có đáp án:** Tạo thêm test cho Unicode casefold (ví dụ một tên tiếng Đức) và so sánh với `.lower()`; xác định hợp đồng của hệ thống tài khoản trước khi áp dụng.
