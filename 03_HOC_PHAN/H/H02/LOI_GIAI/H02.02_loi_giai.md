# Lời giải mẫu H02.02 — unittest và pytest

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết một unittest.TestCase kiểm tra hàm nhân; nêu cách chạy `python -m unittest`.

## Code lời giải

```python
import unittest
def nhan(x,y):return x*y
class TestNhan(unittest.TestCase):
    def test_0(self):self.assertEqual(nhan(4,0),0)
r=unittest.TestResult();TestNhan('test_0').run(r)
assert r.wasSuccessful()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Chưa cài pytest không có nghĩa unittest không chạy được.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
