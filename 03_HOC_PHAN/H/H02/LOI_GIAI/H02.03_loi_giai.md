# Lời giải mẫu H02.03 — Boundary cases và regression tests

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết test 0, 1, max, max+1 cho hàm nhận điểm 0..10.

## Code lời giải

```python
def hop_le(diem):
    return isinstance(diem,(int,float)) and not isinstance(diem,bool) and 0<=diem<=10
assert hop_le(0) and hop_le(10)
assert not hop_le(-1) and not hop_le(11)
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Một test regression có thể trở thành lỗi thời nếu đặc tả thay đổi; sửa test cùng đặc tả.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
