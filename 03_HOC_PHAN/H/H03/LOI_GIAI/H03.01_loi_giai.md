# Lời giải vận dụng — H03.01

**Đề bài B:** Viết test pytest fixture trả dict rỗng và parametrized cases thêm/xóa item.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
# Chạy cùng pytest: python -m pytest -q <file>
import pytest
@pytest.fixture
def inventory(): return {}
@pytest.mark.parametrize('name,amount', [('a',1),('b',0),('c',4)])
def test_add(inventory,name,amount):
    inventory[name]=amount
    assert inventory[name]==amount
@pytest.mark.parametrize('value', ['a','b','c'])
def test_delete(inventory,value):
    inventory[value]=1
    del inventory[value]
    assert value not in inventory
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
