# Hướng dẫn và mẫu kiểm chứng — H03.02

**Trạng thái:** HƯỚNG DẪN / MẪU THAM KHẢO, **chưa phải lời giải độc lập hoàn chỉnh** cho bài vận dụng.

## Cách tiếp cận

1. Xác định tiền điều kiện và hậu điều kiện cho bài tập.
2. Giữ nguyên invariant và contract của phần lý thuyết.
3. Tạo test ca thường, ca biên và dữ liệu lỗi; không dùng kết quả một test duy nhất làm bằng chứng đầy đủ.
4. Đối chiếu với mã minh họa đã chạy (xem `../MA_MAU/H03.02_demo.py`).

## Mẫu tham khảo đã kiểm tra trong môi trường hiện tại

```python
from unittest.mock import Mock
mailer = Mock()
def signup(email, send):
    send(email, 'welcome')
signup('x@example.com', mailer)
mailer.assert_called_once_with('x@example.com', 'welcome')
```

**Nhiệm vụ còn mở:** Viết lời giải khác ví dụ mẫu cho yêu cầu: Thử test fake repository và integration test sqlite :memory: để so sánh.
