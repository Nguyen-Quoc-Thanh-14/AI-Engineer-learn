## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thử test fake repository và integration test sqlite :memory: để so sánh.

**Mã chạy riêng:** [H03.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/H03.02_bai_B_solution.py)

```python
from dataclasses import dataclass
import sqlite3
@dataclass
class Item: name: str
class FakeRepo:
    def __init__(self): self.data=[]
    def add(self,x): self.data.append(x)
    def all(self): return self.data[:]
class SQLiteRepo:
    def __init__(self,db): self.db=db;db.execute('CREATE TABLE item(name TEXT NOT NULL)')
    def add(self,x): self.db.execute('INSERT INTO item VALUES (?)',(x.name,))
    def all(self): return [Item(x[0]) for x in self.db.execute('SELECT name FROM item')]
for repo in (FakeRepo(),SQLiteRepo(sqlite3.connect(':memory:'))):
    repo.add(Item('coffee'));assert repo.all()==[Item('coffee')]
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
