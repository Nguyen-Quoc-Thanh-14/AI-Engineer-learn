# Lời giải vận dụng — H03.03

**Đề bài B:** Viết property cho hàm decode/encode UTF-8 với chuỗi Unicode hợp lệ.

**Phương án:** cài đặt chức năng theo hợp đồng; kiểm tra ca thường, ca biên và ca lỗi.

```python
# Property roundtrip UTF-8: thử các nhóm Unicode đại diện, không thay thế Hypothesis.
import unittest

class Utf8RoundtripTests(unittest.TestCase):
    def test_roundtrip_multiple_unicode_ranges(self):
        examples = ['', 'Tiếng Việt', '🌏', '\u0301', 'a\u0301', '𐐷', '\x00']
        for text in examples:
            with self.subTest(text=repr(text)):
                self.assertEqual(text.encode('utf-8').decode('utf-8'), text)

    def test_invalid_utf8(self):
        with self.assertRaises(UnicodeDecodeError):
            b'\xff'.decode('utf-8')

    def test_roundtrip_generated_scalars(self):
        for codepoint in range(0, 0x110000, 1229):
            if 0xD800 <= codepoint <= 0xDFFF:
                continue
            value = chr(codepoint)
            self.assertEqual(value.encode('utf-8').decode('utf-8'), value)

if __name__ == '__main__':
    unittest.main()
```

**Giới hạn:** Chạy trên Python 3.13.5; không đồng nghĩa đã chạy trên CPython 3.15.2. Với mã dùng pytest/Hypothesis, cần cài phụ thuộc trong môi trường thử.

**Phản biện:** xem xét contract, trường hợp rỗng, tác dụng phụ và khả năng mở rộng; không chỉ dựa một assertion.
