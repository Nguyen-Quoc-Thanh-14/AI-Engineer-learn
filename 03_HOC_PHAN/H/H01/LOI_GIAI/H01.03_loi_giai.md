# Lời giải mẫu H01.03 — Custom exception và exception chaining

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Viết lỗi `LoiDonHang` và ánh xạ từ ValueError với chaining.

## Code lời giải

```python
class LoiDonHang(Exception):pass
def so_luong(x):
    try:v=int(x)
    except ValueError as e:raise LoiDonHang('khong phai so') from e
    if v<0:raise LoiDonHang('am')
    return v
assert so_luong('2')==2
try:so_luong('x')
except LoiDonHang as e:assert e.__cause__ is not None
else:raise AssertionError()
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Không đưa secret vào message exception/log.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
