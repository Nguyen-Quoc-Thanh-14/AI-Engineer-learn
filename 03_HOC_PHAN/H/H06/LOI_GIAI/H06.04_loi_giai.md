# H06.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế ma trận 3.14 × 3.15 và Linux × Windows; nêu điều kiện skip rõ ràng.

```yaml
strategy:
  fail-fast: false
  matrix:
    os: [ubuntu-latest, windows-latest]
    python-version: ['3.14', '3.15']
```
Install dependencies into clean venv, run lint+typing+unit tests. Pin action revisions to reviewed SHAs. Flaky tests must be reproducible via captured seed and logs; quarantine with owner and issue, not an indefinite silent `skip`. Never label a missing wheel as a passing test; report it as blocked/incompatible.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
