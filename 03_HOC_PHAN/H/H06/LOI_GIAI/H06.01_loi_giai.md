## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết test Hypothesis property sorted length preservation và làm hỏng implementation để quan sát shrink.

```python
from hypothesis import given, strategies as st
@given(st.lists(st.integers()))
def test_sort_preserves_length(xs):
    assert len(sorted(xs)) == len(xs)
```
To demonstrate shrinking, deliberately write a broken sorter `def broken(xs): return sorted(xs)[:-1]` and test it on nonempty lists; Hypothesis should find a minimal counterexample. Keep test isolation: reset global state and do not rely on external network.
