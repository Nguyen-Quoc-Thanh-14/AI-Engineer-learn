# H05.01 — Lời giải Bài B: kiểm thử Ruff và static type checker thật

**Đề B:** Thiết lập Ruff/Pyright hoặc mypy và tạo một lỗi kiểu giả để kiểm tra CI.

## Mã nguồn và phép thử âm tính

[Mã B độc lập](../MA_MAU/H05.01_bai_B_static_lint.py) tạo hai file Python tạm thời:
- `good.py`: hàm có type annotation nhất quán, Ruff/Pyright phải chấp nhận.
- `bad.py`: có unused import và `count: int = "bad type"`; Ruff phải bắt F401, Pyright phải từ chối type mismatch.

Chạy thật `ruff check` và `pyright --pythonversion 3.15` bằng subprocess, ghi exit code và phiên bản công cụ; **không** dùng giả lập checker hoặc coi mã sai được chạy là static analysis.

**Tái lập từ gốc repo:** `python -m unittest discover -s tests -p 'test_issue9_h0501_static_lint.py' -v`.

## Tiêu chuẩn

Chỉ PASS nếu cả hai công cụ exit 0 với fixture tốt và exit khác 0 với fixture xấu. CI kiểm định điều này trên CPython 3.15.2. Workflow không thay thế phản biện độc lập, không suy ra toàn dự án đáp ứng lint/type checker từ các fixture nhỏ.

**Trạng thái:** đã bổ sung mã và test; cần CI đúng SHA để xác nhận runtime.
