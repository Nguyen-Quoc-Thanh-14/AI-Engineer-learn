# H05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết lập ruff/pyright hoặc mypy và tạo một lỗi kiểu giả để kiểm tra CI.

**Local verification:** create deliberate type error `x: int = "not integer"` and an unused import. Run `ruff check .`, `ruff format --check .`, and one of `mypy .` / `pyright` using a pinned version. Type-checkers must exit nonzero for the assignment; Ruff should report the unused import.
**CI contract:** formatter check → lint → static type check → pytest; stop promotion if any gate fails. Configure `pyproject.toml` once. Static checking does not execute code and cannot establish functional correctness.
**Status:** tool commands documented, not run here because the tools are not installed in the current environment.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
