## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Tạo báo cáo markdown sinh tự động từ CSV cố định và test metrics.

**Mã chạy riêng:** [PD04.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PD04.03_bai_B_solution.py)

```python
import csv,io,statistics

def report(csv_data):
    rows=list(csv.DictReader(io.StringIO(csv_data)))
    values=[float(r['value']) for r in rows]
    if not values:raise ValueError('no values')
    return f'# Report\n\nRows: {len(rows)}\nMean: {statistics.mean(values):.2f}\n'
assert report('value\n1\n2\n3\n')=='# Report\n\nRows: 3\nMean: 2.00\n'
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
