# PD04.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết data dictionary có owner, source URL, timestamp và validation rules.

**Data dictionary example:** Dataset `orders_v1`, owner `data-team@example.invalid`, source `internal POS / api v2`, extraction timestamp ISO-8601 UTC, license/consent and retention policy recorded. Fields: `order_id` (string, non-null, unique), `order_time` (timestamp with timezone, non-null), `quantity` (int, ≥0), `revenue_vnd` (decimal currency, ≥0), `customer_id` (sensitive identifier, encrypted/limited access). Validation: unique key, schema drift, freshness max 2 hours, no negative totals, PII access log. Store immutable source checksum + transformation git SHA; do not treat an arbitrary URL as verified provenance.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
