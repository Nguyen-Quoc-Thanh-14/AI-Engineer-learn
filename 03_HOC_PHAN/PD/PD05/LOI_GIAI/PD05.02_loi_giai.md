## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thử giá trị missing trong boolean filter, sort, join trên pandas 3.x.

**Mã chạy riêng:** [PD05.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PD05.02_bai_B_solution.py)

```python
import pandas as pd
s=pd.Series([3,pd.NA,1],dtype='Int64')
assert s.isna().sum()==1
mask=s>1
assert str(mask.dtype)=='boolean'
assert s[mask].tolist()==[3]
assert s.sort_values(na_position='last').isna().iloc[-1]
# This checks pandas 2.x behavior only; re-run on pandas 3.x before claiming compatibility.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
