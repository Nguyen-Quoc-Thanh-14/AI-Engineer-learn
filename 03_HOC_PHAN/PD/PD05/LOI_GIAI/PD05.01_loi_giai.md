# PD05.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Trên pandas 3.x, viết test chained assignment so với .loc và ghi phiên bản.

Pandas 3.x Copy-on-Write compatibility experiment (requires **pandas 3.x**, not available here):
```python
import pandas as pd
original=pd.DataFrame({'x':[1,2,3]})
view=original[['x']]
view.loc[0,'x']=99
assert original.loc[0,'x']==1
original.loc[0,'x']=42
assert original.loc[0,'x']==42
```
Never use `df[df.x > 0]['x'] = value` to modify source; prefer `df.loc[df.x > 0,'x']=value` and read exact 3.x CoW warning semantics. Record `pd.__version__`, and compare behavior on 2.2 vs 3.x; passing on 2.2 does **not** validate 3.x.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
