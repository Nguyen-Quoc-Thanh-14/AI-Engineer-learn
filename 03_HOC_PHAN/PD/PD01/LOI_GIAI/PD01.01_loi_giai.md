## 1. Khái niệm và hợp đồng

NumPy ndarray có shape, ndim và dtype; vectorized operations thực hiện trên nhiều phần tử, nhưng broadcasting chỉ hợp lệ khi kích thước từng trục từ phải sang trái bằng nhau hoặc một trong hai là 1.

## 2. Lập luận trước khi viết mã

Kiểm tra đầu vào có đúng hai chiều và chiều cột bằng chiều vector offset trước khi cộng; chuyển dtype sang float để hạn chế tràn số nguyên. Khi shape không tương thích, trả ValueError có nghĩa thay vì dựa hoàn toàn vào exception sâu trong NumPy.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PD01.01_bai_tap_da_giai_v25.py`](../MA_MAU/PD01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```python
import numpy as np

def shift_columns(matrix, offsets):
    matrix = np.asarray(matrix, dtype=float)
    offsets = np.asarray(offsets, dtype=float)
    if matrix.ndim != 2 or offsets.ndim != 1:
        raise ValueError('matrix 2D, offsets 1D')
    if matrix.shape[1] != offsets.shape[0]:
        raise ValueError('số cột phải bằng số offset')
    return matrix + offsets

def check():
    result = shift_columns([[1, 2], [3, 4]], [10, 20])
    assert np.array_equal(result, [[11, 22], [13, 24]])
    assert shift_columns(np.empty((0, 2)), [1, 2]).shape == (0, 2)
    for a, b in (([1, 2], [10, 20]), ([[1, 2]], [1, 2, 3])):
        try: shift_columns(a, b)
        except ValueError: pass
        else: raise AssertionError('shape sai phải báo lỗi')

if __name__ == '__main__':
    check()
    print('OK PD01.01')
```

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không nhầm `array * array` với nhân ma trận (`@`); và không cho rằng mọi phép NumPy đều tránh tạo thêm bộ nhớ trung gian.

**Bài mở rộng chưa có đáp án:** So sánh memory usage khi tính trên mảng 1 triệu phần tử với xử lý theo khối và giải thích trade-off.
