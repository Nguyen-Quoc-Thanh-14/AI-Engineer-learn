## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thử transpose, `.copy()`, `np.save` và ghi nhận strides.

**Mã chạy riêng:** [PD01.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PD01.03_bai_B_solution.py)

```python
import numpy as np
from tempfile import TemporaryDirectory
from pathlib import Path
x=np.arange(12,dtype=np.int64).reshape(3,4)
t=x.T
assert t.strides==(x.strides[1],x.strides[0]) and np.shares_memory(x,t)
y=t.copy();assert not np.shares_memory(x,y)
with TemporaryDirectory() as td:
    p=Path(td)/'matrix.npy';np.save(p,y)
    assert np.array_equal(np.load(p,allow_pickle=False),y)
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
