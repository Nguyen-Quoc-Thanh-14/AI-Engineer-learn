# Lời giải mẫu PD01.02 — Broadcasting và vectorization

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** So sánh vectorization `x**2` với list comprehension cho 4 số, kiểm tra kết quả cùng nghĩa.

## Code lời giải

```python
import numpy as np
x=np.array([1,2,3,4]);assert (x*x).tolist()==[1,4,9,16]
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Mảng shape (2,3) cộng vector shape (3,) được broadcast theo từng hàng. Shape (2,) không khớp chiều cuối cùng 3 nên không thể cộng trực tiếp.

**Giới hạn:** Mismatch shape phát sinh ValueError thay vì tự đoán chiều.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
