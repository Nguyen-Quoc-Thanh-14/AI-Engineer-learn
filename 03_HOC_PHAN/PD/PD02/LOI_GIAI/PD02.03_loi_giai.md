## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết schema nullable integers vs floats và kiểm truyền vào sklearn.

**Mã chạy riêng:** [PD02.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PD02.03_bai_B_solution.py)

```python
import pandas as pd
from sklearn.impute import SimpleImputer
s=pd.Series([1,pd.NA,3],dtype='Int64')
assert s.isna().sum()==1
arr=SimpleImputer(strategy='median').fit_transform(s.to_frame())
assert arr.shape==(3,1) and float(arr[1,0])==2.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
