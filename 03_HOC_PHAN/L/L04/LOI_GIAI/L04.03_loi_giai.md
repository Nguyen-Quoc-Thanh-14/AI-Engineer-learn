# Lời giải mẫu L04.03 — Async I/O và tránh blocking calls

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Dùng semaphore giới hạn số tác vụ xử lý đồng thời.

## Code lời giải

```python
import asyncio
async def f(x):
    await asyncio.sleep(0)
    return x
async def main():
    sem=asyncio.Semaphore(1)
    async def g(x):
        async with sem: return await f(x)
    return await asyncio.gather(g(1),g(2))
assert asyncio.run(main())==[1,2]
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** Không nhầm timeout với cancellation cleanup; tài nguyên cần đóng đúng.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
