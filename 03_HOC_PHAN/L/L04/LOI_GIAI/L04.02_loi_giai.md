# Lời giải mẫu L04.02 — asyncio tasks và gather

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Tạo 3 coroutine trả x+1, gather rồi assert đúng thứ tự kết quả.

## Code lời giải

```python
import asyncio
async def f(x):
    await asyncio.sleep(0);return x+1
async def main():return await asyncio.gather(*(f(i) for i in range(3)))
assert asyncio.run(main())==[1,2,3]
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Xác định đầu vào và hợp đồng → thực hiện bước biến đổi → kiểm tra kết quả bằng `assert` → thử thêm ca biên; giải thích từng dòng thay vì chỉ nhìn đầu ra.

**Giới hạn:** gather mặc định có semantics xử lý exception/cancellation cần đọc tài liệu phiên bản đích.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
