## 1. Khái niệm và hợp đồng

Race condition xảy ra khi kết quả phụ thuộc vào thứ tự xen kẽ các thao tác trên trạng thái chung; GIL không phải lời bảo đảm tổng quát cho mọi phép cập nhật và chế độ free-threaded càng yêu cầu đồng bộ tường minh.

## 2. Lập luận trước khi viết mã

Counter sử dụng Lock để bảo vệ toàn bộ thao tác read-modify-write. Một lần chạy bản không lock cho kết quả đúng không chứng minh mã an toàn; cần xét interleavings, invariant và đồng bộ.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/L02.01_bai_tap_da_giai_v25.py`](../MA_MAU/L02.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/L02.01_bai_tap_da_giai_v25.py
```

```python
from concurrent.futures import ThreadPoolExecutor
from threading import Lock

class Counter:
    def __init__(self):
        self._value = 0
        self._lock = Lock()

    def increment(self):
        with self._lock:
            self._value += 1

    @property
    def value(self):
        with self._lock:
            return self._value

def run_workers(workers: int, times: int) -> int:
    if type(workers) is not int or type(times) is not int or workers < 1 or times < 0:
        raise ValueError('workers >=1 và times >=0')
    counter = Counter()
    def job():
        for _ in range(times):
            counter.increment()
    with ThreadPoolExecutor(max_workers=workers) as pool:
        list(pool.map(lambda _: job(), range(workers)))
    return counter.value

def check():
    assert run_workers(4, 500) == 2000
    assert run_workers(1, 0) == 0
    try: run_workers(0, 2)
    except ValueError: pass
    else: raise AssertionError('workers phải dương')

if __name__ == '__main__':
    check()
    print('OK L02.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không đặt sleep bên trong critical section như cách “sửa race”; điều này chỉ làm các luồng chờ lâu hơn. Lock chỉ nên bảo vệ đoạn cập nhật tối thiểu cần tính nguyên tử.

**Bài mở rộng chưa có đáp án:** Dùng Queue cho thiết kế message passing và so sánh độ đơn giản với trạng thái chia sẻ có lock.
