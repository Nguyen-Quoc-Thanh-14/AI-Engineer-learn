# L05.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thử producer/consumer with bounded queue và cancellation dưới tải.

**Mã chạy riêng:** [L05.03_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/L05.03_bai_B_solution.py)

```python
import asyncio
async def main():
    q=asyncio.Queue(maxsize=2);seen=[]
    async def producer():
        for n in range(30): await q.put(n)
        await q.put(None)
    async def consumer():
        while True:
            value=await q.get()
            try:
                if value is None: return
                seen.append(value)
            finally:q.task_done()
    await asyncio.wait_for(asyncio.gather(producer(),consumer()),timeout=2)
    await q.join()
    assert seen==list(range(30)) and q.maxsize==2
asyncio.run(main())
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
