## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết coroutine mở tài nguyên giả và ghi nhận finally khi task bị hủy.

**Mã chạy riêng:** [L05.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/L05.01_bai_B_solution.py)

```python
import asyncio
async def work(events):
    events.append('open')
    try: await asyncio.sleep(60)
    finally: events.append('close')
async def main():
    events=[];task=asyncio.create_task(work(events))
    await asyncio.sleep(0);task.cancel()
    try: await task
    except asyncio.CancelledError: pass
    assert events==['open','close']
asyncio.run(main())
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
