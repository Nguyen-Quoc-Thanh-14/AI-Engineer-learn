# Lời giải độc lập và kiểm thử — L03.02

**Đề bài đã sửa để khớp mã chương v2.7:** Viết một worker thuần tính toán và xử lý 3 số bằng ProcessPoolExecutor, có kiểm thử số 0 và số âm; không tạo pool tại thời điểm import.

**Hợp đồng:** đúng thứ tự đầu ra/số lượng/schema, có giới hạn thời gian chờ, và dọn tài nguyên.

```python
from concurrent.futures import ProcessPoolExecutor

def square(n: int) -> int:
    return n*n

def batch_square(numbers):
    with ProcessPoolExecutor(max_workers=2) as pool:
        return list(pool.map(square, numbers))

if __name__ == '__main__':
    assert batch_square([2, 3, -4]) == [4, 9, 16]
    assert batch_square([0]) == [0]
    assert batch_square([]) == []
    print('PASS L03.02')
```

**Phản biện:** Không giả định thứ tự hoàn thành giống thứ tự nộp khi dùng as_completed. Dùng pool.map khi cần thứ tự đầu vào; ghi nhận chi phí serialize và process startup. Cần kiểm thử thêm dưới Windows, GIL-on/off khi mục tiêu yêu cầu.
