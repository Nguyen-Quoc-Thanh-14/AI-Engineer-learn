# Lời giải độc lập và kiểm thử — L03.01

**Đề bài đã sửa để khớp mã chương v2.7:** Viết hàm xử lý 3 công việc I/O giả lập bằng ThreadPoolExecutor; kiểm ba kết quả, timeout và dọn pool bằng context manager.

**Hợp đồng:** đúng thứ tự đầu ra/số lượng/schema, có giới hạn thời gian chờ, và dọn tài nguyên.

```python
from concurrent.futures import ThreadPoolExecutor
from time import sleep

def fetch_record(record_id):
    sleep(0.001)
    return {'id': record_id, 'value': record_id * 2}

def run_jobs(items):
    with ThreadPoolExecutor(max_workers=3) as pool:
        futures = [pool.submit(fetch_record, item) for item in items]
        return [future.result(timeout=2) for future in futures]

if __name__ == '__main__':
    assert run_jobs([1, 2, 3]) == [
        {'id': 1, 'value': 2}, {'id': 2, 'value': 4}, {'id': 3, 'value': 6}]
    assert run_jobs([]) == []
    assert run_jobs([5])[0]['value'] == 10
    print('PASS L03.01')
```

**Phản biện:** Đừng dùng CPU-bound thuần Python làm minh chứng tốc độ thread; tránh phụ thuộc thứ tự hoàn tất và dùng Future.result(timeout=...) khi cần hạn chờ. Cần kiểm thử thêm dưới Windows, GIL-on/off khi mục tiêu yêu cầu.
