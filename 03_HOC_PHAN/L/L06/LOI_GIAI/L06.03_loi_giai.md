# L06.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Lập bảng chi phí process startup và data sharing, nêu điều kiện chọn subinterpreters.

| Mechanism | Shared state | Serialization | Cancellation concerns |
|---|---|---|---|
| Thread | Shared heap | Usually no | Cooperative task/IO cancellation |
| Process | Isolated memory | Usually yes | Worker termination and in-flight requests |
| Subinterpreter | Isolated interpreter state | Explicit exchange | Interpreter lifecycle; extension compatibility |

Benchmark cold creation + 1 KB and 10 MB transfers separately. Choose based on workload and failure isolation, not only microbenchmark time. Compare 3.15 docs and the actual installed build before relying on subinterpreter APIs.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
