## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thử stress test 100 lượt producer/consumer có timeout và kiểm tra tất cả task đã xử lý.

**Mã chạy riêng:** [L06.04_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/L06.04_bai_B_solution.py)

```python
import asyncio
async def main():
    q=asyncio.Queue(maxsize=5);seen=[]
    async def producer():
        for n in range(100): await q.put(n)
        await q.put(None)
    async def consumer():
        while True:
            x=await q.get()
            try:
                if x is None:return
                seen.append(x)
            finally:q.task_done()
    await asyncio.wait_for(asyncio.gather(producer(),consumer()),3)
    assert sorted(seen)==list(range(100))
asyncio.run(main())
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
