# L01.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Phân tích lựa chọn threads vs processes cho I/O-bound và CPU-bound trên CPython mặc định.

| Workload | Primary candidate | Caveat |
|---|---|---|
| Waiting on many network sockets | asyncio or thread pool | Use bounded concurrency and timeouts |
| Blocking HTTP library | ThreadPoolExecutor | Threads do not make blocking calls safe by themselves |
| CPU-heavy pure Python under default CPython GIL | ProcessPoolExecutor | Serialization/startup overhead |
| Vectorized native kernels | NumPy/native code | Often release GIL but verify library behavior |
| Free-threaded CPython | Threads may exploit parallelism | Race safety and extension compatibility must be audited |

**Acceptance:** benchmark equal workloads with warmup, repeat measurements, prove output equivalence and record `sys._is_gil_enabled()` where supported.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
