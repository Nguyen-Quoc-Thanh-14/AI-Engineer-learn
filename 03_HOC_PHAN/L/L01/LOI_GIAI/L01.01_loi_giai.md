# Lời giải mẫu L01.01 — Process, thread, task

> Chỉ tham khảo sau khi tự giải. Một bài toán có thể có nhiều lời giải hợp lệ.

**Đề bài:** Giải thích vì sao gọi `time.sleep(1)` bên trong coroutine làm block loop.

## Code lời giải

```python
import asyncio
async def work(n):
    await asyncio.sleep(0)
    return n*n
assert asyncio.run(work(3))==9
```

**Kiểm thử cục bộ:** pass trên Python 3.13.5.

## Giải thích và phản biện

Tạo hai coroutine ngắn với `asyncio.gather()`; lịch trình có thể xen kẽ ở các `await`. Đoạn ví dụ không khởi chạy thread hoặc process; `await` cho event loop cơ hội chạy coroutine khác.

**Giới hạn:** `asyncio.run()` không thể gọi lồng bên trong event loop đang chạy.

**Cách tự đánh giá:** sửa một đầu vào để kiểm tra hợp đồng; so sánh với quy tắc của bài và mã ví dụ.
