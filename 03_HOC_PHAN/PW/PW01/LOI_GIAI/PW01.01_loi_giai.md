## 1. Khái niệm và hợp đồng

HTTP tách URL, method, header, body và status. Query string có thể chứa nhiều giá trị cho cùng một key; không nên đồng nhất việc parse query với xác thực đầu vào hoặc kiểm soát truy cập.

## 2. Lập luận trước khi viết mã

Phân tích URL và các query parameters bằng urllib.parse, chỉ cho phép http/https và hostname không rỗng. Giữ danh sách giá trị của một key thay vì tự động lấy phần tử đầu tiên; hành vi duplicate keys cần được API spec quy định.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PW01.01_bai_tap_da_giai_v25.py`](../MA_MAU/PW01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/PW01.01_bai_tap_da_giai_v25.py
```

```python
from urllib.parse import urlsplit, parse_qs

def parse_http_url(raw: str):
    if not isinstance(raw, str):
        raise TypeError('URL phải là str')
    result = urlsplit(raw)
    if result.scheme not in ('http', 'https') or not result.hostname:
        raise ValueError('cần URL http(s) có host')
    if result.username is not None or result.password is not None:
        raise ValueError('không nhận credentials trong URL')
    return result.path or '/', parse_qs(result.query, keep_blank_values=True)

def check():
    path, query = parse_http_url('https://example.org/items?page=1&page=2')
    assert path == '/items' and query['page'] == ['1','2']
    assert parse_http_url('http://example.org')[0] == '/'
    try: parse_http_url('file:///etc/passwd')
    except ValueError: pass
    else: raise AssertionError('schema sai')
    try: parse_http_url(None)
    except TypeError: pass
    else: raise AssertionError('sai kiểu')

if __name__ == '__main__':
    check()
    print('OK PW01.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không dùng urlsplit rồi cho rằng URL luôn an toàn cho HTTP fetch: SSRF còn đòi hỏi kiểm tra DNS/IP/redirect ở lớp kết nối, không chỉ kiểm tra scheme.

**Bài mở rộng chưa có đáp án:** Viết mô tả API GET /items?page=1 với các mã 200, 400, 404; xây ma trận hợp đồng và test không có network.
