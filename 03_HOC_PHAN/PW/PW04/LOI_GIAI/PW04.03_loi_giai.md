# PW04.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thử instrument API request → DB query và xem trace waterfall.

Trace waterfall target: inbound HTTP request span → business-handler span → DB query span → response. Propagate W3C `traceparent` safely across trusted services, record sampling decisions and high-cardinality attribute limits, set span status on errors. `request_id` and `trace_id` should appear in sanitized logs; never put access tokens or PII into span attributes. Smoke test with local OTLP exporter or in-memory exporter and assert parent-child relationship plus latency observations. **Status:** instrumentation plan; OpenTelemetry SDK not installed here.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
