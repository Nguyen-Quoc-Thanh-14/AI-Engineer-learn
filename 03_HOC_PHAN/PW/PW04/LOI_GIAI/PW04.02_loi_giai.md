## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Xây at-least-once consumer giả lập và test duplicate delivery.

**Mã chạy riêng:** [PW04.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PW04.02_bai_B_solution.py)

```python
# At-least-once deliveries: deduplicate with persistent idempotency key in production.
seen=set();applied=[]
def consume(message):
    key=message['event_id']
    if key in seen:return False
    seen.add(key);applied.append(message['value']);return True
assert consume({'event_id':'e1','value':4})
assert not consume({'event_id':'e1','value':4})
assert applied==[4]
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
