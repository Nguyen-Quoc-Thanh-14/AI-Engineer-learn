# PW04.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế load test 100 concurrent users và policy rollback khi 5xx rate tăng.

**100 concurrent-user load-test plan:** fixed dataset, at least 5-minute steady window after warmup, target mix GET 70%/POST 30%, test authorized and unauthorized endpoints, production-like rate limits. Gate: observed 5xx rate ≤0.5%, p95 API latency ≤500 ms, DB pool wait below timeout, no cross-user leaks. Rollback automatically if 5xx >2% for 3 consecutive minutes or any security regression; keep previous signed image/schema compatibility. Use isolated staging data and record CPU/RAM/network and exact client arrival rate; 100 users is not the same as 100 RPS.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
