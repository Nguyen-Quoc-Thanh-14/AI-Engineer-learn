# PW04.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Xây ASGI lifespan fixture mở/đóng resource một lần mỗi process.

**Mã chạy riêng:** [PW04.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PW04.01_bai_B_solution.py)

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from fastapi.testclient import TestClient
state={'opened':0,'closed':0}
@asynccontextmanager
async def lifespan(app):
    state['opened']+=1
    try:yield
    finally:state['closed']+=1
app=FastAPI(lifespan=lifespan)
@app.get('/')
def home():return {'ok':True}
with TestClient(app) as client:
    assert client.get('/').status_code==200
    assert state=={'opened':1,'closed':0}
assert state=={'opened':1,'closed':1}
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
