## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Viết pytest TestClient test 200, 401, 403, 422 và rollback DB fixture.

**Mã chạy riêng:** [PW03.02_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PW03.02_bai_B_solution.py)

```python
from fastapi import FastAPI,HTTPException
from fastapi.testclient import TestClient
app=FastAPI()
@app.get('/public')
def public():return {'ok':True}
@app.get('/private/{id}')
def private(id:int,role:str='guest'):
    if role=='guest':raise HTTPException(401)
    if id!=1:raise HTTPException(403)
    return {'id':id}
client=TestClient(app)
assert client.get('/public').status_code==200
assert client.get('/private/1').status_code==401
assert client.get('/private/2?role=reader').status_code==403
assert client.get('/private/notint?role=reader').status_code==422
# Synthetic auth role query parameter is ONLY for test illustration; not production auth.
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
