# PW03.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Triển khai app qua ASGI server local và kiểm graceful shutdown bằng test.

ASGI deployment checklist: choose ASGI server compatible with framework and use a supervised process manager/orchestrator; readiness endpoint distinct from liveness endpoint; handle SIGTERM by stop-accepting, drain active requests, finish/cancel bounded background tasks and close DB pools. Use nonroot container, pinned reviewed image digest, TLS at documented edge and secrets from runtime manager. Compare WSGI sync request lifecycle with ASGI async scope rather than assuming WSGI supports WebSockets. Verify graceful shutdown with in-flight request under test and bounded termination timeout.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
