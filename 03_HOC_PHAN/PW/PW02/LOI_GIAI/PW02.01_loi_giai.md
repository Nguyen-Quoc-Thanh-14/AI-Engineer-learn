# PW02.01 — Lời giải vận dụng độc lập (v2.8)

## Lời giải độc lập — Bài B (v2.8)

**Đề bài:** Thiết kế User/Order models và migration tạo foreign key.

**Mã chạy riêng:** [PW02.01_bai_B_solution.py](../../../../31_HOAN_THIEN_LOI_GIAI_V28/PW02.01_bai_B_solution.py)

```python
import sqlite3
with sqlite3.connect(':memory:') as db:
    db.execute('PRAGMA foreign_keys = ON')
    db.execute('CREATE TABLE user(id INTEGER PRIMARY KEY, email TEXT UNIQUE NOT NULL)')
    db.execute('CREATE TABLE orders(id INTEGER PRIMARY KEY, user_id INTEGER NOT NULL REFERENCES user(id))')
    db.execute('INSERT INTO user VALUES (1, "a@example.test")')
    db.execute('INSERT INTO orders VALUES (100, 1)')
    try:db.execute('INSERT INTO orders VALUES (101, 999)')
    except sqlite3.IntegrityError:pass
    else:raise AssertionError('foreign key absent')
```

**Lưu ý chuyên môn:** Các assertion là kiểm thử chức năng trên ví dụ này, không thay thế kiểm thử tích hợp hoặc đánh giá sư phạm.
