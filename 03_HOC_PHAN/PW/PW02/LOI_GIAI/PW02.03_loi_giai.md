# PW02.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế cache invalidation khi update record và job dedup key.

Cache-aside write path: update authoritative database transaction, then invalidate versioned cache key; set TTL and stampede controls. For async job, store stable idempotency key in persistent DB with unique constraint; queue may redeliver at least once, so handler must be duplicate-safe. Tests: stale cache after update (should not return old value), two concurrent identical jobs (one effect), lost worker during commit and retry (no double charge). Do not advertise in-memory set as production deduplication across processes.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
