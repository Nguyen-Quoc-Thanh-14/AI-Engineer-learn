# PW02.02 — Lời giải B: kiểm thử ownership và CSRF với trạng thái giả lập

**Đề B:** Thử resource ownership access và CSRF token verification.

[Mã chính sách](../MA_MAU/PW02.02_bai_B_ownership_csrf.py) sử dụng `VerifiedSession` đại diện cho danh tính đã xác thực **ở server**, `Record` gắn owner và token CSRF **được lưu ở server**. Khi cập nhật: chỉ owner được sửa, token phải khớp bằng `hmac.compare_digest`, input rỗng/sai kiểu phải bị từ chối. Trả một bản ghi bất biến mới thay vì sửa bản ghi nguồn trước khi kiểm quyền.

[Kiểm thử dương/âm](../../../../tests/test_issue9_pw0202_ownership_csrf.py) gồm owner hợp lệ, người dùng khác owner, token thiếu/sai/sai kiểu, session tự gửi không tin cậy, payload rỗng và thông báo lỗi không tiết lộ token.

**Giới hạn bảo mật:** đây là test logic tại policy boundary, **không phải** xác minh cookie `SameSite`, `Secure`, trình duyệt Origin, session lifecycle, middleware CSRF hoặc một API production. Các lớp đó cần integration/browser tests riêng. Chỉ ghi PASS khi GitHub CI trên SHA hiện hành xác nhận test; không dùng dấu hiệu này thay cho review an ninh độc lập.
