# PW02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thử resource ownership access và CSRF token verification.

**Ownership test:** seed user A and user B, each with one record; send authenticated request from A for B's ID, expect 403/404 and **no data**. Session cookie requires `HttpOnly`, `Secure`, appropriate `SameSite` and expiration; state-changing browser requests require CSRF protection unless architecture demonstrably avoids cookie-based ambient authority. Logout must invalidate server-side session/token where supported. Compare unauthenticated (401), unauthorized (403), malformed (422), not found (404) and success (200) separately in API tests.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
