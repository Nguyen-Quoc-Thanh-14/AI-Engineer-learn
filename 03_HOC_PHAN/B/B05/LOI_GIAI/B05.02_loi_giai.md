# Lời giải B05.02 — Điều kiện lồng nhau và kiểm tra dữ liệu

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm phí: dưới 0 -> ValueError; >=200000 được miễn; các trường hợp còn lại 20000.

## Lời giải Python

```python
def tinh_phi(gia_tri):
    if gia_tri < 0:
        raise ValueError("giá trị âm")
    return 0 if gia_tri >= 200000 else 20000
assert tinh_phi(0) == 20000
assert tinh_phi(200000) == 0
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Xác định ràng buộc, trả về hoặc raise khi vi phạm, rồi viết đường đi chính ít tầng lồng. Mỗi nhánh quan trọng phải có ít nhất một ca kiểm thử.

**Lỗi cần tránh:** Không viết điều kiện quá tổng quát rồi che khuất nhánh cụ thể. Một `else` đặt sai mức thụt lề đổi hoàn toàn logic.
