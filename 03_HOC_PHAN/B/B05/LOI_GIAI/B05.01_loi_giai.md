# Lời giải B05.01 — if, elif, else

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm phân loại nhiệt độ: < 15 lạnh, <= 30 dễ chịu, > 30 nóng.

## Lời giải Python

```python
def phan_loai(t):
    if t < 15:
        return "lạnh"
    elif t <= 30:
        return "dễ chịu"
    return "nóng"
assert phan_loai(15) == "dễ chịu"
assert phan_loai(31) == "nóng"
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Đặt các điều kiện loại trừ nhau theo thứ tự phù hợp; `elif` không được đánh giá nếu `if` trước đúng. Nếu không có `else`, có thể không nhánh nào thực thi.

**Lỗi cần tránh:** Đặt điều kiện điểm >= 65 trước >= 80 khiến nhánh giỏi không bao giờ tới được.
