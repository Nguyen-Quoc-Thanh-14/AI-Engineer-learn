# Lời giải B05.03 — match/case, guard và phạm vi áp dụng

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Xây hàm `tai_hinh_dang` xử lý `("square", canh)` và `("rectangle", dai, rong)`; trường hợp khác trả None.

## Lời giải Python

```python
def dien_tich_hinh(du_lieu):
    match du_lieu:
        case ("square", canh) if canh >= 0:
            return canh * canh
        case ("rectangle", dai, rong) if dai >= 0 and rong >= 0:
            return dai * rong
        case _:
            return None
assert dien_tich_hinh(("square", 3)) == 9
assert dien_tich_hinh(("rectangle", 2, 4)) == 8
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Python thử case theo thứ tự; khi pattern và guard khớp, thực hiện nhánh đó. `case _` là wildcard. Đặt case cụ thể trước case tổng quát để tránh che khuất.

**Lỗi cần tránh:** `case name:` không kiểm tra biến name có bằng dữ liệu không; nó bắt giá trị vào tên `name`. Dùng literal, enum hoặc qualified constant cho value pattern.
