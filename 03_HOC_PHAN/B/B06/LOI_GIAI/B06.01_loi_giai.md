# Lời giải B06.01 — for, while và range

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm tính tổng số chẵn từ 0 tới n (kể cả n), yêu cầu n không âm.

## Lời giải Python

```python
def tong_chan(n):
    if n < 0:
        raise ValueError("n âm")
    return sum(range(0, n + 1, 2))
assert tong_chan(0) == 0
assert tong_chan(5) == 6
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

`for` lấy iterator từ iterable, gọi lần lượt next cho đến StopIteration. `while` đánh giá lại điều kiện trước mỗi vòng; phải bảo đảm trạng thái tiến gần điểm dừng.

**Lỗi cần tránh:** `range(1, 5)` chỉ có 1,2,3,4; thay đổi danh sách trong lúc for duyệt có thể làm bỏ sót phần tử.
