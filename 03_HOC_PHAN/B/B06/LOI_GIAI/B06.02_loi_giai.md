# Lời giải B06.02 — break, continue và loop else

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm trả về vị trí số âm đầu tiên hoặc None khi không có số âm.

## Lời giải Python

```python
def vi_tri_am(xs):
    for i, x in enumerate(xs):
        if x < 0:
            return i
    return None
assert vi_tri_am([1, 0, -2]) == 2
assert vi_tri_am([0, 3]) is None
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Tìm kiếm tuyến tính: duyệt → gặp mục tiêu thì break → không gặp mục tiêu thì else chạy. Dùng hàm return có thể đơn giản hơn khi chỉ cần kết luận.

**Lỗi cần tránh:** Với `continue`, vòng vẫn có thể kết thúc bình thường và chạy else; else chỉ bị bỏ qua khi break.
