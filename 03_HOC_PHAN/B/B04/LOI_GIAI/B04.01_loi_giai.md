## Bài toán

Viết hàm xác định một điểm có nằm trong khoảng [0,100] và là int (không nhận bool).

## Lời giải Python

```python
def diem_hop_le(x):
    return type(x) is int and 0 <= x <= 100
assert diem_hop_le(0)
assert diem_hop_le(100)
assert not diem_hop_le(True)
assert not diem_hop_le(101)
```

## Giải thích

Kiểm tra điều kiện từ trái sang phải. Ví dụ `x != 0 and 10 / x > 2` an toàn với x=0 vì phần chia không chạy; đảo thứ tự làm thay đổi kết quả/ngoại lệ.

**Lỗi cần tránh:** Không dùng `a == 1 or 2` để kiểm tra a có bằng 1 hoặc 2; `or 2` truthy. Dùng `a in (1, 2)`.
