# Lời giải B04.02 — Thứ tự ưu tiên và thứ tự đánh giá

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết biểu thức tính diện tích hình vành khăn theo công thức pi × (R² - r²); dùng ngoặc rõ ràng.

## Lời giải Python

```python
import math
def dien_tich_vanh_khan(R, r):
    if not 0 <= r <= R:
        raise ValueError("bán kính không hợp lệ")
    return math.pi * (R ** 2 - r ** 2)
assert math.isclose(dien_tich_vanh_khan(3, 0), math.pi * 9)
```

## Giải thích

Để dự đoán kết quả, xác định nhóm theo precedence rồi xét quy tắc đánh giá toán hạng. Không dựa vào “chạy thử vài lần” để suy ra ngữ nghĩa tổng quát.

**Lỗi cần tránh:** `-2 ** 2` cho -4 vì được hiểu là `-(2 ** 2)`; đây là bẫy phổ biến.
