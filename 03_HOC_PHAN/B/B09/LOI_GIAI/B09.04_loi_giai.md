# Lời giải B09.04 — Kiểm soát chuyển đổi kiểu và quy tắc làm tròn

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm nhận chuỗi số và trả Decimal làm tròn một chữ số với ROUND_HALF_UP.

## Lời giải Python

```python
from decimal import Decimal, ROUND_HALF_UP
def tron_mot(text):
    return Decimal(text).quantize(Decimal("0.1"),rounding=ROUND_HALF_UP)
assert tron_mot("2.25") == Decimal("2.3")
assert tron_mot("2.24") == Decimal("2.2")
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.

## Giải thích

Đặc tả độ chính xác, cách xử lý dữ liệu không hợp lệ, phép làm tròn, rồi kiểm thử quanh điểm nửa đơn vị; không dùng định dạng f-string làm dữ liệu để tính tiếp trừ khi có chủ ý.

**Lỗi cần tránh:** `f"{x:.2f}"` trả chuỗi, không đồng nghĩa thay đổi số gốc hay bảo đảm chính sách làm tròn nghiệp vụ.
