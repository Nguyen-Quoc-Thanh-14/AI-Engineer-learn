# Lời giải B09.02 — Boolean logic và lỗi ranh giới

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Tạo hàm `trong_doan(n)` trả True đúng khi 10 <= n < 20, và kiểm thử ở 9,10,19,20.

## Lời giải Python

```python
def trong_doan(n):
    return 10 <= n < 20
assert not trong_doan(9)
assert trong_doan(10)
assert trong_doan(19)
assert not trong_doan(20)
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.

## Giải thích

Lập bảng kiểm thử với ngưỡng-1, ngưỡng, ngưỡng+1 trước khi viết hàm. Tách việc kiểm tra miền giá trị với logic nghiệp vụ xử lý dữ liệu đã hợp lệ.

**Lỗi cần tránh:** Không kiểm thử duy nhất một trường hợp “đẹp” bên trong miền, vì điều đó bỏ sót hầu hết lỗi biên.
