# Lời giải B03.03 — input, print và f-string

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm nhận văn bản số lượng và trả câu thông báo với tổng tiền 8.500 đồng/sản phẩm.

## Lời giải Python

```python
def bao_gia(so_luong_text):
    n = int(so_luong_text)
    if n < 0:
        raise ValueError("số lượng phải không âm")
    return f"Tổng: {n * 8500:,} đồng"
assert bao_gia("3") == "Tổng: 25,500 đồng"
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Quy trình I/O: nhận chuỗi → kiểm tra/chuyển kiểu → tính toán → định dạng đầu ra. `format` và f-string cho phép định dạng mà không tự thay đổi giá trị lưu trong biến.

**Lỗi cần tránh:** Không cộng trực tiếp chuỗi từ `input()` với số nguyên; hãy bắt lỗi ValueError khi chuyển kiểu.
