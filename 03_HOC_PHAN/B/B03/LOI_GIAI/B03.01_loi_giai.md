# Lời giải B03.01 — str, Unicode cơ bản

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Tạo hàm `so_byte_utf8(text)` đếm số byte khi lưu chuỗi theo UTF-8; kiểm tra chữ Việt.

## Lời giải Python

```python
def so_byte_utf8(text):
    return len(text.encode("utf-8"))
assert so_byte_utf8("A") == 1
assert so_byte_utf8("á") == 2
```

## Giải thích

`len(s)` đếm số code point trong Python string, `len(s.encode("utf-8"))` đếm byte. Hai chuỗi nhìn giống nhau có thể khác biểu diễn do ký tự kết hợp; chuẩn hóa Unicode được cung cấp bởi `unicodedata`.

**Lỗi cần tránh:** Không cắt bytes UTF-8 theo chỉ số tùy ý rồi giải mã: có thể cắt giữa một mã ký tự. Với văn bản người dùng, cần tính tới grapheme cluster.
