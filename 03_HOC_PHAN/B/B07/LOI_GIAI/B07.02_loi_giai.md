# Lời giải B07.02 — Tham số, đối số và giá trị mặc định

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm `them_item(item, danh_sach=None)` trả danh sách mới và không chia sẻ dữ liệu default giữa hai lần gọi.

## Lời giải Python

```python
def them_item(item, danh_sach=None):
    if danh_sach is None:
        danh_sach = []
    return [*danh_sach, item]
assert them_item(1) == [1]
assert them_item(2) == [2]
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Python gán đối số vào các tham số theo chữ ký hàm và kiểm tra thiếu, thừa hoặc trùng lặp. Thiết kế keyword-only cho tham số dễ nhầm lẫn làm lời gọi dễ đọc hơn.

**Lỗi cần tránh:** Không dùng list/dict có thể thay đổi làm default nếu sẽ sửa chúng trong hàm: dùng None rồi tạo đối tượng mới bên trong.
