# Lời giải B07.01 — def, call, return

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm `gia_sau_giam(gia, phan_tram)` có kiểm tra giá và phần trăm giảm trong [0,100].

## Lời giải Python

```python
def gia_sau_giam(gia, phan_tram):
    if gia < 0 or not (0 <= phan_tram <= 100):
        raise ValueError("giá hoặc giảm giá không hợp lệ")
    return gia * (100 - phan_tram) / 100
assert gia_sau_giam(100, 20) == 80
assert gia_sau_giam(0, 20) == 0
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Khi gọi, đối số được đánh giá, tham số liên kết tới đối tượng tương ứng; thân hàm chạy và return chuyển quyền điều khiển cho nơi gọi.

**Lỗi cần tránh:** Nhầm `print(kq)` với `return kq`: print không tự làm hàm trả về kết quả tính toán.
