# Lời giải B08.02 — Call stack và lần vết lời gọi

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm `do_sau(n)` trả số frame lời gọi của chính nó tính từ n tới 0, kể cả base case.

## Lời giải Python

```python
def do_sau(n):
    if n < 0:
        raise ValueError("n âm")
    if n == 0:
        return 1
    return 1 + do_sau(n-1)
assert do_sau(2) == 3
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Ví dụ `count(3)` tạo 3 lời gọi nối tiếp về phía `count(0)`; sau đó return trả giá trị về gọi trước theo thứ tự ngược. Độ sâu call stack tăng theo số tầng đệ quy.

**Lỗi cần tránh:** Không suy ra đệ quy luôn nhanh hơn vòng lặp; Python không bảo đảm tail-call optimization.
