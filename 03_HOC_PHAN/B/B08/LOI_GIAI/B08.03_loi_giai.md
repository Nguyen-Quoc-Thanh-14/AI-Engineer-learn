# Lời giải B08.03 — Đệ quy so với vòng lặp

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm tính giai thừa bằng vòng lặp; so sánh với cách đệ quy cho n=0,5.

## Lời giải Python

```python
def fact_iter(n):
    if n < 0:
        raise ValueError("n âm")
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result
assert fact_iter(0) == 1
assert fact_iter(5) == 120
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

So sánh hai cách bằng cùng hợp đồng đầu vào, kiểm thử các trường hợp n=0, n=1, n lớn và đo số lời gọi / bộ nhớ nếu cần.

**Lỗi cần tránh:** Python không tự tối ưu tail-recursion; không dùng đệ quy thuần cho n vài chục nghìn.
