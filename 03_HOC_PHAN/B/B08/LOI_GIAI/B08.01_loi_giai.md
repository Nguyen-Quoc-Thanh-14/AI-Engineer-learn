# Lời giải B08.01 — Bài toán con và điều kiện dừng

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm đệ quy tính tổng từ 1 tới n, với n không âm.

## Lời giải Python

```python
def tong_den(n):
    if n < 0:
        raise ValueError("n âm")
    if n == 0:
        return 0
    return n + tong_den(n-1)
assert tong_den(4) == 10
assert tong_den(0) == 0
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Khi tính giai thừa, `fact(n)` gọi `fact(n-1)` cho tới `fact(0)`. Sau khi chạm base case, kết quả quay lại lần lượt qua các lời gọi trước.

**Lỗi cần tránh:** Không dùng đệ quy cho dữ liệu quá sâu nếu độ sâu vượt giới hạn interpreter; vòng lặp thường tránh chi phí call stack.
