# Lời giải B02.01 — int, float và các phép toán

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm trả về số hộp đầy và số vật còn lại khi chia n vật thành hộp chứa k vật; k phải dương.

## Lời giải Python

```python
def dong_hop(n, k):
    if n < 0 or k <= 0:
        raise ValueError("n >= 0 và k > 0")
    return divmod(n, k)
assert dong_hop(17, 5) == (3, 2)
assert dong_hop(0, 5) == (0, 0)
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

Biểu thức số học được đánh giá theo quy tắc ưu tiên. Với `a // b` và `a % b` (b khác 0), có hệ thức `a == (a // b) * b + (a % b)`. So sánh với trường hợp âm để tránh hiểu sai.

**Lỗi cần tránh:** Không dùng float để biểu diễn chính xác tiền tệ có yêu cầu làm tròn chặt chẽ; ưu tiên số nguyên đơn vị nhỏ nhất hoặc `Decimal` với quy tắc nghiệp vụ rõ.
