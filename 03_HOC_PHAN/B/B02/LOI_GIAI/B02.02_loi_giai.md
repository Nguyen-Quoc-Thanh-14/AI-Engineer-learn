# Lời giải B02.02 — bool, None và truthiness

> Chỉ tham khảo sau khi đã tự làm. Đây là một lời giải mẫu, không nhất thiết là cách duy nhất.

## Bài toán

Viết hàm nhận số lượng hoặc None; trả 0 nếu là None nhưng giữ nguyên 0 và các số hợp lệ.

## Lời giải Python

```python
def chuan_hoa_so_luong(value):
    return 0 if value is None else value
assert chuan_hoa_so_luong(None) == 0
assert chuan_hoa_so_luong(0) == 0
assert chuan_hoa_so_luong(3) == 3
```

## Kiểm tra: pass

- Môi trường hiện có: Python 3.13.5.
- Lời giải đã chạy và không gặp lỗi trong môi trường trên.
- Người học nên bổ sung test sai đầu vào và thử nhiều trường hợp biên.

## Giải thích

`if x:` kiểm tra truthiness, còn `x is None` kiểm tra đúng sentinel thiếu giá trị. Toán tử `and` và `or` có thể trả về chính toán hạng thay vì một `bool` mới.

**Lỗi cần tránh:** Đừng dùng `if not so_luong:` khi muốn chỉ phát hiện `None`: số lượng 0 cũng sẽ bị xem là thiếu.
