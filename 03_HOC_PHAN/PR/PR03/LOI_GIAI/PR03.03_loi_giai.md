# PR03.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế fuzz harness cho native parser kèm ASAN/UBSAN build.

Fuzz harness: define `parse(const uint8_t *data, size_t length)` that checks length before every read and never retains an input pointer beyond call. Feed seed corpus (empty, max length, negative encoded size, invalid UTF-8, oversized count) into libFuzzer/AFL++ harness. Compile test build with `-fsanitize=address,undefined -fno-omit-frame-pointer -g`; verify at least one intentionally broken fixture is detected. Track unique crashes, minimized repro, sanitizer stdout and safe bounds. **Status:** design only; native fuzzing not run here.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
