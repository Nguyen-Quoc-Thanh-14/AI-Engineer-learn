# PR03.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** So 4 phương án cho transform một triệu integers và lập decision matrix.

Decision matrix (1 million integer transforms):
| Option | Setup | Typical strength | Risk |
|---|---|---|---|
| Python loop | None | Flexible logic | Python overhead |
| NumPy | Installed wheel | Vectorized contiguous arrays | Allocation/overflow and dtype |
| Numba | JIT compilation | Numeric loops after warmup | JIT overhead, support matrix |
| Rust/PyO3 | Native build/packaging | Controlled tight loops | ABI, ownership, unsafe boundaries |
Do **not** pre-rank by assumed speed. Validate exact numeric semantics, compare memory and post-warmup throughput, and include maintenance/portability cost in decision.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
