# PR01.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết C extension đơn giản add(a,b) và dùng sanitizer/test reference ownership.

**CPython extension with object ownership:** C function accepting one `PyObject*` input should use a *borrowed* reference for arguments parsed by `PyArg_ParseTuple` and return a **new reference** via `PyLong_FromLong`, or `Py_NewRef(obj)` when returning the same object. Never `Py_DECREF` a borrowed input that has not been retained. Build a minimal `identity` extension and assert return identity and reference counts with repeated calls under a debug interpreter; refcount counts are CPython-specific and cannot prove leak freedom on their own. Review C API docs `https://docs.python.org/3.15/c-api/refcounting.html`; test with leak/ASAN tooling before release. **Status:** design+API review, not validated on CPython 3.15.2.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
