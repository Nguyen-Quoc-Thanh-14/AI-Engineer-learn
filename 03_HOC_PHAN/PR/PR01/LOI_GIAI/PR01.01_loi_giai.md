## 1. Khái niệm và hợp đồng

FFI chuyển quyền kiểm soát bộ nhớ qua ranh giới Python–native; ctypes không tự đảm bảo rằng độ dài nguồn/đích được kiểm tra khi gọi hàm như memmove.

## 2. Lập luận trước khi viết mã

Tạo buffer C có kích thước cố định, kiểm tra payload là bytes và không dài hơn capacity trước khi copy. Đây là ví dụ minh họa ranh giới bộ nhớ; dùng API Python thuần nếu không có nhu cầu FFI thực tế.

## 3. Mã lời giải đầy đủ

Lưu tại [`../MA_MAU/PR01.01_bai_tap_da_giai_v25.py`](../MA_MAU/PR01.01_bai_tap_da_giai_v25.py). Có thể chạy:

```bash
python ../MA_MAU/PR01.01_bai_tap_da_giai_v25.py
```

```python
import ctypes

def copy_bytes(payload: bytes, capacity: int) -> bytes:
    if not isinstance(payload, bytes):
        raise TypeError('payload phải là bytes')
    if type(capacity) is not int or capacity < 0:
        raise ValueError('capacity phải là int không âm')
    if len(payload) > capacity:
        raise ValueError('buffer không đủ chứa dữ liệu')
    buf = ctypes.create_string_buffer(capacity if capacity else 1)
    if payload:
        ctypes.memmove(buf, payload, len(payload))
    return buf.raw[:len(payload)]

def check():
    assert copy_bytes(b'abc', 3) == b'abc'
    assert copy_bytes(b'', 0) == b''
    try: copy_bytes(b'over', 1)
    except ValueError: pass
    else: raise AssertionError('phải chặn overflow')
    try: copy_bytes('text', 10)
    except TypeError: pass
    else: raise AssertionError('sai kiểu')

if __name__ == '__main__':
    check()
    print('OK PR01.01')
```

## 4. Kết quả kiểm tra và diễn giải

- Các assertion trong `check()` kiểm tra ca bình thường và ca biên/sai đầu vào; **việc chạy thành công** cho biết các kiểm tra hiện tại không thất bại, không chứng minh mọi đầu vào đều đúng.
- Kết quả thực thi: **PASS** với Python 3.13.5.
- Không có lỗi ngoài dự kiến trong lượt chạy hiện tại.

## 5. Sai lầm và biến thể

**Sai lầm đặc trưng:** Không cấp phát buffer size n rồi sao chép n+1 bytes; đây là dạng lỗi native memory corruption nguy hiểm. Đừng tự nhận ctypes đảm bảo memory safety.

**Bài mở rộng chưa có đáp án:** Chuyển ví dụ sang cffi hoặc extension có kiểm tra bounds, phân tích ownership và lifetime của pointer; không giữ pointer tới vùng đã giải phóng.
