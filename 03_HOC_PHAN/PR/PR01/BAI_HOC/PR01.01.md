## 2. Khái niệm — Bản chất

Foreign Function Interface (FFI) cho Python gọi hàm/native library. Crossing boundary yêu cầu thống nhất ABI, kiểu dữ liệu, ownership và error handling; lỗi sai có thể gây crash process thay vì exception an toàn. `ctypes` thuộc stdlib, `cffi` là thư viện ngoài; không nên gọi thư viện hệ thống chưa biết nguồn.

## 3. Nguyên lý và cơ chế từng bước

Ví dụ không nạp thư viện C bên ngoài: dùng `ctypes.Structure` để minh họa layout trường C-compatible và kích thước. Layout phụ thuộc platform và alignment; ví dụ không suy ra byte size cụ thể.

## 4. Ví dụ tối thiểu có thể chạy

```python
import ctypes
class Point(ctypes.Structure):
    _fields_=[('x',ctypes.c_int),('y',ctypes.c_int)]
p=Point(2,3)
assert p.x==2 and p.y==3
assert ctypes.sizeof(Point)>=2*ctypes.sizeof(ctypes.c_int)
print(p.x,p.y)
```

**Kết quả kiểm thử cục bộ:** pass trên Python 3.13.5.

```text
2 3
```
