# PR02.03 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Viết C extension trả ValueError cho input âm và kiểm no memory leaks.

Native C function sketch:
```c
static PyObject *check_nonnegative(PyObject *self, PyObject *args) {
    long value;
    if (!PyArg_ParseTuple(args, "l", &value)) return NULL;
    if (value < 0) {
        PyErr_SetString(PyExc_ValueError, "value must be >= 0");
        return NULL;
    }
    return PyLong_FromLong(value);
}
```
Test zero/positive/negative, integer overflow and wrong type; if `PyLong_FromLong` allocation fails, returning `NULL` propagates `MemoryError`. Review `Py_DECREF` ownership for all branches. Compile with debug/sanitizer settings before claiming no leaks. **Status:** source example not independently compiled as this lesson’s full extension.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
