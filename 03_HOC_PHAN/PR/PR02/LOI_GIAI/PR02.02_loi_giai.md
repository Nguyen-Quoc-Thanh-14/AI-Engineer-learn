# PR02.02 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thử free-threaded build và kiểm nội dung shared mutable C state.

Thread-safety audit for free-threaded build: identify every global/static mutable object in C, every borrowed pointer whose owner may mutate, and callbacks into Python; protect invariants with locks or redesign to per-interpreter module state. Use PEP 803/793/820 stable-ABI rules and supported build tool for `abi3t`; otherwise build version-specific `cp315t`. Run 100,000 concurrent operations under a real 3.15.2 free-threaded interpreter and ASAN/TSAN where supported; check for memory corruption and reference ownership errors. **Status:** cannot claim tested without free-threaded CPython.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
