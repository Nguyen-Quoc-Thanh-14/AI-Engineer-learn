# PR02.04 — Lời giải vận dụng độc lập (v2.8)

## Lời giải thiết kế — Bài B (v2.8)

**Đề bài:** Thiết kế wheel release matrix 3.15 free-threaded và non-free-threaded.

Wheel target matrix: Linux x86_64/aarch64, Windows amd64, macOS arm64 as required × Python 3.14/3.15 × regular/free-threaded. Choose `abi3` only if compliant regular Stable ABI; `abi3t` only after free-threading Stable ABI migration and approved backend, otherwise version-specific `cp315t`. Build from signed source tag; inspect `auditwheel`/`delvewheel` equivalents and `packaging.tags`; install/test **each** wheel on matching runtime. Release blocked if any required architecture lacks an installable tested artifact.

**Trạng thái:** Lời giải dạng thiết kế/quy trình. Không đánh giá là chương trình đã chạy.
